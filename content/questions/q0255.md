::: testing
Whether you can say what slope compensation is, **derive how much** you need and describe the side effects. The interviewer is looking for:

1. Definition: an artificial ramp, with slope $m_a$, added to the sensed inductor current (or subtracted from the current command), synchronized to the clock.
2. Why: it changes the per-cycle multiplier to $\alpha=-(m_2-m_a)/(m_1+m_a)$ and so restores stability for $D>0.5$.
3. How much: $m_a>(m_2-m_1)/2$ for stability; $m_a\ge m_2/2$ covers all duty cycles; $m_a=m_2$ is dead-beat; practical designs use roughly 0.5 to 1 times $m_2$.
4. Costs: too much ramp turns current mode toward voltage mode and makes the peak-current limit depend on duty cycle.
:::

::: why
Slope compensation is a mandatory design detail in every fixed-frequency peak-current-mode converter: some ICs have it fixed internally, which sets a minimum inductance, others let you program it. Picking $L$ and the ramp wrong leads to the oscillation described in [[q0253]]. The parenthetical in the question ("what kinda person asks undergrads this?") is a reminder that this is a topic where a clear, calm derivation impresses an interviewer.
:::

::: concepts
- **Inductor slopes**: $m_1=(V_{in}-V_{out})/L$, $m_2=V_{out}/L$ ([[q0188]]).
- **Per-cycle multiplier** $\alpha$ for the inner loop ([[q0253]]).
- **Current sense gain $R_i$** (V/A) converts amps to volts for the comparator.
- **Compensation ramp**: voltage ramp of slope $S_e=m_aR_i$ (V/µs) added to the sensed signal.
- **Sampling double pole**: $Q_p=1/[\pi(m_cD'-0.5)]$.
- **Peak-current limit**: a fixed threshold gets reduced by the ramp.
:::

::: answer
"Slope compensation is a small artificial ramp that is added to the sensed inductor current, or equivalently subtracted from the current command, in a fixed-frequency peak current-mode converter. The ramp starts at zero each clock edge and rises through the on-time.

It's needed because without it, the error in the inductor current is multiplied by D over one minus D each cycle, so above 50 percent duty cycle the error grows and you get subharmonic oscillation. With a ramp of slope m a, the high-side turns off a bit earlier when the current error was positive, and the multiplier becomes minus m2 minus m a over m1 plus m a. If m a is at least half the inductor's falling slope, V out over L, then the magnitude stays under one for any duty cycle. If m a equals m2 the multiplier is zero, so a disturbance is gone in one cycle.

So it's needed whenever the converter can operate above 50 percent duty, which includes any buck whose input can drop below twice its output. Practically I'd use about half to one times m2, and I'd also use it below 50 percent, since it damps the sampling double pole at half the switching frequency.

The trade-off is that too much ramp makes the inner current loop less dominant, so the converter behaves more like voltage mode, and the peak current limit gets lower at high duty cycle, since the ramp eats into the threshold. Many ICs have the ramp built in, tied to a minimum inductor value, so I check the datasheet."
:::

::: technical
**Mechanism.** The comparator trips when the sensed current $i_L+m_at$ reaches $I_c$ (equivalently $i_L$ reaches $I_c-m_at$, a falling threshold). With $t_{on,n}=(I_c-I_n)/(m_1+m_a)$:

$$I_{n+1}=I_c-m_at_{on,n}-m_2(T-t_{on,n})\ \Rightarrow\ \alpha=-\frac{m_2-m_a}{m_1+m_a}$$

**Stability.** $|\alpha|<1\iff m_a>\dfrac{m_2-m_1}{2}$. Since $m_2-m_1=(V_{out}-(V_{in}-V_{out}))/L=(2D-1)V_{in}/L$ this is $m_a>(2D-1)V_{in}/(2L)$. Over all $D<1$ the condition is met when $m_a\ge m_2/2$ (the limit at $D\to1$ is $m_1\to0$).

**Design values.** $m_a=m_2$ gives $\alpha=0$ and sampling-pole $Q_p=2/\pi=0.64$ for any $D$. $m_a=0.5m_2$ gives $Q_p=1/[\pi(0.5-D+0.5D)]=1/[\pi(0.5-0.5D)]$, which is 3.2 at $D=0.8$ and diverges as $D\to1$.

**Worked example.** $V_{in}=5$ to 12 V, $V_{out}=3.3$ V, $L=4.7$ µH, $f_{sw}=500$ kHz ($T=2$ µs), $R_i=0.1$ V/A.

- $m_2=3.3/4.7\text{ µH}=0.70$ A/µs. At $V_{in}=5$ V, $D=0.66$, $m_1=0.36$ A/µs: $\alpha_0=-1.94$.
- Minimum ramp: $(m_2-m_1)/2=0.17$ A/µs.
- Rule $m_a=0.5m_2=0.35$ A/µs: $S_e=m_aR_i=35$ mV/µs, which over the full period reaches 70 mV. $\alpha=-(0.70-0.35)/(0.36+0.35)=-0.49$.
- Rule $m_a=m_2$: $S_e=70$ mV/µs, 140 mV over the period, $\alpha=0$.

**Side effects.**

- **Peak current limit**: the ramp lowers the effective threshold by $m_aDT$ at turn-off: for $m_a=m_2$ at $D=0.66$: $0.70\cdot0.66\cdot2=0.93$ A lower than at $D\to0$.
- **Loop behavior**: with large $m_a$ the current loop gain falls; in the limit the converter looks like voltage mode with a ramp, and the LC double pole re-emerges (Ridley's model: the low-frequency $Q$ of the LC pair grows with $m_c$).
- **Noise**: a smaller ramp relative to sense noise leaves more jitter; a larger ramp improves noise immunity.

> [!UNCERTAIN]
> Textbooks differ slightly on the recommended ramp: "at least $m_2/2$" ($\alpha$ bounded for all $D$) is common; some designs target $m_a=m_2$ for dead-beat response, and some vendors specify the ramp as a fraction of the "downslope at the worst case". Use the datasheet equation for a specific controller.
:::

::: long
"Slope compensation is a ramp signal, synchronized with the clock, that is added to the sensed inductor current before it goes to the comparator in a fixed-frequency peak current-mode converter. Or, equivalently, you subtract it from the current command. Either way, the threshold that the inductor current has to hit gets lower as the on-time goes on.

Why is it needed? From the previous analysis: with no ramp, a current error at the start of a cycle changes the on-time, and that changes the next start current by minus m2 over m1 times the error, where m1 is the rising slope and m2 the falling slope. That multiplier is D over one minus D, so above 50 percent duty it's greater than one and you get subharmonic oscillation. With the ramp, a start current that's too high makes the comparator trip even earlier, so the on-time changes more, and that reduces the error propagated: the multiplier becomes minus m2 minus m a over m1 plus m a.

How much do I need? The condition for stability is m a greater than half of m2 minus m1. At worst, as the duty cycle approaches one, m1 goes to zero, so a ramp of half of m2 covers all duty cycles. If I set m a equal to m2 the multiplier is exactly zero, a deadbeat response. I'd typically pick between a half and one times m2, and I'd use it below 50 percent too, because it damps the sampling double pole at half the switching frequency.

A worked example: 5 to 12 V in, 3.3 V out, 4.7 microhenries, 500 kHz. The down-slope is 0.70 amps per microsecond. At 5 V in, the duty cycle is 66 percent and the multiplier is minus 1.94 without a ramp. A ramp of 0.35 amps per microsecond, which with a 0.1 volt per amp sense gain is 35 millivolts per microsecond, brings it to minus 0.49. A ramp of 0.70 brings it to zero.

The costs: too much ramp reduces the influence of the inner current loop, so the converter behaves more like voltage mode, with the LC double pole reappearing, and the peak current limit drops with duty cycle because the ramp eats into the threshold. In that example 0.93 amps of limit disappears at 66 percent duty. And since many ICs have a fixed internal ramp, there's a minimum inductance requirement so the ramp is at least half of V out over L."
:::

::: terms
- **Slope compensation**: synchronous ramp added to sensed current (or subtracted from the command).
- **$m_a$ / $S_e$**: ramp slope in A/µs, or in V/µs after multiplying by $R_i$.
- **Dead-beat**: $\alpha=0$; error eliminated in one cycle.
- **$m_c$**: $1+m_a/m_1$, the compensation factor in Ridley's model.
- **Sampling double pole**: pole pair at $f_{sw}/2$ with quality factor $Q_p$.
- **Peak current limit**: maximum allowed peak inductor current.
- **Internal ramp**: fixed on-chip compensation tied to a minimum $L$.
- **Current-sense gain $R_i$**: V/A.
:::

::: exceptional
**An average answer** says "a ramp added to prevent oscillation above 50% duty".

**An exceptional answer**:
- Shows how the ramp changes the multiplier to $-(m_2-m_a)/(m_1+m_a)$ and derives $m_a>(m_2-m_1)/2$.
- Gives design values ($0.5m_2$ covers all $D$, $m_2$ is dead-beat) and converts to V/µs using $R_i$.
- Mentions $Q_p$ damping, so the ramp is useful below 50% as well.
- Lists the side effects: lower current limit versus duty, drift toward voltage mode, reduced current-loop gain.
- Knows ICs have fixed internal ramps, hence minimum inductance in datasheets.
- Mentions alternatives: lower duty, valley mode (mirror), COT, or voltage mode.
:::

::: mistakes
- **Adding the ramp to the output voltage.** It's added to the current-sense signal (or subtracted from the command).
- **Saying the ramp is needed only above 50%.** It's required for stability only above 50%, but it also damps $Q_p$ at lower duty.
- **Using too much ramp "to be safe".** It degrades current-loop dominance and the current limit accuracy.
- **Ignoring $L$.** A smaller $L$ increases $m_2$; a fixed ramp may no longer reach $m_2/2$.
- **Using the minimum value as the design value.** At exactly $(m_2-m_1)/2$ the multiplier magnitude is 1 at that duty, marginal. Add margin.
- **Forgetting valley mode is mirrored.** The ramp is needed for $D<0.5$ there.
:::

::: deep
## What the ramp does geometrically

Without compensation the comparator threshold is flat at $I_c$: the inductor current hits it at a rising slope $m_1$. With compensation the threshold is $I_c-m_at$, a falling line, so the intersection moves to an earlier time when the current started high, and a later time when it started low. The *size* of the on-time response to a start-current error becomes $\delta/(m_1+m_a)$ instead of $\delta/m_1$: the same perturbation causes a smaller on-time change, which means a smaller change in the off-time, and so a smaller error next cycle. Also, the amplitude change on the falling side is $(m_2-m_a)$ because the threshold itself fell by $m_a\Delta t$. Together: $\alpha=-(m_2-m_a)/(m_1+m_a)$.

## Sampling pole and damping

Ridley's model gives a double pole at $f_{sw}/2$:

$$Q_p=\frac{1}{\pi(m_cD'-0.5)}\ \Rightarrow\ \text{with }m_a=km_2:\ Q_p=\frac{1}{\pi(0.5-D+kD)}$$

## Sizing it in practice

1. Find the worst case $m_2=V_{out}/L$ (use the minimum $L$ including tolerance and saturation).
2. Choose $m_a$ between $0.5m_2$ and $m_2$. For the example: 0.35 to 0.70 A/µs.
3. Convert to the controller's units: $S_e=m_aR_i$. With $R_i=0.1$ V/A: 35 to 70 mV/µs, which is 70 to 140 mV across a 2 µs period.
4. Check the current limit: the peak limit at turn-off is reduced by $m_aDT$ (0.46 to 0.93 A at $D=0.66$).
5. Check $\alpha$ and $Q_p$ at minimum $V_{in}$ (maximum $D$).
6. Verify on the scope: no alternating pulse widths at $V_{in(min)}$, full load, and across a $V_{in}$ sweep.

For ICs with a fixed internal ramp, the datasheet gives a minimum inductance: $L\ge V_{out}/(2m_a)$ ensures $m_a\ge m_2/2$.

## Costs of too much ramp

- **Voltage-mode-like behavior**: as $m_a\gg m_1$ the comparator threshold is dominated by the ramp, $d\approx V_c/(\text{ramp amplitude})$, so the converter reverts to voltage mode, with the LC double pole and no inherent line rejection.
- **Current limit varies with duty**: $I_{pk,limit}=I_{lim}-m_aDT$. At high $D$ the allowed current falls.
- **Lower current-loop gain**: sensitivity to $V_c$ falls and the outer loop needs more gain.

## Other ways to avoid the problem

- Limit duty to below 50% (not usually possible for wide-input).
- Valley current mode for low duty, ripple-based (COT) or voltage mode for others ([[q0251]]).
- A ramp that scales with $V_{out}$ so it tracks $m_2$ (adaptive internal ramp).
- Digital controllers that compute the correction.

## Dead-beat is forgiving: sensitivity to tolerance

Setting $m_a=m_2$ looks fragile ("what if $L$ is not exactly 4.7 µH?"), but the multiplier $\alpha=-(m_2-m_a)/(m_1+m_a)$ has a numerator that is small when $m_a\approx m_2$, so the result is insensitive. Fix the ramp at the nominal value $m_a=0.702$ A/µs (designed for $L=4.7$ µH, $V_{out}=3.3$ V) and let the inductance change:

| $L$ | $\alpha$ at $V_{in}=5$ V | at 8 V | at 12 V |
|---|---|---|---|
| 3.29 µH (−30%, saturating) | −0.25 | −0.14 | −0.09 |
| 3.76 µH (−20%) | −0.15 | −0.09 | −0.06 |
| 4.70 µH (nominal) | 0.00 | 0.00 | 0.00 |
| 5.64 µH (+20%) | +0.12 | +0.08 | +0.05 |

The worst case in the whole table is a quarter of the way to instability. The margin protection is the reason to design to $m_a\approx m_2$ with the *minimum* inductance in mind. Contrast this with a minimum-ramp design ($m_a=0.17$ A/µs at 5 V): it is marginal by construction ($\alpha=-1$ at nominal), and a $-30\%$ inductance pushes it past $-1$ (to about $-1.2$), so it oscillates. Compare the table with the tolerance study in [[q0253]], which used the half-slope ramp.

## Picking $L$ for a part with a fixed ramp

When the ramp is built into the controller its slope is fixed, so the datasheet constrains the inductor instead. The requirement $m_a\ge m_2/2$ becomes

$$L\ge\frac{V_{out}}{2\,m_a}.$$

With an illustrative internal ramp equivalent to 0.35 A/µs (it depends on the sense gain: $m_a=S_e/R_i$), a 3.3 V output needs $L\ge3.3/0.70=4.7$ µH, and a 5 V output needs $L\ge7.1$ µH. These are the minimum *effective* values. If the inductor is rated ±20% and loses another 10% to 20% of its value at the peak current, the nominal value must be bigger: for the 5 V case $7.1/0.8=8.9$ µH before saturation is even considered. This is usually where an unexpected oscillation at low $V_{in}$ comes from: a part that works with the evaluation board's 10 µH inductor is replaced by a smaller one to save cost.

> [!UNCERTAIN]
> The ramp slope inside a controller can vary by tens of percent over temperature and process, and some parts scale it with $V_{in}$ or switching frequency. The 0.35 A/µs figure is a worked-example number, not a typical value for any particular device.

## Where the ramp comes from in silicon

An on-chip ramp generator is a current source charging a small capacitor that is reset by every clock edge: $S_e=I_{ramp}/C_{ramp}$. A ramp of 35 mV/µs on a 10 pF capacitor needs only $I=C\,dV/dt=10\text{ pF}\times35\ \text{mV/µs}=0.35$ µA, which is easy to generate but also easy to disturb with noise coupling or leakage. For a part with an external ramp resistor or capacitor, the pin is a high-impedance node: keep it short and away from the switch node, and place the capacitor close to the pin. Because the ramp resets every cycle, it also starts from zero at the beginning of a short on-time, which is why the current-limit penalty is small at low duty cycle.

## The current-limit cost, quantified

The ramp lowers the actual peak current by $m_aD T$ at turn-off. For the 0.35 A/µs ramp at 500 kHz:

| $D$ | Reduction of peak limit |
|---|---|
| 0.10 | 70 mA |
| 0.30 | 210 mA |
| 0.50 | 350 mA |
| 0.66 | 462 mA |
| 0.90 | 630 mA |

If the nominal limit is 5 A, a unit that trips at 5.0 A at low duty cycle will trip at about 4.5 A in dropout. For a design that must deliver 4.8 A at the minimum input voltage, the limit setting must account for the reduction at high duty, or the converter folds back at exactly the operating point where the battery is weakest. Some controllers add a duty-dependent offset to flatten this, but check the datasheet's limit-versus-duty curve.

## Verifying the ramp on the bench

The multiplier $\alpha$ can be measured directly. Inject a small step on the control voltage (or a small amplitude change on a load) and capture the inductor current (or the switch-node pulse width) over the next 10 cycles. Compute the ratio of consecutive errors in the alternating pulse widths: it should match $-(m_2-m_a)/(m_1+m_a)$ at that duty cycle. For the 5 V in, 3.3 V out example with the 0.35 A/µs ramp the prediction is $-0.49$, so a 100 ns error becomes about $-49$ ns, then $+24$ ns, then $-12$ ns, about a quarter of the original after two cycles. A ratio near $-1$ says the ramp is too small or the inductance is lower than assumed, and a ratio near zero says it is close to dead-beat. Do the measurement at the lowest $V_{in}$ in the specification, with full load, with the lowest-inductance part, and at high temperature, since all three raise $|\alpha|$.

## When to refuse slope compensation altogether

If the converter's $V_{in}/V_{out}$ range is such that $D$ never exceeds about 0.4, slope compensation is optional for stability, but the damping argument still favors a small ramp ($m_a\approx0.5m_2$ gives $Q_p=1.6$ at $D=0.6$ but only about 0.9 at $D=0.3$). When noise immunity at short on-times is the main concern (very small $D$ with blanking), valley current mode or COT often avoids both the ramp and the blanking problem ([[q0251]]). Choosing the topology instead of tuning the ramp is a valid answer when the interviewer asks for alternatives.
:::

::: applications
- **Wide-input bucks** (for example 4.5 V to 60 V in) where the duty can exceed 50% at the low end.
- **Battery-powered converters** that run near dropout, with $D\to0.9$ or more.
- **Boost and buck-boost converters** in peak current mode, which need it for $D>0.5$ in the same way (with their own slopes).
- **IC selection**: datasheet minimum inductance tied to internal ramp.
- **Power factor correction and LED drivers** with current-mode control.
:::

::: assumptions
- **Fixed-frequency trailing-edge peak current mode**, CCM; the ramp starts at the clock.
- **Linear ramp added to the current signal** (or subtracted from the command).
- **Ideal slopes**; real inductors saturate (higher $m_1$, $m_2$) and tolerances shift $L$ by ±20% or more.
- **$R_i$ = 0.1 V/A** is illustrative.
- For valley current mode the same applies with $D\to1-D$.
:::

::: followups
### What is the minimum ramp slope for stability at a given $D$?
$m_a>(m_2-m_1)/2=(2D-1)V_{in}/(2L)$. For $V_{in}=5$ V, $D=0.66$, $L=4.7$ µH: $0.32\cdot5/(9.4\text{ µH})=0.17$ A/µs. For $D\le0.5$ no ramp is needed for stability, but it still helps damping.

### Why does too much slope compensation hurt?
The comparator then trips mostly on the ramp, not the current, so the converter looks like voltage mode: the LC resonance comes back and line rejection is lost. The peak-current limit also drops with duty cycle by $m_aDT$, and the current-loop gain falls.

### How do you add slope compensation physically?
Add a clock-synchronized sawtooth voltage to the sensed-current voltage (or subtract it from the error amplifier output) before the PWM comparator. In an IC it comes from a current charging an internal capacitor each cycle, often with an external resistor or capacitor to adjust the slope. Digital controllers add the ramp numerically.

### Does it matter for DCM?
No for stability: in DCM the current returns to zero each cycle so there is no cycle-to-cycle memory. The ramp still affects the comparator threshold and current limit slightly.

### Scenario: a datasheet says the internal ramp requires $L\ge10$ µH for 5 V out. You want to use 4.7 µH. What happens?
At 10 µH and 5 V out, $m_2=0.5$ A/µs and the internal ramp is presumably sized at about $0.5m_2=0.25$ A/µs. With 4.7 µH, $m_2=5/4.7=1.06$ A/µs, so the same fixed ramp is only 0.24 of $m_2$, below the 0.5 minimum. At $V_{in}=7$ V ($D=0.71$, $m_1=0.43$ A/µs), $\alpha=-(1.06-0.25)/(0.43+0.25)=-1.20$, so it oscillates. Use the recommended inductor, a part with adjustable ramp, or limit the maximum duty cycle.
