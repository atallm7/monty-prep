::: testing
Whether you can state the ideal op-amp model **and use it**. Interviewers don't want a recited list; they want to see that you know:

1. The three rules: **infinite input impedance** (no current into the inputs), **zero output impedance** (the output is an ideal voltage source), and **infinite gain**, which under **negative feedback** forces $V_+ = V_-$ (the virtual short).
2. That the virtual short is a *consequence* of feedback and high gain, valid only when the output is not saturated.
3. How to apply them to a circuit with just KCL and Ohm's law.
4. How real parts deviate from each rule.
:::

::: why
These rules turn op-amp circuits from differential-equation problems into a handful of lines of algebra. With them you can analyze a summing amplifier, an integrator, a filter or an instrumentation amplifier in your head. Practically, they also tell you where reality bites: input bias current is rule 1 failing, output droop under load is rule 2 failing, and gain error and bandwidth loss are rule 3 failing. Interviewers use the question to see if you can both calculate with the ideal model and say when it breaks, which is the core skill of analog design.
:::

::: concepts
- **Input impedance**: how much current an input draws. Ideal infinite, so $I_+ = I_- = 0$. See [[q0001]].
- **Output impedance**: the series resistance of the output. Ideal zero, so $V_{out}$ doesn't sag with load.
- **Open-loop gain $A$**: ideal infinite. See [[q0126]].
- **Negative feedback**: the loop that makes high gain useful and forces the inputs together. See [[q0121]].
- **Virtual short**: $V_+ = V_-$ with no current between them. A virtual ground if $V_+$ is grounded.
- **KCL**: the tool you apply at the inverting node, with $I_- = 0$. See [[q0004]].
:::

::: answer
"The three rules for an ideal op-amp are these. One, the inputs have infinite impedance, so no current flows into either the inverting or non-inverting terminal. Two, the output has zero impedance, so it acts like an ideal voltage source and can supply whatever current the load wants without the voltage sagging. Three, the open-loop gain is infinite.

The third one is what gives you the famous virtual short. With negative feedback, the output will do whatever it takes to make the difference between the inputs go to zero, because if there were any difference at all, infinite gain would produce infinite output. So you can treat the two inputs as being at the same voltage, even though they aren't connected.

To use it, say I want an inverting amplifier. The plus input is grounded, so the minus input is also at zero volts, a virtual ground. The current into the input resistor is $V_{in}/R_{in}$. No current goes into the op-amp, so all of it goes through the feedback resistor, and the output is $-I R_f$, so the gain is $-R_f/R_{in}$.

Of course real parts only approximate these: the gain is more like a hundred thousand, bias currents are not zero, and the output impedance is a few tens of ohms open loop."
:::

::: technical
**Ideal model.**

1. $Z_{in}\to\infty\Rightarrow I_+ = I_- = 0$.
2. $Z_{out}\to 0\Rightarrow V_{out}$ is independent of load current (within the rails).
3. $A\to\infty$. With negative feedback and the output in its linear range: $V_+ - V_- = V_{out}/A\to 0\Rightarrow V_+ = V_-$.

(Often also: infinite bandwidth, infinite CMRR and PSRR, zero offset, zero noise, infinite slew rate.)

**Applying the rules (inverting amplifier).** $V_+ = 0\Rightarrow V_- = 0$. KCL at the inverting node: $\frac{V_{in}-0}{R_{in}} = \frac{0 - V_{out}}{R_f}\Rightarrow V_{out} = -\frac{R_f}{R_{in}}V_{in}$. Non-inverting: $V_- = V_{out}\frac{R_g}{R_g+R_f} = V_{in}\Rightarrow V_{out} = (1 + R_f/R_g)V_{in}$.

**Where the real part deviates.**
- *Rule 1*: input bias current $I_B$ from pA (JFET/CMOS) to hundreds of nA (bipolar); differential input resistance of order MΩ to TΩ depending on input type. Error: $I_B R_{source}$.
- *Rule 2*: open-loop $Z_o\sim$ tens of Ω; closed loop $Z_{out}\approx Z_o/(1+A\beta)$, which rises with frequency as $A$ falls. For $Z_o = 75\ \Omega$, $A_0 = 10^5$ and $\beta = 0.1$ it is 7.5 mΩ at DC, but about 7.5 Ω at 10 kHz for a 1 MHz GBW part.
- *Rule 3*: the residual $V_+ - V_- = V_{out}/A$. At $V_{out} = 5$ V and $A = 10^5$ that is 50 µV. It also falls with frequency.

**Conditions.** The virtual short requires **negative feedback** and an output that is **not saturated**. In open loop or with positive feedback the rule fails.
:::

::: long
"The ideal op-amp model has three properties. First, infinite input impedance: no current flows into either input terminal. Second, zero output impedance: the output behaves like an ideal voltage source, so its voltage doesn't change with the load. Third, infinite open-loop gain.

That third one is what makes op-amp circuits so easy to analyze. If the op-amp has negative feedback and its output isn't stuck at a rail, then the output is finite, and a finite output divided by an infinite gain means the voltage difference between the inputs has to be zero. So the two inputs sit at the same voltage. We call it a virtual short, because the voltages are the same but no current flows between them, which is different from a real short.

Using it is a two-step recipe: set $V_-$ equal to $V_+$, then write KCL at the inverting node knowing no current goes into the op-amp. For the inverting amplifier, the plus input is at ground, so the minus node is at zero, a virtual ground. The input resistor has $V_{in}/R_{in}$ flowing through it. That current can't go into the op-amp, so it all flows through the feedback resistor, producing a drop of $I R_f$, so $V_{out} = -(R_f/R_{in})V_{in}$. For the non-inverting amplifier the minus node is a divider of the output, and the virtual short says that divider equals $V_{in}$, giving $1 + R_f/R_g$.

In a real part, none of these are perfect. Input bias current means the input draws nanoamps or picoamps, so large source resistances create offsets. Output impedance is tens of ohms open loop, and feedback reduces it by the loop gain, but only at low frequency. And the gain is more like $10^5$ and falls with frequency, so the virtual short is only good where the loop gain is large. And I'd always add that all of this assumes the output hasn't hit a rail."
:::

::: terms
- **Ideal op-amp**: a model with infinite gain, infinite input impedance, zero output impedance (and often infinite bandwidth).
- **Virtual short**: $V_+ = V_-$ enforced by negative feedback, with no current between the inputs.
- **Virtual ground**: a virtual short where the + input is grounded, so the − node is at 0 V.
- **Input bias current ($I_B$)**: real-world violation of rule 1.
- **Output impedance ($Z_{out}$)**: ideally 0; closed-loop value is $Z_o/(1+A\beta)$.
- **Loop gain ($A\beta$)**: how far from ideal you are: error $\approx 1/(A\beta)$.
- **Summing junction**: the inverting node, where currents add to zero under rule 1.
- **Saturation**: output at a rail; the virtual short no longer holds.
:::

::: exceptional
**An average answer** recites the three rules (or the two "golden rules") as facts.

**An exceptional answer**:
- States the rules *and the conditions*: the virtual short needs **negative feedback** and an **unsaturated output**.
- Derives the virtual short from "finite output over infinite gain" so it is not an axiom.
- Immediately **applies** the rules to the inverting amplifier in four lines (virtual ground, KCL, $V_{out} = -R_f V_{in}/R_{in}$).
- Names how each rule fails in a real part and gives an order of magnitude (e.g. $V_d = V_{out}/A\approx 50$ µV, bias currents pA to nA, $Z_o\sim$ tens of Ω).
- Mentions that the "three rules" vary by textbook: some list "infinite bandwidth" or the "golden rules" form.
:::

::: mistakes
- **Treating the virtual short as a real wire.** No current flows between the inputs. If you short them, the circuit changes.
- **Applying the virtual short without negative feedback**, for example to a comparator or Schmitt trigger. There, $V_+\ne V_-$.
- **Applying it with a saturated output.** If $V_{out}$ is at a rail, the loop is broken and the inputs can differ by volts.
- **Saying the op-amp output current is infinite.** The output is an ideal *voltage* source within limits. Real parts are limited by the rails and a short-circuit current of typically 10s of mA.
- **Believing "no current into the input" means the input draws exactly zero.** The bias current is small but not zero, and it creates offsets with big resistors.
- **Mixing up which rule gives what.** The virtual short comes from infinite *gain* with feedback, not from infinite input impedance. The input impedance gives $I = 0$.
:::

::: deep
## Where the three rules come from

Start with the real equation of an op-amp, $V_{out} = A(V_+ - V_-)$, and let it get ideal.

**Rule 3: infinite gain.** If $A\to\infty$ and $V_{out}$ is finite, then $V_+ - V_- = V_{out}/A\to 0$. For a finite $A$, the residual is small but not zero: with $V_{out} = 5$ V and $A = 10^5$, $V_d = 50$ µV. Why must $V_{out}$ be finite? Because there is *negative feedback*: if the output went up, the feedback would pull the inverting input up and reduce $V_d$ until balance. The stable solution of the loop is where $V_d\approx 0$.

**Rule 1: infinite input impedance.** The inputs are the gates or bases of a differential pair. A MOS or JFET gate draws almost nothing (pA or less), and a bipolar base draws $I_C/\beta$ (nA to µA). In the ideal model, we set it to zero. That is what allows you to write KCL with the op-amp's input terminals omitted.

**Rule 2: zero output impedance.** The output stage is an emitter/source follower with a small output resistance. With negative feedback the *closed-loop* output resistance is the open-loop value divided by $1+A\beta$.

## Using the rules: the recipe

1. Identify the feedback path (is it negative?).
2. Set $V_- = V_+$.
3. Write KCL at the inverting node with $I_- = 0$.
4. Solve for $V_{out}$. Check that the answer is inside the rails.

Result:
$$I = \frac{V_{in}-0}{R_{in}},\qquad V_{out} = 0 - I R_f = -\frac{R_f}{R_{in}}V_{in}$$

For $R_{in} = 10$ kΩ and $R_f = 100$ kΩ, a 0.5 V input gives $-5$ V.

For the non-inverting amplifier: $V_- = V_{out}\frac{R_g}{R_g+R_f}$ and the virtual short says $V_- = V_{in}$, so $V_{out} = V_{in}\left(1 + \frac{R_f}{R_g}\right)$.

## What the virtual short physically means

It is not magic: the op-amp is a controller. Its output moves until the inverting input matches the non-inverting input. Think of it as a very high-gain servo with a fixed set point of $V_+$. The inverting input is the measurement, the feedback network turns the output into a measurement, and the output is the control effort. It "wants" zero error, and with 100 dB of gain the leftover error is a few µV.

## How good is each rule in a real part?

| Rule | Real behavior | Typical orders of magnitude |
|---|---|---|
| Infinite $Z_{in}$ | Bias current $I_B$ and offset current | pA or less (CMOS/JFET) to hundreds of nA (bipolar) |
| Zero $Z_{out}$ | $Z_o/(1+A\beta)$, rises with frequency | $Z_o$ tens of Ω open loop; mΩ closed loop at DC |
| Infinite $A$ | $V_d = V_{out}/A$ | $A_0$ of $10^5$ to $10^6$ at DC, falling 20 dB/dec |

> [!UNCERTAIN]
> These are typical values only. Input impedance, bias current and open-loop output impedance vary by orders of magnitude between op-amp families (JFET, CMOS, bipolar, zero-drift). Check the datasheet.

## When the rules do not apply

- **Positive feedback or no feedback** ([[q0127]]): $V_+\neq V_-$ by design.
- **Output saturated**: the loop is open; the inputs can differ by volts.
- **High frequency**: loop gain falls; the virtual short degrades above the closed-loop bandwidth.
- **Precision work**: offset voltage, bias current and finite gain give the error budget.
:::

::: applications
- **Inverting and non-inverting amplifiers**, the first things you analyze with the rules ([[q0125]]).
- **Summing amplifiers** (audio mixers, DAC output stages): each input resistor feeds the virtual ground and the currents add.
- **Integrators and differentiators**: the virtual ground makes $i = C\,dV/dt$ through the capacitor.
- **Transimpedance amplifiers**: a photodiode's current is forced into the virtual ground and out through $R_f$, giving $V_{out} = -I_{ph}R_f$.
- **Precision rectifiers**: the op-amp's gain cancels the diode drop inside the loop.
- **Voltage followers**: rule 1 (high $Z_{in}$) and rule 2 (low $Z_{out}$) together make an impedance buffer.
:::

::: assumptions
The three-rule list I gave is the most common one for the *ideal* model. Other textbooks (for example the "golden rules" in Horowitz & Hill) state it as two rules: (1) the output does whatever is necessary to make the voltage difference between the inputs zero, and (2) the inputs draw no current. These contain the same information. Some add infinite bandwidth, infinite CMRR and zero offset.

I assumed a voltage-feedback op-amp with negative feedback and linear operation. A **current-feedback amplifier** has a low-impedance inverting input, so rule 1 fails there by design. In **comparators** the virtual short doesn't apply. And for **high-precision or high-frequency** work, you must use the finite-gain model: closed-loop gain $= \frac{A}{1+A\beta}$.
:::

::: followups
### Why is it called a "virtual" short rather than a real short?
A real short has the same voltage on both sides *and* carries any current. The virtual short only forces the same voltage. No current flows between the inputs because of rule 1 (infinite input impedance). If you replaced it with a real wire, you'd change the circuit: the output could no longer move to maintain the balance.

### Use the rules to find the gain of a non-inverting amplifier with $R_f = 90$ kΩ, $R_g = 10$ kΩ.
The virtual short sets $V_- = V_{in}$. The divider gives $V_- = V_{out}\cdot R_g/(R_g + R_f) = V_{out}/10$. So $V_{out} = 10V_{in}$, gain $= 1 + 90/10 = 10$. No current goes into the op-amp's inputs, so the divider is unloaded.

### What is the input resistance of the inverting amplifier, and of the non-inverting amplifier, using the rules?
Inverting: the − node is a virtual ground, so the input source sees $R_{in}$ to ground: $Z_{in} = R_{in}$. Non-inverting: the signal goes straight into the op-amp's + input, so $Z_{in}$ is the op-amp's own input impedance, very large (with feedback it is often multiplied further). That's one reason the non-inverting form is preferred for high-impedance sources, see [[q0128]].

### With an inverting gain of $-10$, $R_{in} = 10$ kΩ, and the op-amp's $A = 10^5$: how big is the virtual-short error when $V_{out} = -5$ V?
$V_d = |V_{out}|/A = 5/10^5 = 50$ µV. It amounts to 0.001% of the output, which is negligible for most uses but significant for precision DC amplifiers with µV-level offsets.

### Harder: the rules say the inverting input has zero current. Yet a circuit with a 10 MΩ feedback resistor shows an output drift of tens of mV. Why?
The input bias current isn't zero. A bipolar op-amp with $I_B = 50$ nA flowing through 10 MΩ gives 0.5 V, and even a 1 nA offset current gives 10 mV. This violates rule 1 in a way that matters at high resistor values. Fixes: a JFET/CMOS-input part (fA to pA), a bias-current-compensating resistor on the + input, or lower resistor values.
:::

::: interpretations
Sources differ on "the three rules". The set I gave (infinite $Z_{in}$, zero $Z_{out}$, infinite gain) is the common textbook list for the **ideal op-amp model**. Another common version is the **two golden rules** (zero input current; output makes $V_+ = V_-$), plus sometimes "infinite bandwidth" as a third. If the interviewer says "three rules" and only means the two golden rules plus the gain assumption, the content is the same; state both so you're covered. See [[q0125]] for using them.
:::

- States infinite input impedance, so no current into the inputs :: This is rule 1 and is what lets you ignore the op-amp when writing KCL.
- States zero output impedance (ideal voltage source) :: Rule 2 is the one most often forgotten; it explains why a buffer can drive a load.
- States infinite gain and derives $V_+ = V_-$ under negative feedback :: This is the key insight behind every op-amp analysis.
- Notes the conditions: negative feedback and no saturation :: Shows you won't misapply the virtual short to comparators.
