::: testing
Whether you can **draw both amplifiers correctly from memory and derive their gains** with the ideal rules from [[q0124]]. Checks:

1. Inverting: input through $R_{in}$ to the − node, feedback $R_f$ from output to the − node, + input grounded. Gain $-R_f/R_{in}$.
2. Non-inverting: signal on the + input, divider $R_f$/$R_g$ from output to ground tapped into the − input. Gain $1 + R_f/R_g$.
3. Where the sign and the "+1" come from, and the consequences: input impedance, minimum gain, bandwidth.
4. That you label the ground and the node names and note both loops are *negative* feedback.
:::

::: why
These two stages are the building blocks of nearly every op-amp circuit: sensor amplifiers, ADC front ends, filters, DAC output stages, signal conditioning of every type. Interview questions like "design an amplifier with gain 20 for a 10 kΩ source" or "why would you choose one over the other" come straight from here. If you can draw and derive both in a minute, you can derive summers, integrators, transimpedance amplifiers and active filters, which are the same two circuits with different feedback elements. See also [[q0012]] for basic op-amp circuit analysis and [[q0128]] for the preference between the two.
:::

::: concepts
- **Virtual short / virtual ground**: with negative feedback, $V_- = V_+$. See [[q0124]].
- **Voltage divider**: the non-inverting feedback network is a divider from the output. See [[q0008]].
- **KCL at the summing node**: the inverting circuit is a current-in = current-out argument.
- **Negative feedback**: both circuits return the output to the − pin. See [[q0122]].
- **Input impedance**: $R_{in}$ for inverting, very large for non-inverting.
- **Noise gain / closed-loop bandwidth**: $1 + R_f/R_{in}$ in both circuits, so $f_{-3dB}\approx GBW/(1+R_f/R_{in})$. See [[q0116]].
:::

::: answer
"For the inverting amplifier I draw an op-amp with the plus input tied to ground. The signal goes through an input resistor, $R_{in}$, to the minus input, and a feedback resistor, $R_f$, goes from the output back to the minus input. The minus node is a virtual ground, so the input current is $V_{in}/R_{in}$, all of it flows through $R_f$, and $V_{out} = -(R_f/R_{in})V_{in}$.

For the non-inverting amplifier, the signal goes straight into the plus input. From the output I run a resistor divider to ground, $R_f$ on top and $R_g$ on the bottom, and the midpoint goes to the minus input. The virtual short says the minus node equals $V_{in}$, and that node is $V_{out}R_g/(R_g+R_f)$, so $V_{out} = (1 + R_f/R_g)V_{in}$.

With $R_f = 100$ kΩ and 10 kΩ for the other resistor, the inverting amp gives minus 10 and the non-inverting amp gives plus 11. Differences: the inverting circuit's input impedance is just $R_{in}$, so it loads the source, while the non-inverting one has an extremely high input impedance. Non-inverting can't give a gain below 1 and inverting can. Both have the same bandwidth for the same $R_f/R_{in}$ ratio, since the loop gain is the same."
:::

::: technical
**Inverting amplifier.** $V_+ = 0$, $V_- = 0$ (virtual ground). KCL at the − node with $I_- = 0$:
$$\frac{V_{in}}{R_{in}} + \frac{V_{out}}{R_f} = 0\;\Rightarrow\;A_{CL} = -\frac{R_f}{R_{in}}$$
Input impedance $Z_{in} = R_{in}$. Output impedance $\approx 0$.

**Non-inverting amplifier.** $V_+ = V_{in}$, and $V_- = V_{out}\frac{R_g}{R_g+R_f}$:
$$A_{CL} = 1+\frac{R_f}{R_g}\;\ge 1$$
Input impedance is the op-amp's input impedance (typically $\gg$ MΩ, further raised by feedback) in parallel with the bias network. Setting $R_f = 0$ and removing $R_g$ gives the **unity-gain buffer** ($A = 1$).

**Finite open-loop gain.** With $\beta = R_g/(R_g+R_f)$ (non-inverting) and $A$ finite, $A_{CL} = \frac{A}{1+A\beta}$. For the inverting amp: $A_{CL} = -\frac{R_f}{R_{in}}\cdot\frac{1}{1 + (1+R_f/R_{in})/A}$. Both have noise gain $1 + R_f/R_{in}$.

**Bandwidth.** With a single-pole op-amp, $f_{-3dB}\approx GBW/(1+R_f/R_{in})$. For $R_f/R_{in} = 10$ and GBW = 1 MHz, that is 91 kHz for both circuits.

**Resistor errors.** 1% resistors in a gain-of-10 circuit can leave the gain anywhere from about −9.8 to −10.2 (inverting, worst case ±2%), or 10.8 to 11.2 (non-inverting).

**Practical:** DC bias path on both inputs; for the inverting amp with a source in front, $R_{in}$ includes the source resistance; match $R_+$ to $R_{in}\parallel R_f$ if bias currents matter.
:::

::: short
"Inverting: plus input to ground, signal through $R_{in}$ into the minus node, $R_f$ from the output back to that node. The minus node is a virtual ground, so gain is $-R_f/R_{in}$. Non-inverting: signal on the plus input, and $R_f$ and $R_g$ form a divider from output to ground feeding the minus input. The virtual short makes $V_{out}(R_g/(R_g+R_f)) = V_{in}$, so gain is $1 + R_f/R_g$. Inverting has input impedance $R_{in}$ and can attenuate; non-inverting has very high input impedance and gain of at least 1."
:::

::: long
"Let me do the inverting amplifier first. The op-amp's non-inverting input goes to ground. The signal source connects through a resistor $R_{in}$ to the inverting input, and a feedback resistor $R_f$ goes from the output to the inverting input. Because the plus pin is grounded and there's negative feedback, the inverting node sits at zero volts, the virtual ground. So the current from the source is $V_{in}/R_{in}$. No current goes into the op-amp, so all of it flows through $R_f$, and the output is $-I R_f$. That gives $V_{out} = -(R_f/R_{in})V_{in}$. With 100 k and 10 k that's a gain of minus 10.

The non-inverting amplifier: the signal goes right into the plus input. Then I need a feedback divider: $R_f$ from the output to the minus input and $R_g$ from the minus input to ground. Negative feedback makes the minus input equal $V_{in}$, and the minus input is $V_{out}\,R_g/(R_g + R_f)$, so $V_{out} = V_{in}(1 + R_f/R_g)$. With the same resistors, that's plus 11, not 10, because of the +1.

The differences matter in practice. The inverting circuit has an input impedance equal to $R_{in}$ because the virtual ground sits at one end of it, so it loads the source. The non-inverting circuit feeds the high-impedance plus pin, so it barely loads anything. The inverting one can attenuate, a gain of minus 0.5 for example, but the non-inverting one can't go below 1. And for bandwidth, both have the same noise gain, $1 + R_f/R_{in}$, so with a 1 MHz GBW op-amp and a gain setting of 10 you'd get about 90 kHz either way.

I'd double check the signs by tracing the feedback: both circuits send the output back to the minus input, so both are negative feedback."
:::

::: terms
- **Inverting amplifier**: gain $-R_f/R_{in}$; output 180° out of phase with the input.
- **Non-inverting amplifier**: gain $1 + R_f/R_g$; output in phase.
- **Voltage follower (buffer)**: non-inverting with gain 1; high input impedance, low output impedance.
- **Virtual ground**: the − node of the inverting amplifier, held at 0 V by feedback.
- **Summing node**: the − input node where currents add (zero net current).
- **Feedback factor $\beta$**: fraction of the output returned to the − input.
- **Noise gain**: $1 + R_f/R_{in}$ (or $1/\beta$); it determines bandwidth and the amplification of offsets and noise.
- **Closed-loop bandwidth**: roughly GBW divided by noise gain.
:::

::: exceptional
**An average answer** draws both circuits and quotes $-R_f/R_{in}$ and $1+R_f/R_g$.

**An exceptional answer**:
- Draws with **ground symbols, node labels and a dot at the feedback junction** and says out loud that both loops return to the − input.
- **Derives** each gain in two lines with the ideal rules, explaining where the minus sign and the "+1" come from.
- Compares them: input impedance ($R_{in}$ vs very high), minimum gain (inverting can attenuate), the same noise gain for the same ratio, and common-mode input range (the inverting circuit has none; the non-inverting circuit's inputs move with the signal).
- Gives a quick design example with real values and a resistor tolerance check.
- Notes DC bias paths and, for precision, equalizing source resistances to cancel bias-current offsets.
:::

::: mistakes
- **Gain of the non-inverting circuit as $R_f/R_g$** (forgetting +1). With equal resistors it is 2, not 1.
- **Grounding the wrong input** in the inverting amplifier (grounding the − pin kills the feedback).
- **Feeding back to the + input.** Positive feedback, so the output saturates. Check both loops end on the − pin.
- **Forgetting that the inverting circuit's input impedance is $R_{in}$**, then driving it from a high-impedance sensor. Gain error and offset result.
- **Trying to get a gain below 1 from the non-inverting circuit.** The minimum is 1 (a buffer). To attenuate, use the inverting configuration or a divider before a buffer.
- **Thinking "inverting" only applies to AC signals.** DC inverts too: $+1$ V in gives $-10$ V out for a gain of $-10$.
- **Ignoring the rails:** a gain of $-10$ with 2 V input needs $-20$ V of output swing; with ±12 V rails it clips.
:::

Figure: Plus input grounded, signal into the minus node through $R_{in}$, feedback $R_f$ from output to the minus node. The dot marks the summing node where $I_{in}$ meets $I_f$.

**Derivation.** Virtual short: $V_- = V_+ = 0$. KCL at the summing node: $I_{R_{in}} = I_{R_f}$ (nothing enters the op-amp).

$$\frac{V_{in}-0}{R_{in}} = \frac{0-V_{out}}{R_f}\;\Rightarrow\;\boxed{V_{out} = -\frac{R_f}{R_{in}}V_{in}}$$

The minus sign has an intuitive meaning: current flows in through $R_{in}$ toward the summing node. To keep that node at zero, the output must go *negative*, to pull the same current out through $R_f$.

**Derivation.** The virtual short says $V_- = V_{in}$. The divider gives $V_- = V_{out}\frac{R_g}{R_g+R_f}$. So

$$V_{out} = V_{in}\,\frac{R_g+R_f}{R_g} = \boxed{\left(1+\frac{R_f}{R_g}\right)V_{in}}$$

It is just the inverse of the divider ratio. If $R_f = 0$ (a wire) the gain is 1, which is the buffer.

## Side by side

| | Inverting | Non-inverting |
|---|---|---|
| Gain | $-R_f/R_{in}$ | $1 + R_f/R_g$ |
| Range of $\lvert$gain$\rvert$ | any positive value, including $<1$ | $\ge 1$ |
| Input impedance | $R_{in}$ | very high (op-amp input) |
| Inputs' voltage | both at the same fixed voltage (virtual ground) | both follow $V_{in}$ (common-mode swing) |
| Noise gain | $1 + R_f/R_{in}$ | $1 + R_f/R_g$ |
| Phase | 180° | 0° |

With $R_f = 100$ kΩ and $R_{in} = R_g = 10$ kΩ, the gains are $-10$ and $+11$, and the noise gain and the bandwidth are identical: $f_{-3dB}\approx 1\text{ MHz}/11\approx 91$ kHz.

## Choosing resistor values

The ratio sets the gain but the values matter too:
- **Too small** (e.g. $R_f = 1$ kΩ in total): loads the op-amp output and wastes current. A 5 V output into a 1 kΩ feedback network already needs 5 mA.
- **Too big** (MΩ values): bias current errors ($I_B R$), thermal noise ($\sqrt{4kTR}$), and a pole with input capacitance (just 1 pF of parasitic capacitance across 1 MΩ gives a corner near 160 kHz).
- A common middle ground is $R_f$ between 1 kΩ and 100 kΩ.
- **Source loading** in the inverting circuit: the source sees $R_{in}$ (plus any source resistance), so a 1 kΩ source resistance in series with $R_{in} = 10$ kΩ changes the gain to $-100/11\approx -9.09$ for $R_f = 100$ kΩ.

## Accuracy with real resistors

Resistor tolerance sets gain accuracy. With 1% resistors the worst case on a gain of 10 inverting is $R_f$ high and $R_{in}$ low: $-10.2$, or $-9.8$ the other way, ±2%. Non-inverting with 1% parts: 10.80 to 11.20. Using 0.1% parts, or a matched resistor network, reduces it to ±0.2%.

## What the loop looks like for each circuit

Both circuits have the same loop gain $A\beta$ with $\beta = R_g/(R_g+R_f)$ for non-inverting and $\beta = R_{in}/(R_{in}+R_f)$ for inverting. That is why bandwidth and stability are the same for the same resistor ratio: $A_{CL}$ changes, but the loop does not.

## Finite open-loop gain: the exact result and the size of the error

The ideal-op-amp derivations assume $A\to\infty$. Keeping $A$ finite, the output is $V_{out}=A(V_+-V_-)$, so the exact non-inverting gain is

$$A_{CL}=\frac{A}{1+A\beta},\qquad \beta=\frac{R_g}{R_g+R_f}$$

which approaches $1/\beta=1+R_f/R_g$ when $A\beta\gg1$. For the gain-of-11 circuit, $\beta=1/11$. With a DC open-loop gain of $A=10^5$ (100 dB) the exact gain is $10^5/(1+10^5/11)=10.9990$, an error of 0.009% from the ideal 11. An op-amp with a DC gain of only $10^3$ would give $1000/(1+1000/11)=10.89$, an error of 1%. Gain error from finite $A$ is $\approx1/(A\beta)=11/A$, which says the same thing: the larger the closed-loop gain, the less loop gain remains to correct errors.

With a single-pole op-amp, $A(s)=\omega_t/s$ where $\omega_t=2\pi\cdot GBW$. Substituting gives a first-order closed-loop response with $f_{-3dB}=\beta\,GBW$, which is where the $GBW/(1+R_f/R_{in})$ rule comes from. At that frequency the loop gain has fallen to 1, so the *accurate* bandwidth is smaller. The magnitude of a first-order response is $1/\sqrt{1+(f/f_c)^2}$, which is within 1% of the passband value up to $f\approx0.14f_c$ (about 13 kHz for $f_c=91$ kHz), but by then the phase has already shifted by $\arctan(0.14)=8^\circ$. The complex gain error is $1/(A\beta)=f/f_c$, so keeping the phase error under a degree means staying below roughly $f_c/57$, about 1.6 kHz here.

## Worked example: DC errors at the output

Take the non-inverting gain-of-11 circuit with $R_f=100\ \text{k}\Omega$, $R_g=10\ \text{k}\Omega$, and an op-amp with input offset voltage $V_{OS}=1$ mV, input bias current $I_B=50$ nA and offset current $I_{OS}=5$ nA.

- **Offset voltage** is amplified by the noise gain: $1\ \text{mV}\times11=11$ mV at the output.
- **Bias current** flows out of (or into) each input pin. With the + input tied directly to a zero-impedance source, only the − pin's current matters, and it flows through the feedback network, giving $I_B R_f=50\ \text{nA}\times100\ \text{k}\Omega=5$ mV. This adds to or subtracts from the offset, so the worst case total is $11+5=16$ mV.
- **Compensation.** If you place a resistor on the + input equal to $R_f\parallel R_g=9.09\ \text{k}\Omega$ (for the inverting circuit, put it in series with the grounded + pin), the two bias currents produce nearly equal voltages and cancel. What remains is $I_{OS}R_f=5\ \text{nA}\times100\ \text{k}\Omega=0.5$ mV. The total is now about 11.5 mV, dominated by $V_{OS}$.

A gain of $+11$ on a 100 mV full-scale sensor signal gives 1.1 V output, so 11.5 mV of output error is 1% of full scale, not acceptable for a precision application. That is why precision designs choose low-offset parts, trim, or use chopper-stabilized amplifiers, and why the source resistance seen at the + input (including the sensor) must be accounted for.

## Worked example: why a large-value feedback network rings

Real inputs have capacitance to ground: op-amp input capacitance plus pad and trace, say 10 pF at the − node. That capacitor forms a pole in the feedback path with the resistance seen at that node. With $R_{in}=R_g=1\ \text{M}\Omega$, $R_f=10\ \text{M}\Omega$ (noise gain 11) and $GBW=1$ MHz, the capacitor adds a zero to the noise gain at $1/[2\pi(R_{in}\parallel R_f)C_{in}]=1/[2\pi(0.91\ \text{M}\Omega)(10\ \text{pF})]=17.5$ kHz. That is well below the 91 kHz where the loop gain would normally cross unity, so the noise gain keeps rising and the crossover is pushed to about 38 kHz in a numerical evaluation of the loop, with a phase margin of only about 25°. The step response overshoots and rings, and the closed-loop response shows a peak.

The cure is a small capacitor $C_f$ across $R_f$ that restores the divider ratio at high frequency. The exact cancellation condition is $R_fC_f=R_{in}C_{in}$, which here gives $C_f=1\ \text{pF}$ and makes the feedback factor constant with frequency (the same idea as a compensated scope probe). Evaluating the loop numerically: $C_f=0$ gives about 25° of phase margin, $C_f=0.4$ pF gives about 70°, and $C_f=1$ pF gives 90°, with the crossover back at 91 kHz. A common design rule of thumb, $C_f\approx\sqrt{C_{in}/(2\pi R_f GBW)}=0.4$ pF here, sits in between and gives a comfortable margin without slowing the response much.

With the original 10 kΩ and 100 kΩ resistors the zero is at 1.75 MHz, well above the crossover, so the same 10 pF barely matters: the phase margin is about 87°. This is why the "choose R no larger than necessary" advice is not just about noise.

> [!UNCERTAIN]
> Input capacitance and the open-loop response of a real amplifier (second poles, output impedance, load capacitance) vary by part, so these phase-margin numbers use an idealized single-pole op-amp and are illustrative. Check the datasheet's input capacitance and any recommended feedback-capacitor guidance.

## How to verify it on the bench

1. **DC gain.** Apply a known DC voltage and measure the output with a good meter. Compare with the calculated value using the *measured* resistor values, not the labels. With 1% parts the measured gain should be within the tolerance band computed above.
2. **Offset.** Ground the input (with the source resistance you will really have) and measure the output. It should match $V_{OS}\times$ noise gain plus the bias-current term. A drifting reading suggests thermal EMF, bias current changing with temperature, or an input that is not truly grounded.
3. **Bandwidth.** Sweep a small sine and find where the output falls to 70.7%. Compare with $GBW/(1+R_f/R_{in})$ using the datasheet's GBW. A lower value usually means the signal is too large and the output is slew-limited.
4. **Stability.** Apply a small square wave (small enough to avoid slew limiting) and look for overshoot and ringing. Overshoot above about 10% indicates a phase margin that has dropped, often from input or load capacitance. Add the feedback capacitor and confirm the ringing disappears.
5. **Input impedance.** For the inverting circuit, put a known series resistor ahead of $R_{in}$ and measure the gain change; it should match a simple divider against $R_{in}$.

::: applications
- **Sensor conditioning**: a strain-gauge bridge or thermocouple into a non-inverting stage with a gain of 100 to 1000.
- **Audio**: an inverting preamplifier with a mixing resistor per channel acts as a mixer (summing amplifier).
- **Photodiode transimpedance amplifier**: an inverting circuit where the source is a current; $R_f$ sets the volts per amp.
- **DAC output stage**: a current-output DAC feeds an inverting amp's virtual ground to convert current to voltage.
- **ADC driver**: a non-inverting or buffer stage so the ADC input sees a low-impedance driver.
- **Level shifting and gain scaling** of 0 to 3.3 V logic-level analog to a ±10 V range using an inverting amp with an offset reference on the + input.
:::

::: assumptions
I used the ideal op-amp ([[q0124]]): infinite gain, no input current, zero output impedance, unlimited bandwidth. For finite gain, the exact closed-loop gain is $A/(1+A\beta)$; for a gain-10 circuit with $A = 10^5$ the error is 0.01%. With bandwidth limits the gain falls above $f\approx GBW/\text{noise gain}$. I assumed a **dual supply** with the + input at ground for the inverting circuit. In a single-supply design the + input is biased at a mid-rail reference and the gain equation applies to the signal around that reference. The numbers assume resistor tolerances as stated and neglect input offset voltage and bias current. For a **current-feedback amplifier** the gain equation is the same but the resistor value of $R_f$ also sets the bandwidth, and it can't be chosen freely.
:::

::: followups
### How would you build a gain of 20 for a source with a 100 kΩ output impedance?
The source resistance is large, so the non-inverting stage avoids loading it: $1 + R_f/R_g = 20\Rightarrow R_f/R_g = 19$, for example $R_g = 10$ kΩ and $R_f = 190$ kΩ (nearest standard 1% values: 191 kΩ gives 20.1, 187 kΩ gives 19.7). With an inverting stage, $R_{in}$ would have to be much larger than 100 kΩ to avoid gain error, making $R_f$ megaohms and noisy.

### What's the input impedance of each configuration?
Inverting: $R_{in}$, since the − node is a virtual ground. Non-inverting: the op-amp's input impedance, which is MΩ to TΩ depending on the input type, in parallel with any bias resistor you add to ground.

### Can you get a gain of 0.5 from each configuration?
Inverting: yes, $R_f = 5$ kΩ and $R_{in} = 10$ kΩ gives $-0.5$. Non-inverting: no. Its minimum gain is 1. To attenuate non-inverting you'd put a resistive divider ahead of a buffer (or use the inverting config).

### Both circuits have the same noise gain, so why does the bandwidth differ between a gain of −10 and +11?
It doesn't. Both have noise gain 11 (for $R_f/R_{in} = 10$), so the bandwidth is $GBW/11$ in both. The magnitude of the signal gain differs by 1, but the loop is the same. The bandwidth differs only if you compare circuits of equal *signal* gain: gain −10 has noise gain 11, while gain +10 has noise gain 10 (slightly wider bandwidth).

### Harder: you see an offset of 200 mV at the output of an inverting gain-of-$-100$ amplifier built from a 10 kΩ and 1 MΩ with its input grounded. What do you suspect?
An op-amp's input offset voltage is multiplied by the noise gain (101), so a 2 mV offset gives 200 mV. Also, bias current $I_B$ flowing through the 1 MΩ gives $I_B R_f$: 100 nA gives 100 mV. Check the datasheet's $V_{OS}$ and $I_B$, add a compensating resistor ($\approx R_{in}\parallel R_f$) on the + input to cancel bias-current error, use a lower-offset or FET-input part, or AC-couple.
:::

- Draws the inverting circuit: + grounded, $R_{in}$ to −, $R_f$ from output to − :: Correct topology is the first thing the interviewer checks.
- Draws the non-inverting circuit: signal on +, divider from output to ground feeding − :: Same, and it shows you can build a feedback divider.
- States $-R_f/R_{in}$ and $1 + R_f/R_g$ and derives them using the virtual short :: The derivation shows understanding, not memorization.
- Explains the sign and the +1 physically :: Prevents common gain mistakes.
- Compares input impedance (low $R_{in}$ vs very high) :: A key reason to choose one or the other.
- Notes that gain below 1 requires inverting (or a divider) :: A classic follow-up trap.
- Mentions bandwidth via noise gain or resistor value trade-offs :: Shows engineering judgment beyond ideal algebra.
:::
