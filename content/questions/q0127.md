::: testing
Whether you understand what happens when the "huge gain" of an op-amp is **not** tamed by negative feedback:

1. The output swings to a supply rail depending on the sign of $V_+ - V_-$, so the op-amp acts as a **comparator** (a 1-bit analog-to-digital converter).
2. That the "virtual short" does not apply here, and how small the linear region is ($V_{rail}/A_0\approx$ 100 µV).
3. **Noise and chatter** near the threshold, and the fix: positive feedback for hysteresis (a **Schmitt trigger**).
4. Why a real op-amp is a mediocre comparator (saturation recovery, input clamps, output levels) compared with a dedicated comparator IC.
:::

::: why
Comparators turn analog quantities into digital decisions: over-voltage detection, zero-crossing detectors, battery-low flags, PWM generation, relaxation oscillators, level detection on sensors, and the front end of every ADC architecture that uses them. Mistakes show up as chattering outputs, double-triggering and missed edges. The question also tests whether you can reason about the *same* device in two modes (open loop vs. closed loop), and whether you know the usual follow-ups: hysteresis, propagation delay, and when to use a real comparator IC instead of an op-amp.
:::

::: concepts
- **Open-loop gain**: $10^5$ or more, so the linear input range is tens to hundreds of µV. See [[q0126]].
- **Saturation**: output limited by the supplies; $V_{out}\in[V_{OL}, V_{OH}]$. See [[q0123]].
- **Comparator**: a circuit that outputs one of two levels depending on which input is larger.
- **Positive feedback / hysteresis**: feeding some output back to the + input creates two thresholds (Schmitt trigger).
- **Virtual short**: only exists with negative feedback; absent here. See [[q0124]].
- **Propagation delay / saturation recovery**: how fast the output flips after the input crosses.
:::

::: answer
"Open loop, an op-amp has no feedback to hold the inputs together, so its enormous gain acts on any difference. If the plus input is even a hundred microvolts above the minus input, the output slams to the positive rail. If it's below, it goes to the negative rail, or ground in a single-supply design. So it behaves like a comparator: it compares two voltages and outputs a one or a zero. There's a tiny linear region, about the supply voltage divided by the gain, so a couple hundred microvolts wide, and it isn't useful.

The circuit type is a comparator, essentially a one-bit analog-to-digital converter. It's used for threshold detection, zero-crossing detectors, and PWM generation.

The catch is noise. If the input hovers near the threshold, even millivolts of noise make the output chatter back and forth. The fix is hysteresis: feed a bit of the output back to the plus input through a resistor, which is positive feedback. That's a Schmitt trigger, with two thresholds, one for rising and one for falling inputs.

And I'd mention that general-purpose op-amps aren't great comparators. They recover slowly from saturation, some have input clamp diodes, and the output isn't logic level. A dedicated comparator IC is faster and designed for this."
:::

::: technical
**Transfer function.** With no feedback:
$$V_{out} = \begin{cases} V_{OH}\;\approx +V_{sat} & V_+ - V_- > V_{sat}/A_0\\ A_0(V_+ - V_-) & |V_+ - V_-| < V_{sat}/A_0\\ V_{OL}\;\approx -V_{sat} & V_+ - V_- < -V_{sat}/A_0\end{cases}$$
For $A_0 = 10^5$ and $V_{sat} = 12$ V, the linear region is $\pm 120$ µV. The input offset voltage ($\sim$ 0.1 to 5 mV) shifts the actual threshold by that amount.

**Hysteresis (non-inverting Schmitt).** Input through $R_1$ to the + terminal, $R_2$ from output to the + terminal, − terminal at $V_{ref}$. The + node is $V_+ = \frac{V_{in}R_2 + V_{out}R_1}{R_1+R_2}$. Switching occurs when $V_+ = V_{ref}$, so the thresholds are
$$V_{TH,\pm} = V_{ref}\left(1+\frac{R_1}{R_2}\right) - V_{OL/OH}\frac{R_1}{R_2}$$
With $V_{ref}=0$, $R_1 = 10$ kΩ, $R_2 = 100$ kΩ, $V_{sat}=\pm12$ V: thresholds at $\pm 1.2$ V, hysteresis width 2.4 V.

**Real-op-amp issues.** Saturation recovery (stored charge in output and internal nodes) makes the delay microseconds in many general-purpose amps. Some op-amps have back-to-back input diodes that conduct for $|V_d| > \sim0.7$ V, which is incompatible with big differential inputs. Output levels are the rails minus a saturation voltage, not necessarily TTL/CMOS compatible. **Comparator ICs** are built to saturate cleanly: propagation delays of ns to µs, open-collector or push-pull outputs, optional built-in hysteresis.

**Speed.** The input overdrive $V_d$ affects the delay, since the output slews at a finite rate; larger overdrive means smaller delay.

> [!UNCERTAIN]
> Saturation recovery times, input clamp diode presence and propagation delays vary widely among op-amp and comparator families. Check the datasheet for the specific part, including the "propagation delay vs. overdrive" curves for comparators.
:::

::: short
"Open loop, the op-amp's gain of $10^5$ or more acts on the tiny difference between its inputs, so the output slams to a rail depending on which input is higher. That makes it a comparator, a one-bit ADC. The linear region is only ~100 µV wide. Noise near the threshold causes chatter, so you add positive feedback for hysteresis, a Schmitt trigger. In practice, dedicated comparators are better than op-amps for this because of faster recovery and logic-compatible outputs."
:::

::: long
"Without feedback, an op-amp's gain of a hundred thousand or more applies directly to the difference between the inputs. So the output is basically a sign function. If the plus input is higher than the minus input by more than about the supply voltage over the gain, which is roughly a hundred microvolts for a 12-volt supply, the output goes to the positive rail. If it's lower by that much, it goes to the negative rail. Only inside that narrow window does it behave linearly, and in practice input offset is bigger than that window, so you can ignore it.

So an open-loop op-amp is a comparator, a one-bit analog-to-digital converter. I'd use it for zero-crossing detection, over-voltage flags, or to generate PWM by comparing a triangle wave to a control voltage. The virtual short rule doesn't apply here, because that rule needs negative feedback.

The first problem is noise. If the input signal is slowly passing through the threshold, any noise or ripple makes the comparator output flip repeatedly. So I add hysteresis: a resistor from the output back to the plus input, which is positive feedback. Now the threshold depends on the output state, so the circuit has two thresholds, and the input has to move past the upper threshold to go high and below the lower one to go low. With 10 k and 100 k and 12-volt rails, that's plus and minus 1.2 V. Positive feedback is also what you use in relaxation oscillators.

Second, a general-purpose op-amp is not an ideal comparator. It's slow to recover from saturation, sometimes microseconds, it may have input protection diodes that limit the differential input, and the output swing might not match logic levels. A real comparator like an LM393-type part is built for that job, with fast response and an open-collector output you can pull up to any logic level. The trade-off is that comparators are usually not stable with negative feedback, so I wouldn't use them as amplifiers."
:::

::: terms
- **Comparator**: a circuit that outputs a high or low level depending on which of two inputs is larger.
- **Saturation**: output pinned near a supply rail.
- **Overdrive**: how far the input exceeds the threshold; affects propagation delay.
- **Hysteresis**: two different switching thresholds, depending on the output state.
- **Schmitt trigger**: a comparator with positive feedback that creates hysteresis.
- **Propagation delay**: time from input crossing the threshold to the output transition.
- **Open-collector (open-drain) output**: an output that sinks current and needs a pull-up resistor; lets you choose the logic level.
- **Chatter**: repeated output toggling when the input hovers near the threshold.
- **Phase reversal**: output flips when an input exceeds the common-mode range in some op-amps.
:::

::: exceptional
**An average answer** says "it saturates, so it's a comparator".

**An exceptional answer**:
- Quantifies the linear region ($V_{sat}/A_0\approx 120$ µV) and notes offset is larger than it.
- Says the virtual short **doesn't apply** without negative feedback.
- Identifies **chatter** as the main practical problem and derives the **Schmitt trigger thresholds** from the + node divider with numbers.
- Explains **why op-amps make poor comparators**: saturation recovery, input clamps, output levels, and says a **dedicated comparator** exists for that reason (and why a comparator should not be used as an amplifier).
- Mentions overdrive vs. delay and applications (zero-cross, PWM, relaxation oscillator).
:::

::: mistakes
- **Applying the virtual short to the open-loop circuit.** The inputs differ; that's the entire point.
- **Thinking the output can be "in between".** Practically it's at a rail except when the difference is ≲ 100 µV.
- **No hysteresis on a noisy or slow input**, leading to chattering and multiple triggers. Add hysteresis or a filter.
- **Using positive feedback and calling it "negative".** Feedback to the + input is regenerative, which is what creates the latching behavior.
- **Assuming the comparator output is logic-level.** An op-amp's output goes close to its supply, and may need a clamp or a level shift. Comparator ICs with open-collector outputs need a pull-up resistor.
- **Using a comparator IC with negative feedback as an amplifier.** Most are not frequency-compensated and will oscillate.
- **Forgetting input common-mode range**: both inputs must be within the allowed range, including at the threshold.
:::

::: deep
## What "open loop" means for the output

Take $V_{out} = A_0(V_+ - V_-)$ and clip it at the supply limits. For $A_0 = 10^5$ and $\pm12$ V rails the transition from one rail to the other takes place over a differential input of just $\pm120$ µV. Compare that to the offset voltage of a typical general-purpose op-amp (1 mV or more): the offset alone can move the threshold by an order of magnitude more than the width of the transition region. The consequence is that, for a comparator, the *threshold* is set by the other input plus offset, and the transition itself is sharp enough to be treated as ideal.

## The noise problem and the Schmitt trigger

If $V_{in}$ moves slowly through $V_{ref}$ with 5 mV of noise on top, the output toggles every time the noisy signal crosses the threshold, perhaps dozens of times. Digital circuits downstream see that as many edges (a counter will miscount, a microcontroller interrupt will fire repeatedly).

The cure is positive feedback. Add $R_2$ from the output to the + input:

Analysis: switching happens when $V_+ = V_- = 0$:
$$\frac{V_{in}R_2 + V_{out}R_1}{R_1+R_2}=0\;\Rightarrow\;V_{in} = -V_{out}\frac{R_1}{R_2}$$
With $V_{out} = +12$ V the threshold is $-1.2$ V (the input must fall below it to switch low); with $V_{out} = -12$ V it is $+1.2$ V (the input must rise above it to switch high).

## Why op-amps are poor comparators

1. **Saturation recovery.** An op-amp's internal nodes are driven hard into saturation; recovery adds delay (typically hundreds of ns to µs for a general-purpose part).
2. **Input protection / clamps.** Some precision op-amps have back-to-back diodes across the inputs that conduct at ~±0.7 V of differential input. These are fine in negative feedback (where the inputs are nearly equal), but they limit open-loop operation and draw current.
3. **Output levels.** The output swings between rails (or near them), so it may not match logic levels or may need a clamp. A comparator with an open-collector output can be pulled up to any logic supply.
4. **Frequency compensation** slows the op-amp for stability; comparators omit it, so they're fast but can't be used with negative feedback.
5. **Phase reversal** and common-mode range limits near the rails can cause output inversion for some parts.

A dedicated comparator IC addresses all of these. Typical propagation delays range from tens of ns to a few µs depending on the family, with a speed/power trade-off (nano-power comparators are slow).

## Overdrive and delay

The output cannot respond instantly. Delay depends on how far the input overshoots the threshold ("overdrive"): a larger overdrive gives a faster response because the internal stage is driven harder. Datasheets show propagation delay vs. overdrive (e.g., 10 mV, 100 mV). If you want a fast response, you want a large overdrive or a high-speed part.

## Where positive feedback shows up elsewhere

Replace the resistor feedback by a capacitor from the output to the input via an RC network and you get a **relaxation oscillator**: the comparator charges and discharges a capacitor between the two hysteresis thresholds, which makes a square wave with period set by the RC time constant. Compare a triangle wave with a control voltage and you have a **PWM generator**.

## Worked example: a single-supply Schmitt trigger sized from the noise

The ±12 V example above is tidy, but most comparators run from a single rail. Take a 5 V supply, a rail-to-rail output that reaches $V_{OL}=0.05$ V and $V_{OH}=4.95$ V into the load (assumed values; use your part's datasheet figures), and a threshold centered on $V_{ref}=2.5$ V. With $R_1=10$ kΩ in series with the input and $R_2=100$ kΩ from output to the + input, the general formula gives

$$V_{TH}=V_{ref}\Big(1+\frac{R_1}{R_2}\Big)-V_{out}\frac{R_1}{R_2}\ \Rightarrow\ \begin{cases}2.5(1.1)-4.95(0.1)=2.255\text{ V}&(V_{out}=V_{OH},\ \text{falling threshold})\\ 2.5(1.1)-0.05(0.1)=2.745\text{ V}&(V_{out}=V_{OL},\ \text{rising threshold})\end{cases}$$

The hysteresis is $2.745-2.255=0.49$ V, which equals $(V_{OH}-V_{OL})R_1/R_2=4.9\times0.1$. Now suppose the signal has 50 mV peak-to-peak of noise riding on a slow ramp. Choose the hysteresis at about twice the noise, 100 mV. That needs $R_1/R_2=0.1/4.9=0.0204$, so with $R_1=10$ kΩ the feedback resistor is $R_2\approx490$ kΩ; the nearest standard value, 470 kΩ, gives 104 mV of hysteresis with thresholds at 2.448 V and 2.552 V. The current drawn from the output through the divider is at most about $4.95\text{ V}/480\text{ k}\Omega\approx10$ µA, negligible. Notice that the thresholds are centered on $V_{ref}$ only because $V_{OH}+V_{OL}=V_{CC}$; with an open-collector output and a pull-up the high level is whatever the pull-up supplies and the thresholds shift accordingly.

## Limiting cases of hysteresis

- **$R_2\to\infty$.** Hysteresis vanishes and you recover the plain comparator with a threshold at $V_{ref}$ and all its chatter problems.
- **Hysteresis too wide.** If the threshold pair spans more than the input swing, the output latches in one state and never switches. Keep the thresholds well inside the signal's minimum and maximum, and check this at the supply and temperature corners.
- **Hysteresis comparable to the noise.** The output still occasionally double-triggers. A rule of thumb is hysteresis at least twice the peak-to-peak noise, measured with the bandwidth the comparator actually sees.
- **Slew-limited feedback.** Positive feedback is regenerative, so once the + node crosses the threshold the output accelerates itself. Parasitic capacitance from the output to the + input works the same way, which is why a layout with a long, high-impedance input trace next to the output can oscillate even with a modest hysteresis. A small capacitor (tens of picofarads) in parallel with $R_2$ speeds up the edge, and a lower source impedance at the input makes the node harder to disturb.

## Measuring the thresholds on the bench

Drive $V_{in}$ with a slow triangle wave (10 Hz, spanning well past both thresholds) and put the scope in XY mode, with $V_{in}$ on X and $V_{out}$ on Y. You see the hysteresis loop directly, and the cursors read the two switching points. For the 470 kΩ design, expect transitions near 2.45 V (falling) and 2.55 V (rising). Compare against the calculation; a few millivolts of skew is offset voltage and resistor tolerance (1% resistors change the 100 mV window by only about 1-2 mV), while a shift of both thresholds together comes from $V_{ref}$: a 1% error in a 2.5 V reference moves the whole window by 25 mV.

To see overdrive and delay, apply fast steps of 10 mV, 50 mV and 500 mV beyond the threshold and measure the time from the input crossing to the output crossing half of its swing. The delay shrinks as overdrive grows, and for a general-purpose op-amp used as a comparator it is much longer than for a purpose-built comparator. Finally, to check chatter, inject a known noise level through a small series resistor from a function generator at a few hundred kilohertz and slowly sweep the input. The output should switch once per crossing; if it does not, the hysteresis is too small or the supply and reference are noisy.

::: applications
- **Zero-crossing detectors** for AC mains sensing or phase measurement (with hysteresis and input protection).
- **Over/under-voltage supervisors** and battery-low flags.
- **PWM generators**: compare a triangle or sawtooth to a control voltage (analog buck controllers do this internally).
- **Relaxation oscillators and timers**: a classic op-amp/comparator RC square-wave generator.
- **Flash and SAR ADCs** use banks of comparators or a comparator in a successive-approximation loop.
- **Window comparators** for fault detection: two comparators with different thresholds define a "good" window.
:::

::: assumptions
I assumed a voltage-feedback op-amp with a dual supply, no input clamp, and saturation levels near the supplies. With a **single supply**, $V_{OL}$ is near 0 V. Real thresholds also include input offset voltage and temperature drift. The Schmitt analysis assumes $V_{OH}$ and $V_{OL}$ are symmetric and equal to $\pm V_{sat}$; real outputs rarely are, so compute with the actual $V_{OH}$ and $V_{OL}$ from the datasheet at your load. Many comparator ICs have **open-collector outputs** that need a pull-up resistor, which changes the high level and slows the rising edge ($RC$ with the load capacitance). Some applications use positive feedback within an op-amp *with* some negative feedback (for stable linear regions); that's a different circuit.
:::

::: followups
### Why does the open-loop op-amp make a bad amplifier but a decent comparator?
As an amplifier, its gain is so high and uncontrolled that any offset pushes it to a rail, and the linear window is ~100 µV. As a comparator you only care about the sign of the difference, which is exactly what the saturating gain provides. The things that matter for comparison (threshold accuracy, speed) are different from what matters for amplification (linearity, gain accuracy).

### Design a Schmitt trigger with thresholds of ±0.5 V from ±5 V output levels.
Using the non-inverting Schmitt with $V_{ref}=0$: $V_{TH} = \pm V_{sat}R_1/R_2$. So $R_1/R_2 = 0.5/5 = 0.1$, e.g. $R_1 = 10$ kΩ and $R_2 = 100$ kΩ. Hysteresis width is 1 V. Pick $R_2$ large enough to not load the output heavily (5 V across 110 kΩ is 45 µA).

### What is the propagation delay and how does overdrive affect it?
Propagation delay is the time between the input crossing the threshold and the output reaching its switching point (e.g., 50% of its swing). It decreases with overdrive: the more the input exceeds the threshold, the harder the internal stages are driven. The datasheet gives curves for different overdrives, such as 5 mV and 100 mV.

### A comparator's output chatters even with hysteresis. What would you check?
(1) Is the hysteresis width larger than the peak-to-peak noise at the input? (2) Supply noise or ground bounce coupling into the reference or the input; add decoupling and keep high-current return paths away. (3) Output-to-input coupling: a fast output edge capacitively coupling into a high-impedance input causes oscillation; add hysteresis, reduce input impedance, and separate traces. (4) Input outside the common-mode range.

### Harder: could a comparator be used as an op-amp with negative feedback?
Usually not. Comparators are not frequency-compensated, have little or no phase margin when used with feedback, and many have open-collector outputs that can't pull up. The result is oscillation. Some "op-amp/comparator" parts are specified for both. Check the datasheet for "stable with negative feedback".
:::

::: interpretations
"How does an open-loop opamp behave? What type of circuit is it?" has a one-word answer for the second half: a **comparator** (a one-bit ADC). Some interviewers may say "an open-loop *amplifier*" or "a high-gain amplifier with a very narrow linear range"; both describe the same circuit. It differs from the closed-loop circuits in [[q0125]], where negative feedback gives a controlled gain. Positive feedback (hysteresis) is a different circuit type, the Schmitt trigger, but it is the usual follow-up and so is covered here.
:::
