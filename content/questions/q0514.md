::: testing
Whether you route fast signals as **transmission lines with a return path**, not as "wires". The interviewer wants a short, prioritised list, and for each rule the physical reason behind it: continuous reference plane, controlled impedance, no stubs, few vias, spacing for crosstalk, matched lengths, termination. They also want to hear *when* the rules matter (edge rate, not clock frequency) so you don't over-engineer a 100 kHz signal or under-engineer a 100 ps edge. Candidates who can attach a number to a rule (3W spacing, tr/6 critical length, ground via next to every layer change) sound like they have laid out a real board.
:::

::: why
A board with perfect schematics can fail purely on routing: ringing that corrupts a clock, a DDR byte lane that violates setup, a USB link that only works at room temperature, a radiated-emissions failure at the EMC lab. Routing rules are cheap to follow at layout time and brutally expensive to fix after fabrication. In interviews this is the standard "have you done a real design?" probe, and it leads straight into the follow-ups on vias ([[q0515]]), corners ([[q0516]]), length matching ([[q0517]]) and differential pairs ([[q0519]]).
:::

::: concepts
- **Edge rate, not frequency, decides what is "high speed"**: a signal is a transmission line when the trace's one-way delay is a sizeable fraction of the rise time. See [[q0708]], [[q0709]].
- **Return current follows the signal**: at high frequency the return current flows in the reference plane directly under the trace, so the loop area is set by the plane, not by a "ground wire". See [[q0486]], [[q0489]].
- **Characteristic impedance $Z_0$**: set by trace width, dielectric height, $\varepsilon_r$. A constant $Z_0$ along the path means no reflections. See [[q0710]], [[q0524]].
- **Reflections from discontinuities**: stubs, vias, width changes and gaps in the plane each reflect part of the edge. See [[q0711]], [[q0526]].
- **Crosstalk**: coupled lines share fields; spacing and height above the plane control it. See [[q0694]].
- **Skew**: parallel signals must arrive within the receiver's timing window. See [[q0517]].
:::

::: answer
"The way I think about it, a fast edge is a wave travelling down a transmission line, so every rule is about keeping that line uniform and giving the return current a clean path.

First, route over a solid reference plane, usually ground, and never across a split or slot in it, because the return current has to detour and you get a big loop and EMI. Second, keep the impedance constant: one width, one layer where possible, controlled-impedance stackup from the fab. Third, keep it short and direct with as few vias as I can, and when I do change layers I put a ground via right next to the signal via so the return current can follow. No stubs, no T-junctions, so point-to-point, and bends are 45° or curved.

Then spacing: keep other signals at least three trace widths away to limit crosstalk, and give clocks even more room. Match lengths on buses and differential pairs, in time, not just millimetres. And terminate when the line is electrically long compared with the edge, series at the source or parallel at the load.

The one thing I'd add is that it all scales with rise time, not clock frequency. A 10 MHz clock with a 500 ps edge needs this treatment; a 1 MHz signal with a 50 ns edge doesn't."
:::

::: technical
**When the rules apply.** Treat a trace as a transmission line when its one-way delay $t_d$ exceeds roughly $t_r/6$ (some use $t_r/4$ or $t_r/10$). With $t_{pd}\approx 5.9$ ps/mm for FR-4 microstrip ($\approx 150$ ps/inch) the critical length is $\ell_c = t_r/(6\,t_{pd})$: 28 mm for $t_r = 1$ ns, 2.8 mm for $t_r = 100$ ps. The signal bandwidth is roughly $0.35/t_r$ (the "knee"), 350 MHz for a 1 ns edge.

**Checklist with reasons.**
- *Continuous reference plane directly under the trace.* Return current hugs the trace; a slot forces a detour, adding loop inductance (ringing, ground bounce) and radiating.
- *Controlled $Z_0$* (commonly 50 Ω single-ended, 90–100 Ω differential): same width and layer end to end; confirm with the fab's field solver, not just a calculator. A 10% $Z_0$ step gives $\Gamma = 0.05$.
- *No stubs/T-branches.* A stub of delay $t_s$ reflects the edge and rings at $f = 1/(4t_s)$. Use daisy-chain or fly-by, not stars.
- *Minimise vias; pair each layer change with a nearby return (ground) via,* and remove or back-drill unused barrel stubs ([[q0515]]).
- *Bends of 45° or arcs, no acute angles* ([[q0516]]).
- *Spacing ≥ 3W* (centre-to-centre ≥ 3 trace widths, i.e. edge gap ≥ 2W) cuts crosstalk to a few percent. Increase for clocks, resets and analog.
- *Length/skew matching* to the receiver's timing window ([[q0517]], [[q0520]]).
- *Keep traces off plane edges,* away from connectors' unshielded areas, and don't run them over power-plane splits.
- *Terminate* when $t_d > t_r/6$ and the driver isn't matched ([[q0531]]).
- *Placement first:* put the driver and receiver close, so the best route is short.

**Quick number.** At $t_r = 200$ ps and a 25 mm trace, $t_d = 148$ ps $> t_r/6 = 33$ ps. It is a transmission line, and an unterminated CMOS driver will ring.
:::

::: short
"High-speed routing is about keeping the trace a uniform transmission line with a clean return path. I route on a solid reference plane without crossing splits, keep one width for controlled impedance, avoid stubs, minimise vias and put a ground via beside each signal via, use 45° bends, keep about three trace widths of spacing, match lengths on buses and pairs, and terminate if the trace is long compared with the edge. What counts is rise time, not clock frequency: if the one-way delay is more than a sixth of the rise time, it's a transmission line."
:::

::: long
"I start by asking how fast the edges are, because rise time decides everything. If the trace's one-way delay is more than about a sixth of the rise time, the trace behaves as a transmission line. For FR-4 that's roughly 150 ps per inch, so with a one nanosecond edge anything over about an inch matters, and with a 100 picosecond edge it's a couple of millimetres.

Once it's a transmission line, the goal is a uniform impedance and a clean return path. So I route over a continuous ground plane, ideally on a layer adjacent to it, and I never cross a slot or split, because the return current has to go around and I've created a loop antenna. I keep the width constant so impedance is constant, and I get the actual stackup from the fab and use their numbers for 50 ohm single-ended or 100 ohm differential.

Then I attack discontinuities. No stubs or T-junctions: it's point to point, or daisy chain with tiny stubs. As few vias as possible, and every time a signal changes layers I drop a ground via next to it so the return current can follow, and I worry about the unused stub of the via. Corners are 45 degrees or curved, never 90 with a tight acute angle.

For interference, I keep traces at least three widths from neighbours, more for clocks, and I don't run fast signals parallel for long distances. For timing, I length-match buses and differential pairs, accounting for the different delays on different layers.

Finally, termination. If the line is long relative to the edge, I add a series resistor at the driver or a parallel termination at the end, depending on the topology. And I check the result in a simulation or on a scope, because rules of thumb get you close but not all the way."
:::

::: terms
- **Characteristic impedance ($Z_0$)**: the ratio of voltage to current of a wave travelling on the line, set by geometry and dielectric. Typically 50 Ω single-ended.
- **Reference (return) plane**: the solid copper layer adjacent to the signal layer that carries the return current.
- **Critical length**: the trace length above which transmission-line effects matter, about $t_r/(6t_{pd})$.
- **Stub**: a dead-end branch that reflects energy and resonates at $1/(4t_s)$.
- **Crosstalk**: unwanted coupling from an aggressor trace to a victim through mutual capacitance and inductance.
- **Skew**: arrival-time difference between signals that should be simultaneous.
- **Fly-by / daisy chain**: a topology where one trace passes each receiver in turn instead of branching.
- **Return-path discontinuity**: any gap, slot or layer change that interrupts the plane under a trace.
:::

::: exceptional
An average answer lists "short traces, no 90° corners, use ground planes." An exceptional answer:
- Opens with **edge rate and critical length** and gives the number ($t_r/6$, 150 ps/in).
- Explains each rule through the **return current** ("a split forces the return around, which is a loop antenna and an inductance").
- Mentions the **ground via beside a layer-change via** and via stubs, which many candidates forget.
- Distinguishes **inter-signal** rules (spacing, 3W) from **intra-signal** rules (uniform $Z_0$, no stubs) and **timing** rules (matching).
- Admits where rules of thumb stop and a **field solver or simulation** takes over, and says how they'd verify on hardware (TDR, eye diagram).
:::

::: mistakes
- **"High speed means high clock frequency."** It is the edge rate. A 1 MHz clock with 1 ns edges has GHz-wide content. Judge by $t_r$.
- **Routing across a plane split or slot.** The return current detours, the loop area grows and EMI/ground bounce follow. Stitch with caps or re-route.
- **Using vias freely because "they're just wires."** A via is roughly 1 nH and 0.3–0.5 pF with a stub; see [[q0515]].
- **Treating 90° corners as the main problem and ignoring return paths.** Corners barely matter below several GHz; return-path breaks matter at every speed. See [[q0516]].
- **Matching length in mm instead of time.** Different layers, vias and package lengths contribute different delays; match the *delay*.
- **Terminating everything.** Short nets on slow edges don't need terminators, and a parallel terminator costs power.
- **Star topology for a multi-drop net.** The stubs reflect; use fly-by or daisy chain.
:::

::: deep
## Why "high speed" depends on the edge, not the clock

A digital edge has a rise time $t_r$, and its spectrum extends to roughly $f_{knee} \approx 0.35/t_r$. A wire is "short" if it is much smaller than the shortest wavelength of interest, and a lumped model works. When the trace delay becomes comparable to the rise time, the voltage at the far end has not yet heard about the edge at the near end, and the wire must be treated as a distributed transmission line with characteristic impedance $Z_0=\sqrt{L'/C'}$.

A useful rule is that the line needs transmission-line treatment when the one-way delay $t_d > t_r/6$ (the exact factor, 4, 6 or 10, differs by author and tolerance). The critical length follows directly:

$$\ell_c = \frac{t_r}{6\,t_{pd}},\qquad t_{pd} = \frac{\sqrt{\varepsilon_{eff}}}{c}\approx 5.9\ \text{ps/mm (FR-4 microstrip)}$$

## The return current is half of the circuit

The loop is not just the trace. At DC, current returns by the lowest-resistance path. At high frequency it returns by the lowest-**impedance** (lowest inductance) path, which is the plane directly under the trace, concentrated within a few times the height $h$ of the trace. This gives a design rule that can be stated in one line: **do not interrupt the plane under a fast signal.**

## The rules, with numbers

1. **Reference plane and layer choice.** Route fast signals on a layer adjacent to a solid plane (microstrip on the outer layer, stripline between two planes on an inner layer, see [[q0479]]). Keep traces at least a few $h$ from the edge of the plane.
2. **Controlled impedance.** Ask the fab for a controlled-impedance stackup. For example, with FR-4 ($\varepsilon_r\approx 4.3$), $h = 0.2$ mm and 1 oz copper (35 µm), a 50 Ω microstrip is about 0.36 mm wide; at $h=0.1$ mm it's about 0.17 mm. A change from 50 to 55 Ω is $\Gamma = 0.048$: tolerable. A change from 50 to 100 Ω is $\Gamma = 0.33$: a visible one-third echo.
3. **Stubs.** A stub of one-way delay $t_s$ looks like a shunt open that resonates when $t_s = T/4$, i.e. at $f_0=1/(4t_s)$. A 10 mm stub on microstrip has $t_s = 59$ ps and rings at about 4.2 GHz: inside the spectrum of a 100 ps edge.
4. **Spacing.** Crosstalk falls rapidly with edge spacing. Reaching "centre-to-centre ≥ 3W" typically cuts coupling into the low single-digit percent for typical microstrip, but it depends on $h$: crosstalk scales with $(h/s)^2$-ish, so the real lever is **bringing the trace closer to its plane** and not just moving traces apart. 5. **Matching.** Bus lines should arrive within the receiver window. 1 mm of microstrip costs 5.9 ps; on a 1 Gb/s bus (UI = 1 ns) that is small, on a 10 Gb/s link (UI = 100 ps) 1 mm is 6% of a bit ([[q0520]]).
6. **Termination and topology.** Point-to-point or fly-by; terminate at the source (series) or sink (parallel) ([[q0529]], [[q0533]]).

## Worked example: should this trace be treated as a line?

A 3.3 V MCU drives a 90 mm trace to an SPI flash. The driver's edge is 2 ns (20–80%) and $t_{pd}$ = 5.9 ps/mm. $t_d = 0.53$ ns. Compare with $t_r/6 = 0.33$ ns: $t_d > t_r/6$, so it is electrically long: expect ringing unless the driver impedance matches or the trace is terminated. The fix costs one 33 Ω series resistor at the driver pin. If the same trace were only 30 mm ($t_d = 177$ ps), no termination is needed.

## Real hardware behaviour

- **Fibre-weave skew:** within a differential pair on a coarse glass weave, one trace may lie over glass and the other over resin; the dielectric constant differs by about 0.5–1 and gives picoseconds of skew. At multi-gigabit rates designers use zig-zag routing or spread-glass laminates ([[q0520]]).
- **Component pads and test points** are discontinuities too; keep them off the fastest nets or use impedance-friendly pads.
- **Verification:** a TDR/TDT measurement shows each discontinuity as a bump in the impedance profile, and an eye diagram shows the net effect ([[q0698]]).

> [!UNCERTAIN]
> The multiplier in the critical-length rule ($t_r/4$, $t_r/6$, $t_r/10$), and the "3W" spacing figure, are conventions, not laws. Different textbooks and company guidelines choose different margins. Use them for first-pass decisions, then verify with simulation or the receiver's datasheet.
:::

::: applications
- **DDR memory interfaces**: byte lanes length-matched to the strobe, fly-by clocks and address, controlled 40–60 Ω single-ended impedance (vendor-specific; see the SoC/memory layout guide).
- **USB 2.0/3.x and Ethernet PHY traces**: differential pairs with a continuous plane, ground vias at layer changes and AC-coupling capacitors placed symmetrically.
- **Clock distribution**: a clock net is the highest-risk trace on a board; it gets series termination near the driver and extra spacing.
- **RF / SMA launches**: 50 Ω microstrip or grounded coplanar waveguide with via fences.
- **High-speed ADC/DAC sample clocks and data buses** (LVDS, JESD204): matched-length pairs, clean reference planes and symmetric breakout.
:::

::: assumptions
- The numbers assume **FR-4 ($\varepsilon_r\approx 4.3$–4.5)** and typical 1 oz copper. Rogers-type laminates ($\varepsilon_r\approx 3$) change widths and delays.
- The $t_r/6$ and **3W** rules are conservative first-pass heuristics; analog and RF signals, sensitive clocks and very fast edges (tens of ps) need stricter treatment, and slow-edge signals may be fine with none of this.
- For **very short interconnects** (inside a module, on-chip) different regimes apply.
- Some interviewers may mean the **RF microwave** version of this question (microstrip, CPW, via fences), whose rule set emphasises grounded coplanar structures and via-stitching; the principles above still hold.
:::

::: followups
### How do you decide whether a particular net needs controlled impedance and termination?
Compare the trace's one-way delay with the rise time. If $t_d > t_r/6$ (e.g. 25 mm and a 200 ps edge: 148 ps against 33 ps), the net is a transmission line, so I use controlled impedance and decide on termination. If it's 10 mm and a 5 ns edge ($t_d = 59$ ps against 0.83 ns), it's a lumped wire and I just route it neatly.

### A signal must change layers. What do you do?
Prefer layers that reference the same plane, so the return doesn't have to jump. If it moves between planes at different potentials (e.g. L2 ground to L5 ground), I put ground-stitching vias within a couple of millimetres of the signal via, so the return current can transfer. If the reference changes from ground to power, I add a stitching capacitor nearby. Then I check the via stub.

### Why not just run all high-speed signals on the top layer?
Top-layer microstrip is simple, avoids vias and is easy to probe, but it's exposed to radiation and to neighbours, the dielectric is partly air so edges propagate faster than in stripline and crosstalk is more asymmetric. Stripline between two planes is better shielded and has cleaner coupling, but it needs vias to get in and out. The choice depends on the length, the edge rate and EMC. See [[q0479]].

### What if the rules conflict: the shortest route crosses a plane split?
I'd move the split or the component first. If it isn't possible, I keep the signal on the same layer and bridge the split with stitching capacitors (a few 100 pF to nF placed at the crossing) or re-route a longer path that stays above solid copper. A longer trace with a clean return nearly always beats a short trace with a broken return.

### Your board fails EMC at 400 MHz. Where do you look?
Likely a return-path discontinuity or a fast net with an unterminated stub. Using a near-field probe I find the hot trace, check whether it crosses a split or has a via with no ground via nearby, check for harmonics of a clock (400 MHz might be the fourth harmonic of a 100 MHz clock), and consider slowing the driver, adding a series resistor, or adding stitching vias.
:::

::: rubric
- Frames "high speed" by edge rate / delay vs rise time, not clock frequency :: This is the criterion that decides which rules apply.
- Route over a continuous reference plane; no splits or slots :: Return current follows the signal; breaking it causes loops, EMI and impedance steps.
- Keep impedance uniform (single width/layer, controlled stackup) :: Impedance steps are the cause of reflections.
- Avoid stubs and minimise vias; ground via beside layer-change vias :: Vias and stubs are the dominant discontinuities on real boards.
- Corners at 45° or curved; avoid acute angles :: Standard practice, even though the electrical effect is small at moderate speeds.
- Spacing (about 3W) and keeping traces close to the plane for crosstalk :: Shows you handle interference as well as reflections.
- Length/time matching for buses and pairs :: Timing windows are what actually fail in source-synchronous interfaces.
- Termination, and verifying by simulation/TDR/eye :: Completes the loop from design rule to confirmation.
:::
