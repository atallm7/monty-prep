::: testing
Whether you can list **concrete layout moves** that give return currents a low-impedance, well-defined path, and explain each by its physical cause. The interviewer wants things like: a solid plane under signals, a via at every ground pad (placed next to it), short connections for decoupling capacitor returns, no routing across splits, keeping high-current and sensitive returns apart by placement, star points only where needed, stitching vias, and avoiding ground loops and islands. Naming five rules is easy; giving the reason and a number for each is what stands out.
:::

::: why
These are the habits that decide whether a board is quiet on the first spin. Almost none of them cost money (they're free if you do them while placing and routing) but each one fixes a specific failure mode: bounce, crosstalk, emissions, noisy references. Interviewers use this question to see whether you design the return path on purpose or hope the autorouter did.
:::

::: concepts
- **Return path and loop area**: the current's loop sets inductance, radiation and pickup. See [[q0484]], [[q0486]].
- **Via inductance**: each via adds about 1 nH for a 1.6 mm barrel, much less for short vias. See [[q0509]].
- **Decoupling loop**: capacitor to pin to plane. See [[q0503]], [[q0507]].
- **Ground partitioning**: separation by placement vs. cutting the plane. See [[q0493]], [[q0496]].
- **Star grounding**: single-point connection for specific cases. See [[q0495]].
- **Stitching**: tying ground layers and pours together. See [[q0487]].
:::

::: answer
"I use a handful of rules, and each one is about keeping the return path short and well-defined.

One: use a solid ground plane directly next to the signal layers, and don't cut it up with slots or route across gaps. Two: connect every ground pin and pad to the plane with a via right at the pad, not through a long trace, because each millimetre of trace is about a nanohenry. Three: decoupling capacitors get the shortest loop I can build, with the ground via touching the capacitor pad, so the plane takes the return. If the plane is on layer 2, that via is only 0.2 millimetres long and almost no inductance.

Four: keep high-current or noisy returns away from sensitive ones by placement. For example, the motor driver's ground current should not flow under the ADC, so I put them in different regions of the same plane. Five: use a star or single-point connection only where I really need to separate returns, like a shunt measurement or a power stage next to a precision reference. Six: stitch the ground layers and any ground pours together with vias so there are no floating islands and the return can hop layers. And seven: keep signal and return close, so no big loops and no ground loops through cables or long paths.

The general idea is to decide where each current returns, and then make that path short."
:::

::: technical
**Techniques**

| Technique | Why | Number |
|---|---|---|
| Solid plane adjacent to signals | Smallest loop; defined return | $L'\approx0.3$ nH/mm at $h=0.2$ mm |
| Via at each ground pad, adjacent | Via inductance ∝ length | 0.08 nH for 0.2 mm via; 1.3 nH for 1.6 mm via |
| Multiple vias for high current / low L | Parallel inductances | 4 vias: ~0.32 nH vs 1.3 nH |
| Decoupling: pad–via–plane with minimal loop | Sets cap's effective ESL | 1.5 nH → 13 MHz SRF (100 nF); 6.5 nH → 6.2 MHz |
| No slots/gaps/trenches under fast signals | Return detours enlarge the loop | detour of 20 mm ≈ 20 nH loop |
| Separate returns by placement | Avoids common-impedance coupling | see [[q0484]] |
| Star point where needed | Forces large currents away from the reference | Kelvin sense, power stage |
| Stitching vias | Ties planes, avoids islands | spacing ≤ λ/20 ([[q0487]]) |
| Direct (not thermal-relief) connection for high-frequency ground pads | Lower inductance | use reliefs only where soldering needs them |

**Via inductance** (Johnson & Graham approximation, $h,d$ in inches): $L\approx5.08h[\ln(4h/d)+1]$ nH. For $d=0.3$ mm: 1.3 nH at $h = 1.6$ mm, 0.37 nH at 0.6 mm, 0.08 nH at 0.2 mm.

**Decoupling example.** A 100 nF capacitor with 1.5 nH total loop inductance has $f_{SRF}=1/(2\pi\sqrt{LC})=13$ MHz and presents 0.94 Ω at 100 MHz. With 6.5 nH of long trace and via, SRF is 6.2 MHz and the impedance at 100 MHz is 4.1 Ω, four times worse.

> [!UNCERTAIN]
> Via and trace inductance figures are first-order estimates. Real values depend on pad geometry, via spacing, plane proximity and the return-path shape. Use them to compare options, not as guaranteed values.
:::

::: short
"I give return currents a short, well-defined path. A solid ground plane right next to the signal layers, never cut by slots; a via at every ground pad, placed right at the pad; the shortest possible loop for decoupling capacitors, since each millimetre of trace is about a nanohenry; separate noisy and sensitive returns by placement rather than by cutting the plane; a star point only where I need one; and stitching vias so no ground pour is floating. The goal is small loops and no shared impedance between circuits."
:::

::: long
"My basic rules all come back to the return path.

First, a solid ground plane right next to the signal layers, and I don't cut it. A plane under the trace gives the return current a path with the lowest inductance, and any slot or gap forces it to detour. I check every fast net for a continuous reference.

Second, every ground pin or pad gets its own via to the plane, right at the pad, not through a long trace. Via inductance is proportional to length, so a 1.6 millimetre via is about 1.3 nanohenries, but a 0.2 millimetre via to a layer-2 plane is under a tenth of a nanohenry. For high current or critical pins I use two or more vias.

Third, decoupling capacitors. The loop is pin, capacitor, via, plane, back to the pin, and I make it as small as I can, with the ground via at the capacitor pad. For a 100 nanofarad cap, 1.5 nanohenries of loop gives a self-resonance of 13 MHz and 0.9 ohms at 100 MHz; 6.5 nanohenries from a long trace gives 4 ohms.

Fourth, separation by placement. I keep high-current and noisy returns, like motor drivers and switching regulators, away from sensitive circuits like ADC references, by putting them in different regions over the same plane. I only use a star or single-point ground where I really need to, for example a shunt resistor measurement or a precision reference.

Fifth, stitching. Ground pours on outer layers get vias to the plane, so there are no floating islands that radiate, and ground layers tie together at least every one-twentieth of a wavelength of the highest frequency I care about.

And I avoid loops: signal and return stay together, and long ground paths through cables or connectors are watched."
:::

::: terms
- **Return path**: the path current takes back to the source.
- **Via inductance**: series inductance of a via, roughly proportional to its length.
- **Decoupling loop**: the current loop formed by pin, capacitor, via and plane.
- **Self-resonant frequency (SRF)**: where the capacitor's reactance cancels its loop inductance.
- **Star ground**: all returns meet at one point.
- **Stitching via**: via that ties ground layers or pours together.
- **Ground island**: floating or poorly connected ground copper that can radiate or pick up noise.
- **Thermal relief**: spokes that connect a pad to a plane for solderability, at the cost of added inductance.
:::

::: exceptional
An exceptional answer gives each rule a mechanism and a number (via length, loop inductance, SRF) and recognises the trade-offs: thermal reliefs help soldering but add inductance; star points are right for DC/low frequency but wrong at high frequency, where a plane is better; splitting the plane is rarely the answer. It also says to verify the result by looking at the return current path, not just by connectivity, since a net can be connected and still have a bad return.
:::

::: mistakes
- **Connecting decoupling-capacitor grounds with a trace** to a distant via. The trace adds inductance.
- **Using thermal reliefs on all ground pins**. They help soldering but add inductance; use direct connections for high-frequency or high-current pads where the assembly process allows.
- **Slicing the plane to "isolate" grounds** and then routing signals across the gap.
- **Using a star ground for a high-speed digital board.** At high frequency, current doesn't follow your star; it follows the lowest inductance path.
- **Leaving copper islands**: unconnected ground pours act as antennas and couplers.
- **Putting one via for many ground pins**, so all the returns share a high-inductance connection.
:::

::: deep
## The goal: make each current's loop small and private

Every current flows in a loop. The loop's *inductance* sets how large a voltage spike a fast current change creates, and its *area* sets the radiation and pickup. Grounding techniques either shrink loops or keep different circuits' loops from overlapping.

## Via rules

- Place the ground via **adjacent to the pad**, ideally touching, or with via-in-pad if the fab allows.
- Use a via to the **nearest** plane: from L1 to an L2 ground is 0.2 mm; to a bottom-layer ground is 1.6 mm.
- Use **two vias** for high-current or high-speed ground pads; they halve the via inductance and share current.
- **Thermal reliefs** on ground pads connected to big pours help soldering but add series inductance (spokes). For ground vias that are not pads, connect directly. For decoupling capacitor pads on a plane, direct connection through a via beside the pad avoids the relief altogether.

## Plane rules

- **No slots under fast signals.** A row of through-holes with overlapping anti-pads can create a slot; stagger or space them.
- **Don't split to isolate** unless there's a reason (see [[q0493]]); partition by placement. See [[q0496]].
- **Return path continuity at layer changes**: a ground via next to a signal via (see [[q0487]]).
- **Plane cutouts for connectors or heat**: route signals around them, and don't run traces across a cutout.

## When to use single-point (star) grounding

A star point makes every circuit return through its own conductor to one node, so there's no common impedance between them. It works well at DC and low frequency (below ~1 MHz) where resistance dominates and wires are short compared with wavelength: audio, instrumentation, current-sense shunts and power-stage vs. control returns. At high frequency, a star fails because the long individual returns have high inductance and form loops. So a typical board uses a continuous plane for the high-frequency return and a *deliberate* single connection point only where DC currents need separating (for example the point where the sense ground meets the power ground at the shunt). See [[q0495]].

## Ground pours on signal layers

On a two-layer board a ground pour on the second layer acts as the "plane". On multilayer boards, extra pours on outer layers between traces provide shielding and a second return path, but only if stitched to the planes with vias, otherwise they are floating antennas. Fill rules: stitch every few millimetres, remove narrow slivers and dead-end islands, and keep pours symmetric top/bottom for copper balance.

## Ground loops

A loop through two ground connections (for instance a board with both an earth connection at the USB shield and a ground connection through a cable to another board) picks up magnetic fields and conducts currents from the other equipment. Cure: one connection between the systems for ground (or isolation), a common-mode choke or a capacitor on the shield, or an isolator on the interface. See [[q0493]].

## A quick design review

1. Is there an unbroken plane under every fast net?
2. Does every ground pad have a short via? Any ground connections made through traces?
3. Are the decoupling-capacitor loops minimal?
4. Do any high-current returns pass under sensitive circuits?
5. Are there floating pours, or islands?
6. Are stitching vias placed at layer changes and around the board edge?

> [!INTERVIEW]
> Give one before/after number: "Moving the ground via from 5 mm of trace away to touching the pad drops the loop from 6.5 nH to 1.5 nH, which moves the 100 nF cap's self-resonance from 6 MHz to 13 MHz and cuts its impedance at 100 MHz by four."

## Worked example: decoupling droop with the two ground connections

Put the two capacitor connections from the figure under a real load. An MCU supply pin steps its current by $\Delta I = 100$ mA in $\Delta t = 2$ ns. In the first instant the capacitor's bulk charge is not the limit; the loop inductance between the capacitor and the pin is. The voltage dip across that loop is $v = L\,\Delta I/\Delta t$:

$$v_{1.5\,\text{nH}} = (1.5\times10^{-9})\frac{0.1}{2\times10^{-9}} = 75\ \text{mV},\qquad v_{6.5\,\text{nH}} = (6.5\times10^{-9})\frac{0.1}{2\times10^{-9}} = 325\ \text{mV}$$

On a 3.3 V rail with a ±5 % window (±165 mV), the second layout is outside spec from this one capacitor and one 100 mA step, with no help from the board's other capacitors; the first uses under half of the window. Because many I/O pins can switch together, the real current step can be many times larger, so the margin matters. Adding a second via halves the via part of the inductance (the 0.08 nH term), but the dominant term in the bad layout is the 5 mm of trace at about 1 nH/mm, which no number of vias beside the cap fixes; the cure is to move the via to the pad.

The same arithmetic shows that above its self-resonance a capacitor's value stops mattering. A 10 nF part in the same 1.5 nH loop resonates at $1/(2\pi\sqrt{1.5\times10^{-9}\cdot10^{-8}}) = 41$ MHz; above that both it and the 100 nF part present the same $\omega L$, and between 13 MHz and 41 MHz the 100 nF part is actually lower (at 20 MHz about 0.11 Ω versus 0.61 Ω). The smaller capacitor only buys a deeper notch near 41 MHz. Beyond that, the only lever is lower inductance, which is why geometry beats value for the highest frequencies.

## Worked example: why a star point fixes a current-sense error

Consider a 10 mΩ shunt in the ground return of a 5 A load, read by an amplifier. The wanted signal is $5\ \text{A}\times10\ \text{m}\Omega=50$ mV. Suppose the amplifier's ground reference is taken from a ground pad 20 mm along a 1 mm-wide, 35 µm trace that also carries the 5 A load return. That trace is 20 squares, and each square of 1 oz copper is $\rho/t = 0.49\ \text{m}\Omega$, so its resistance is $20\times0.49 = 9.8$ mΩ. The load return current then develops $5\ \text{A}\times9.8\ \text{m}\Omega = 49$ mV across it, which is almost exactly as large as the signal you are trying to measure. If the amplifier's reference is on the wrong end of that trace, the output is off by about 98 %.

The cure is a single point where the sense circuit's reference meets the power ground, placed directly at the shunt's low side (a Kelvin connection): the amplifier gets its own thin return to that point, which carries only microamps, and the 49 mV drop on the power trace is simply not in the loop. The technique costs nothing but the discipline to route two separate conductors to one pad. Note that the star point is in *DC* terms: a solid plane remains under everything for high frequencies, and the Kelvin return routes over that plane.

## Worked example: how big can a ground loop be before it matters?

The ground-loop section above mentions pickup. Faraday's law gives the magnitude: $v = 2\pi f B A$ for a sinusoidal flux density $B$ through a loop of area $A$. Take a cable-and-board loop of 100 cm² (0.01 m²) in a 60 Hz field of 1 µT:

$$v = 2\pi(60)(10^{-6})(0.01) = 3.8\ \mu\text{V}$$

That is invisible to a digital input but is 40 times the 0.1 µV of resolution an instrumentation front end might need, and it appears as 60 Hz hum. The leverage is the area: a 5 cm² loop has 20 times less. (The 1 µT figure is a placeholder for a plausible stray-field level near mains wiring and equipment; measure the real environment with a pickup coil rather than assuming it.) Pickup scales linearly with frequency, so a switching supply's 500 kHz field couples about 8,000 times better than 60 Hz at the same $B$, which is why the compact buck loop matters so much.

## Real-hardware considerations

- **Via-in-pad is not free.** It puts the via barrel under the capacitor pad, but unfilled barrels wick solder away during reflow and can starve the joint. Fabs offer filled-and-capped vias at extra cost; ask for it or place the via touching the pad's edge instead.
- **Capacitor orientation.** Placing a capacitor so its power pad is nearest the IC's power pin and its ground pad nearest the ground via matters more than which side is which. Rotate it to shorten the shorter of the two legs.
- **Mounting inductance is geometry.** For a given footprint, a 0402 mounted with vias at the pads has the least loop area; an 0805 of the same value has more. Using a physically smaller package is a cheaper way to lower inductance than adding capacitors.
- **Pour fragments.** Slivers and isolated copper islands left by an automated pour act as antennas. Check the CAD tool's "dead copper" report and stitch or remove islands.

## Bench verification

You can measure a decoupling loop's inductance directly. Remove the IC, short the footprint's power and ground pins with a small copper strap, and use a VNA with a short 1-port reflection measurement: the inductive slope of the impedance above the capacitor's self-resonance gives $L = X/(2\pi f)$, and the resonant frequency gives the same number cross-checked with the capacitor value. Compare two nominally identical boards, one with the via at the pad and one with it moved, to see the 1.5 nH versus 6.5 nH difference for yourself. For a working board, probe the rail at the pin with a spring-tip ground and trigger on an I/O toggle; the spike height relative to the 75 mV and 325 mV predictions confirms the model.

::: applications
- **Microcontroller decoupling**: one 100 nF capacitor per supply pin with a via next to its ground pad.
- **Buck converter layout**: input-capacitor ground to the low-side switch ground in a tiny loop on the top layer, with immediate vias to L2.
- **ADC front end**: analog return paths kept in the quiet region, with the ADC's ground pin connected straight to the plane.
- **Shunt-based current sensing**: Kelvin sense traces from the resistor pads, with a single defined reference point.
- **Connector entry**: shield and ground pins stitched to the plane with multiple vias.
:::

::: assumptions
- Multilayer FR-4 board with a ground plane on L2; on 2-layer boards the same ideas apply with the bottom as the pour.
- 1 oz copper, 0.3 mm drill/vias and typical 0402–0805 decoupling parts.
- Frequencies from DC to a few hundred MHz; at GHz, the plane's parasitic behaviour (cavity resonance, return via placement) takes over.
- Safety grounding (earth connections, creepage) follows standards beyond these techniques.
- Where the fab doesn't allow via-in-pad, the closest practical via next to the pad is used.
:::

::: followups
### Why put the ground via right next to the decoupling capacitor pad?
Because the loop inductance (and therefore SRF and high-frequency impedance) is set by the loop area, and the via is the "ground leg" of that loop. A via touching the pad adds only the via's own inductance (about 0.1 nH when it goes to an adjacent plane), while a trace to a remote via adds roughly 1 nH per mm.

### When is a star ground a good idea?
At DC and low frequency where the resistive drop matters, for example high-current returns vs a precision measurement, or an audio gain stage. It makes sure large currents don't flow through the reference conductor. At high frequency, rely on the plane. Often the practical design is a plane everywhere with a deliberate single connection point (for example at a shunt).

### What are thermal reliefs and how do they interact with grounding?
Thermal reliefs connect a pad to a pour through narrow spokes so the pad doesn't draw all the soldering heat into the plane. They add series inductance (spoke inductance of several nH if long and thin), so for high-frequency or high-current ground pins it's better to connect directly to the plane through vias next to the pad, and keep reliefs for through-hole pins that are hard to solder.

### What if my board only has two layers?
Use the bottom layer as a mostly continuous ground pour with the minimum number of interruptions, route fast signals on top directly over unbroken ground, put ground vias beside decoupling caps, and stitch top pours to the bottom. The loop inductance is higher because the plane is 1.6 mm from the signal, so be more careful with clock edges and slow them if needed.

### Scenario: your board has a clean 3.3 V rail on the bench but 200 mV of high-frequency noise at one MCU supply pin when the I/O toggles. What layout techniques do you check?
Look at the decoupling capacitor at that pin: how long is the ground connection? Is the via adjacent? Are other loads sharing the via? Is the capacitor on the correct side of the via? Check whether the supply trace passes through the capacitor pad (so the capacitor is *in* the path) rather than branching off. Also check for a ground plane slot near the MCU and whether the output pins' return paths are crossing it. Fix by moving or adding capacitors, adding a second ground via and shortening the supply stub.
:::
