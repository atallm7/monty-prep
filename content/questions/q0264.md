::: testing
Whether you can build the control loop of a buck from parts you know: a reference, an error amplifier or comparator, a ramp, a gate drive and the power stage, and explain how the duty cycle responds to the feedback voltage. The interviewer is looking for **negative feedback direction** (output too high means duty goes down), the PWM comparator-plus-ramp idea ($D = V_c/V_{ramp}$), and ideally the simpler hysteretic alternative with its trade-offs. A clear drawing and an explanation of "which way does each signal move" is the whole test.
:::

::: why
Every buck regulator, however sophisticated, contains this loop. Understanding the minimal version, a comparator against a ramp or a comparator with hysteresis, lets you read any datasheet block diagram, build a quick prototype from discrete parts, and reason about what the controller does when things go wrong. It's also a common whiteboard exercise because it tests analog fundamentals (op-amp feedback, comparators) in a power context.
:::

::: concepts
- **Buck power stage**: switch, diode (or low-side FET), L and C; $V_{OUT} \approx D\,V_{IN}$ ([[q0201]], [[q0211]]).
- **Feedback divider and reference**: $V_{FB}$ compared to $V_{REF}$ ([[q0262]]).
- **Error amplifier**: integrates/amplifies $V_{REF}-V_{FB}$ into a control voltage $V_c$.
- **PWM comparator and ramp**: $D = V_c/V_{ramp,pk}$ for a 0 to $V_p$ sawtooth ([[q0231]] for PFM comparison).
- **Hysteretic control**: a comparator with positive feedback toggles the switch between two thresholds.
- **Gate drive**: a high-side PMOS can be driven directly; a high-side NMOS needs bootstrap ([[q0204]], [[q0206]]).
- **Negative feedback sign**: output high implies duty falls.
:::

::: answer
"The simplest version is a comparator. I divide the output down to a feedback voltage and compare it to a reference. If the output is too low, the comparator turns the switch on; if it's too high, it turns the switch off. With a little positive feedback for hysteresis, it chatters at a rate set by the inductor, the hysteresis band and the delays, and the output stays within the band. That's a hysteretic or 'bang-bang' buck.

For a fixed-frequency version, I'd use PWM. An error amplifier compares the feedback to the reference and produces a control voltage $V_c$. A ramp oscillator makes a sawtooth at, say, 500 kHz. A comparator checks the ramp against $V_c$: the switch is on while the ramp is below $V_c$, so duty is $V_c$ over the ramp amplitude. If the output goes up, the feedback goes up, the error amp pulls $V_c$ down, the on-time shrinks and the output comes back. That's negative feedback, as long as I wire the polarity right.

The comparator output goes through a gate driver to the switch. A high-side PFET is the simplest because I can drive it directly; for an NFET I'd add a bootstrap or use a driver IC, and on a synchronous design I'd add dead time so both FETs are never on together."
:::

::: technical
**Option A: hysteretic (ripple) control.** A comparator with $V_{FB}$ on one input and $V_{REF}$ on the other, plus positive feedback resistor $R_h$ from output to the non-inverting node, gives thresholds $V_{REF}\pm V_{h}/2$ at the FB node. At the output the band is $\Delta V_{out,h} = V_{h,FB}\,(R_1+R_2)/R_2$. The hysteresis at FB is $\Delta V_{FB} \approx V_{DD}\dfrac{R_1\parallel R_2}{R_1\parallel R_2 + R_h}$. The inductor current ripple is $\Delta I = \Delta V_{h}/ESR$ if the ripple at FB is ESR-dominated, giving a frequency (ideal, no delay)
$$f = \frac{V_{OUT}(V_{IN}-V_{OUT})}{L\,\Delta I\,V_{IN}}$$
Frequency varies with $V_{IN}$ and load; propagation delays lower it. Because the FB signal must contain ripple in phase with inductor current, ceramic-capacitor outputs need ripple injection from the SW node via an RC.

**Option B: fixed-frequency PWM voltage mode.** Error amp: $V_c = A(s)\,(V_{REF} - V_{FB})$ (inverting; integrator or Type II/III network). Ramp: sawtooth of amplitude $V_p$ at $f_{SW}$. Comparator: output high (switch ON) while ramp $< V_c$, so
$$D = \frac{V_c}{V_p}\quad(0 \le V_c \le V_p)$$
In steady state $V_{OUT} = D V_{IN} = V_{IN}V_c/V_p$, so the modulator gain is $V_{IN}/V_p$ (a design number, e.g. 12/2 = 6). Output rises: $V_{FB} \uparrow \Rightarrow V_c \downarrow \Rightarrow D \downarrow \Rightarrow V_{OUT} \downarrow$.

**Option C: current-mode PWM.** A clock sets the switch; the comparator resets it when sensed inductor current reaches $V_c/R_i$ (needs slope compensation for $D>0.5$; [[q0252]], [[q0255]]).

**Drive.** High-side PFET gate low = on; for sync designs use two-FET half-bridge with dead time ([[q0207]]).
:::

::: short
"I divide the output to a feedback voltage and use an error amplifier against a reference to make a control voltage. A comparator compares that voltage to a sawtooth ramp, so duty is control voltage over ramp amplitude, and drives the switch through a gate driver. If the output rises, the error amp lowers the control voltage and the duty cycle falls. The even simpler option is a comparator with hysteresis that turns the switch on below the reference and off above it."
:::

::: long
"Let me draw the hysteretic version first because it's the simplest. The power stage is a high-side PFET from $V_{IN}$ to a switch node, a Schottky from ground to the switch node, an inductor and an output capacitor. A divider takes the output down to the feedback node. A comparator has the feedback on one input and the reference on the other. When the output is too low, the comparator output goes low, which turns the PFET on; the inductor current ramps up and the output rises. When the feedback crosses the upper threshold, the comparator output goes high, the PFET turns off, the Schottky takes over, the current falls and the output drops. A resistor from the comparator output to its positive input gives hysteresis, so it doesn't chatter at the threshold. It's fast and needs no compensation, but the frequency isn't fixed, and it needs ripple at the feedback node, which with ceramics means injecting ripple from the switch node.

For a fixed-frequency design I'd use PWM. There's an oscillator that generates a sawtooth between 0 and, say, 2 V. An error amplifier takes the feedback and the reference, and its output is a control voltage between 0 and 2 V, wired with feedback so that when the output is high, the control voltage goes down. A comparator compares the control voltage to the ramp; the switch is on while the ramp is below the control voltage. So duty is $V_c/V_{ramp}$. For 12 V to 3.3 V I need 27.5% duty, so $V_c \approx 0.55$ V on a 2 V ramp. The comparator drives the gate through a buffer. For synchronous operation, I'd add the low-side FET with dead time. And I'd add a compensation network around the error amp, plus soft-start by ramping the reference."
:::

::: terms
- **PWM comparator**: compares control voltage to a ramp; its output width is the duty cycle.
- **Ramp / sawtooth**: periodic linear ramp from 0 to $V_p$ at $f_{SW}$.
- **Error amplifier**: amplifies $V_{REF} - V_{FB}$ with a compensation network.
- **Control voltage ($V_c$)**: error amplifier output; sets duty.
- **Hysteretic (bang-bang) control**: comparator with two thresholds; frequency not fixed.
- **Ripple injection**: coupling switch-node ripple into FB so a hysteretic loop works with low-ESR capacitors.
- **Dead time**: brief delay so high-side and low-side FETs are never on together.
- **Modulator gain**: $V_{IN}/V_p$ for voltage-mode PWM.
:::

::: exceptional
**An average answer** says "use a 555 timer" or "use PWM from a microcontroller".

**An exceptional answer**:
- Draws the whole loop (divider, reference, error amp or comparator, ramp, comparator, driver, switch, LC) and states the **sign** of each stage.
- Gives $D = V_c/V_p$ and a worked number ($V_c = 0.55$ V for 27.5%).
- Offers the **hysteretic alternative** and explains its frequency and its need for ripple at FB.
- Mentions how the loop is **compensated** and how **soft-start** is done.
- Notes gate drive details: PFET vs bootstrap NFET and **dead time** for synchronous.
- Compares options: hysteretic (fast, no comp, variable $f$), voltage-mode PWM (simple, needs Type III), current-mode (inherent current limit, needs slope comp).
:::

::: mistakes
- **Wrong feedback polarity.** If the error amp inputs are swapped the loop has positive feedback and saturates to 0% or 100% duty.
- **Driving a high-side NFET directly from a logic comparator.** Without bootstrap or a charge-pump the gate cannot be above $V_{IN}$ ([[q0206]]).
- **Forgetting dead time** in a synchronous design, causing shoot-through ([[q0207]]).
- **Hysteretic loop with ceramic output caps and no ripple injection.** The ripple at FB is 90° out of phase and tiny, so it oscillates erratically or at very low frequency.
- **Skipping the compensation network** around the error amp: a buck's LC plant needs lead ([[q0261]]).
- **Using a 555 and calling it regulated.** A bare 555 gives fixed duty; you'd need to feed the error back into its control pin and handle the nonlinear duty range.
:::

::: deep
## The sign convention first

The cleanest way to avoid mistakes is to trace "what happens if the output is too high?" through each block:

1. $V_{OUT}$ high $\Rightarrow$ $V_{FB} = V_{OUT}R_2/(R_1+R_2)$ high.
2. Error amp (inverting): $V_c = A(V_{REF}-V_{FB})$ goes **down**.
3. PWM comparator: switch is on while ramp $< V_c$, so lower $V_c$ means shorter on-time.
4. Lower $D$ lowers $V_{OUT}$. Negative feedback closed.
