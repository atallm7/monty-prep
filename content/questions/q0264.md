::: basics
### In plain words
The simplest regulated buck uses a comparator. It compares a scaled copy of the output to a reference, and turns the switch on when the output is too low and off when it is too high. A fixed-frequency version uses a ramp and an error amplifier to set how long the switch stays on each cycle. Both are feedback loops that push the output back toward the target.

### Picture it
This is a thermostat. When the room is too cold, the heater turns on. When it is warm enough, the heater turns off. A little gap between the on and off temperatures (hysteresis) stops it from flicking on and off nonstop. The buck does the same with the switch, only thousands of times per second. The fixed-frequency version is more like a heater that is always on for a set share of each minute.

### Words you need
- **Comparator**: a circuit that outputs high or low depending on which of two voltages is larger.
- **Hysteresis**: a small gap between the turn-on and turn-off thresholds.
- **PWM**: pulse width modulation, controlling the on-time share of each fixed period.
- **Error amplifier**: an amplifier that measures how far the output is from the target.
- **Gate driver**: a circuit that gives the switch's gate enough drive to switch fast ([[q0256]]).

### The simplest example
Take a ramp that rises from 0 to 2 V each cycle. The error amplifier outputs a control voltage of 0.5 V. The switch is on while the ramp is below 0.5 V, so the duty is $0.5/2=25\%$. From a 12 V input, the ideal output is $12\times0.25=3$ V. If the output sags, the control voltage rises, the duty grows, and the output recovers.

That is the whole idea. The rest of this page shows both circuits, the polarity that makes feedback negative, and the practical issues of driving the switches.
:::

::: testing
Whether you can build the control loop of a buck from parts you know: a reference, an error amplifier or comparator, a ramp, a gate drive and the power stage, and explain how the duty cycle responds to the feedback voltage. The interviewer is looking for **negative feedback direction** (output too high means duty goes down), the PWM comparator-plus-ramp idea ($D = V_c/V_{p}$), and ideally the simpler hysteretic alternative with its trade-offs. A clear drawing and an explanation of "which way does each signal move" is the whole test.
:::

::: why
Every buck regulator, however sophisticated, contains this loop. Understanding the minimal version, a comparator against a ramp or a comparator with hysteresis, lets you read any datasheet block diagram, build a quick prototype from discrete parts, and reason about what the controller does when things go wrong. It's also a common whiteboard exercise because it tests analog fundamentals (op-amp feedback, comparators) in a power context.
:::

::: concepts
- **Buck power stage**: switch, diode (or low-side FET), L and C; $V_{OUT} \approx D\,V_{IN}$ ([[q0201]], [[q0211]]).
- **Feedback divider and reference**: $V_{FB}$ compared to $V_{REF}$ ([[q0262]]).
- **Error amplifier**: amplifies $V_{REF}-V_{FB}$ into a control voltage $V_c$.
- **PWM comparator and ramp**: $D = V_c/V_p$ for a 0 to $V_p$ sawtooth ([[q0231]] for the PFM comparison).
- **Hysteretic control**: a comparator with positive feedback toggles the switch between two thresholds.
- **Gate drive**: a high-side PMOS can be driven directly; a high-side NMOS needs bootstrap ([[q0204]], [[q0206]]).
- **Negative feedback sign**: output high implies duty falls.
:::

::: answer
"The simplest version is a comparator. I divide the output down to a feedback voltage and compare it to a reference. If the output is too low, the comparator turns the switch on; if it's too high, it turns the switch off. With a little positive feedback for hysteresis it toggles at a rate set by the inductor, the hysteresis band and the delays, and the output stays within the band. That's a hysteretic, or bang-bang, buck.

For a fixed-frequency version I'd use PWM. An error amplifier compares the feedback to the reference and produces a control voltage $V_c$. A ramp oscillator makes a sawtooth at, say, 500 kHz. A comparator checks the ramp against $V_c$: the switch is on while the ramp is below $V_c$, so duty is $V_c$ over the ramp amplitude. If the output goes up, the feedback goes up, the error amp pulls $V_c$ down, the on-time shrinks and the output comes back. That's negative feedback, as long as I wire the polarity right.

The comparator output goes through a gate driver to the switch. A high-side PFET is the simplest because I can drive it directly; for an NFET I'd add a bootstrap or use a driver IC, and on a synchronous design I'd add dead time so both FETs are never on together."
:::

::: technical
**Option A: hysteretic (ripple) control.** A comparator with $V_{FB}$ on one input and $V_{REF}$ on the other, plus a positive-feedback resistor $R_h$ from the output to the sensing input, gives thresholds $V_{REF}\pm\Delta V_{FB}/2$. With the comparator swinging between 0 and $V_{DD}$,
$$\Delta V_{FB} \approx V_{DD}\,\frac{R_1\parallel R_2}{R_1\parallel R_2 + R_h}, \qquad \Delta V_{OUT,h} = \Delta V_{FB}\,\frac{R_1+R_2}{R_2}$$
If the output ripple is ESR-dominated, the inductor ripple is $\Delta I = \Delta V_{OUT,h}/ESR$, and the (ideal, no-delay) switching frequency is
$$f = \frac{V_{OUT}(V_{IN}-V_{OUT})}{L\,\Delta I\,V_{IN}}$$
This varies with $V_{IN}$ and load, and propagation delays lower it. With ceramic outputs the FB ripple is tiny and badly phased, so ripple is injected from the switch node through an RC.

**Option B: fixed-frequency PWM voltage mode.** Error amp (FB on the inverting input, compensation network $Z_f$ in its feedback path): $V_c$ falls as $V_{FB}$ rises. Ramp: sawtooth of amplitude $V_p$ at $f_{SW}$. Comparator: switch ON while ramp $< V_c$, so
$$D = \frac{V_c}{V_p}\quad(0 \le V_c \le V_p), \qquad V_{OUT} = D\,V_{IN} = V_{IN}\frac{V_c}{V_p}$$
The modulator gain is $V_{IN}/V_p$. Output up means $V_{FB}\uparrow$, $V_c\downarrow$, $D\downarrow$, $V_{OUT}\downarrow$.

**Option C: current-mode PWM.** A clock sets the switch; a comparator resets it when sensed inductor current reaches $V_c/R_i$ (needs slope compensation for $D>0.5$; [[q0252]], [[q0255]]).

**Drive.** A high-side PFET is on when its gate is below $V_{IN}$ by more than $|V_{th}|$. A synchronous design uses two FETs with dead time ([[q0207]]).
:::

::: short
"I divide the output to a feedback voltage and use an error amplifier against a reference to make a control voltage. A comparator compares that voltage to a sawtooth ramp, so duty is control voltage over ramp amplitude, and drives the switch through a gate driver. If the output rises, the error amp lowers the control voltage and the duty cycle falls. The even simpler option is a comparator with hysteresis that turns the switch on below the reference and off above it."
:::

::: long
"Let me draw the hysteretic version first because it's the simplest. The power stage is a high-side PFET from $V_{IN}$ to a switch node, a Schottky from ground to the switch node, an inductor and an output capacitor. A divider takes the output down to the feedback node. A comparator has the feedback on one input and the reference on the other. When the output is too low the comparator output goes low, which turns the PFET on; the inductor current ramps up and the output rises. When the feedback crosses the upper threshold the comparator output goes high, the PFET turns off, the Schottky takes over, the current falls and the output drops. A resistor from the comparator output to its sensing input gives hysteresis so it doesn't chatter at the threshold. It's fast and needs no compensation, but the frequency isn't fixed, and it needs ripple at the feedback node, which with ceramics means injecting ripple from the switch node.

For a fixed-frequency design I'd use PWM. An oscillator generates a sawtooth between 0 and, say, 2 V. An error amplifier takes the feedback and the reference, and its output is a control voltage wired with feedback so that when the output is high, the control voltage goes down. A comparator compares the control voltage to the ramp; the switch is on while the ramp is below the control voltage. So duty is $V_c/V_{ramp}$. For 12 V to 3.3 V I need 27.5% duty, so $V_c \approx 0.55$ V on a 2 V ramp. The comparator drives the gate through a buffer. For synchronous operation I'd add the low-side FET with dead time. And I'd add a compensation network around the error amp, plus soft-start by ramping the reference."
:::

::: terms
- **PWM comparator**: compares control voltage to a ramp; its output width is the duty cycle.
- **Ramp / sawtooth**: periodic linear ramp from 0 to $V_p$ at $f_{SW}$.
- **Error amplifier**: amplifies $V_{REF} - V_{FB}$ with a compensation network.
- **Control voltage ($V_c$)**: error amplifier output; sets duty.
- **Hysteretic (bang-bang) control**: comparator with two thresholds; frequency not fixed.
- **Ripple injection**: coupling switch-node ripple into FB so a hysteretic loop works with low-ESR capacitors.
- **Dead time**: brief delay so high-side and low-side FETs are never on together.
- **Modulator gain**: $V_{IN}/V_p$ for voltage-mode PWM.
:::

::: exceptional
**An average answer** says "use a 555 timer" or "use PWM from a microcontroller".

**An exceptional answer**:
- Draws the whole loop (divider, reference, error amp or comparator, ramp, comparator, driver, switch, LC) and states the **sign** of each stage.
- Gives $D = V_c/V_p$ and a worked number ($V_c = 0.55$ V for 27.5%).
- Offers the **hysteretic alternative** and explains its frequency and its need for ripple at FB.
- Mentions how the loop is **compensated** and how **soft-start** is done.
- Notes gate drive details: PFET vs bootstrapped NFET and **dead time** for synchronous.
- Compares options: hysteretic (fast, no compensation, variable $f$), voltage-mode PWM (simple, needs Type III), current-mode (inherent current limit, needs slope compensation).
:::

::: mistakes
- **Wrong feedback polarity.** If the error-amp inputs are swapped the loop has positive feedback and saturates to 0% or 100% duty.
- **Driving a high-side NFET directly from a logic comparator.** Without bootstrap or a charge pump the gate cannot go above $V_{IN}$ ([[q0206]]).
- **Forgetting dead time** in a synchronous design, causing shoot-through ([[q0207]]).
- **Hysteretic loop with ceramic output capacitors and no ripple injection.** The FB ripple is tiny and phase-lagged, so it oscillates erratically at a very low frequency.
- **Skipping the compensation network** around the error amp: a buck's LC plant needs phase lead ([[q0261]]).
- **Saying a bare 555 regulates.** It gives a fixed duty; you would have to feed the error back into its control pin and handle its limited duty range.
:::

::: deep
## The sign convention first

The cleanest way to avoid mistakes is to trace "what happens if the output is too high?" through each block:

1. $V_{OUT}$ high means $V_{FB} = V_{OUT}R_2/(R_1+R_2)$ is high.
2. Error amp (FB on the inverting input): $V_c$ goes **down**.
3. PWM comparator: switch is on while ramp $< V_c$, so lower $V_c$ means shorter on-time.
4. Lower $D$ lowers $V_{OUT}$. Negative feedback closed.

Figure: Output goes high when $V_{FB}$ exceeds the (shifted) reference: gate high turns the PFET off. $R_h$ feeds the output back to the non-inverting input, shifting the threshold in the direction that keeps the present state, so the switch toggles between an upper and lower threshold instead of chattering at one.

**How it runs.** When $V_{FB}$ is below the lower threshold the comparator is low, $Q_1$ is on, and the inductor current ramps up at $(V_{IN}-V_{OUT})/L$. The output voltage rises as the capacitor takes the current ripple (through its ESR). When $V_{FB}$ reaches the upper threshold the comparator switches high, $Q_1$ turns off, the diode conducts and the current ramps down at $V_{OUT}/L$.

**Worked numbers.** $V_{IN}$ = 12 V, $V_{OUT}$ = 3.3 V, $V_{REF}$ = 0.8 V, $R_1 = 31.6$ kΩ, $R_2 = 10$ kΩ, so $R_1\parallel R_2 = 7.6$ kΩ and the divider ratio is 0.24. For a 100 mV output hysteresis, $\Delta V_{FB} = 24$ mV, so
$$R_h = (R_1\parallel R_2)\left(\frac{V_{DD}}{\Delta V_{FB}}-1\right) = 7.6\text{k}\,\left(\frac{12}{0.024}-1\right) \approx 3.8\ \text{M}\Omega$$
With $L = 6.8$ µH and an output capacitor ESR of 50 mΩ (a polymer, say), inductor ripple is $\Delta I = 0.1/0.05 = 2$ A pp and, without delays, $f = 3.3\times8.7/(6.8\mu\times2\times12) = 176$ kHz. A comparator and gate-drive delay of 200 ns adds overshoot $(8.7 + 3.3)\times200\text{ ns}/6.8\mu = 0.35$ A to the ripple, so $\Delta I \approx 2.35$ A and $f \approx 150$ kHz. The frequency drifts with $V_{IN}$ and load, which is the main drawback for EMI and filter design.

**Why ripple at FB matters.** The comparator reacts to $V_{FB}$. In a hysteretic buck, the signal it sees is the output ripple, which is the ESR drop of the inductor current ($\Delta I\cdot ESR$) plus the capacitive part, 90° later. With 5 mΩ ceramics the ESR part is 4 mV and the capacitive part dominates, lagging the current, so the switch overshoots the band, oscillating at low frequency with huge ripple. The cure is **ripple injection**: an RC from the switch node (square wave) to FB creates a triangle in phase with the inductor current, independent of the capacitor.

**Pros/cons.** No compensation, fastest load-step response (the switch reacts within a delay), simplest. Frequency varies, ripple ≈ band, EMI harder to filter, accuracy includes half the band.

Figure: While the ramp is below $V_c$ the switch is on. A 0.55 V control level on a 2 V ramp gives 27.5% duty, which for 12 V in produces $0.275\times12 = 3.3$ V. Raise $V_c$ and the pulse widens; lower it and it narrows. (The red trace is shifted and scaled for visibility.)

**Worked numbers.** Ramp $V_p = 2$ V at 500 kHz. For 12 V to 3.3 V: $D = 0.275$, so the steady-state $V_c = D V_p = 0.55$ V. At 18 V in the same output needs $D = 0.183$ and $V_c = 0.37$ V; at 9 V, $D = 0.367$, $V_c = 0.73$ V. The modulator gain $V_{IN}/V_p$ is 6 at 12 V: the loop gain changes with $V_{IN}$ (a design headache fixed by **input voltage feed-forward**, which makes $V_p \propto V_{IN}$ so the gain is constant).

**Error amplifier and compensation.** $Z_f$ sets the controller's loop shape. A Type I (integrator only) is too slow with a double-pole plant. Type II or III networks add zeros ([[q0261]]). The reference ramps during soft-start (a capacitor on a current source) so $V_c$ rises gradually and inrush is limited.

## Extending to a synchronous bridge

Replace $D_1$ by a low-side NFET. A synchronous driver needs complementary gate signals with **dead time** (tens of ns) so $Q_1$ and $Q_2$ are never on together ([[q0207]]). If $Q_1$ is an NFET, a bootstrap capacitor and diode supply its gate above $V_{IN}$ ([[q0206]]). In practice all of this plus current limit, UVLO and protection is inside the controller IC ([[q0256]]).

## Choosing among the simple options

| | Hysteretic | Voltage-mode PWM | Current-mode PWM |
|---|---|---|---|
| Frequency | Variable | Fixed | Fixed |
| Compensation | None | Type III usually | Type II |
| Transient response | Very fast | Limited by loop bandwidth | Good |
| Current limit | Needs separate sensing | Needs separate sensing | Inherent cycle-by-cycle |
| Parts | Fewest | Ramp generator, EA | Sense element, slope comp |
| Typical use | Fast-response, simple rails | General-purpose | Most integrated ICs |

::: applications
- **Hysteretic/COT-style buck ICs** (constant on-time controllers) in notebook and server power: fast transient with simple loops.
- **Voltage-mode PWM controllers** in low-cost supplies and in some CPU VRMs with Type III compensation.
- **Peak-current-mode buck ICs** for most point-of-load converters ([[q0252]]).
- **Quick prototype supplies** built from a comparator, a PFET and a Schottky for a bench experiment.
- **Digitally controlled supplies**: an MCU's PWM with a software loop is the same structure with the error amp and ramp implemented in code.
:::

::: assumptions
- Asynchronous buck with a PFET for the simplest drive; a synchronous or NFET-based design adds bootstrap and dead time.
- Comparator and gate-drive delay values (200 ns) are examples; real values depend on parts.
- The hysteretic frequency formula assumes ESR-dominated ripple and ignores capacitor ripple and delays beyond the added overshoot.
- Voltage-mode formulas assume an ideal ramp and linear modulator; real ICs add input feed-forward and blanking.
- A microcontroller PWM with software control also satisfies "simple circuit"; the control sign and compensation issues are identical.
:::

::: followups
### What's the duty cycle if the control voltage is 0.55 V on a 2 V ramp?
$D = V_c/V_p = 0.55/2 = 0.275$. With 12 V in the average switch-node voltage is 3.3 V, so the LC filter outputs 3.3 V (ignoring drops).

### How would you generate the ramp simply?
Charge a capacitor from a constant current source (or resistor from a reference) and discharge it with a switch each clock period, or use a relaxation oscillator built with a comparator. Many ICs integrate this. To make the ramp amplitude track $V_{IN}$ (input feed-forward), make the charging current proportional to $V_{IN}$.

### Why does a hysteretic buck with ceramic output capacitors misbehave, and what do you do?
The comparator sees output ripple, which with ceramics is mostly capacitive: it lags the inductor current by 90° and is small. The switching decision comes late and the band is exceeded, with large, slow oscillation. Add ripple injection: an RC from the switch node (and a capacitor to FB) creates a triangular signal in phase with the inductor current, or use a constant-on-time controller with a ripple generator ([[q0251]]).

### Scenario: the output goes to $V_{IN}$ as soon as you power it. What could be wrong in the loop?
Possible causes: error-amp inputs swapped (positive feedback, $V_c$ saturates high, 100% duty), FB divider open (FB = 0, the loop sees zero output and keeps raising duty), comparator inputs swapped, or the PFET gate stuck low. Check $V_{FB}$ first: if it is 0 V with the output high, the divider's connection is missing ([[q0266]]). Also verify soft-start isn't stuck.

### What changes if the high-side switch is an NFET?
The gate must be about 5 V above the switch node when on, which can't come from a logic output. Use a bootstrap circuit: diode charging a capacitor from a 5 V supply while the low side is on, and a level-shifted driver referenced to SW ([[q0206]]). The comparator signal is level-shifted to the high-side driver, and dead time is added to the synchronous low-side FET.
:::
