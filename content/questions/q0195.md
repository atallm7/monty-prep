::: testing
Whether you can write the slope as *(voltage across the inductor) / (inductance)* in each state, identify exactly which circuit quantities enter that voltage (input, output, switch drops, DCR), and state what does *not* matter (load current, duty cycle itself, output capacitor). Good candidates extend it to saturation, temperature and tolerance, and to what it means for protection: how fast current rises in a short.
:::

::: why
The slope is the quantity that every control and protection scheme leans on: peak-current-mode control compares a ramp to a threshold, slope compensation must match the down-slope, current limits need to react before the current climbs too far, and inductor sizing is a slope calculation. It is also how you reason about worst-case conditions (startup into a short, input transients) without simulating.
:::

::: concepts
- **Inductor law** $di/dt=v_L/L$. See [[q0041]].
- **Voltage across $L$** is the switch node minus the output: $V_{SW}-V_{out}$, minus resistive drops. See [[q0191]].
- **Two states, two slopes**: on $\approx(V_{in}-V_{out})/L$, off $\approx-V_{out}/L$. See [[q0188]].
- **Inductance is not constant**: tolerance, temperature and current (saturation). See [[q0046]].
- **Steady state** requires the two ramp changes to cancel: $D=V_{out}/V_{in}$.
:::

::: answer
"The slope of the inductor current is the voltage across the inductor divided by its inductance. That's $di/dt = v/L$. In the buck the voltage across the inductor is the switch node minus the output, so the slope depends on exactly three things: the voltage on the switch-node end, the output voltage, and $L$.

On the on state the switch node is at the input voltage, so the current rises at $(V_{in}-V_{out})/L$: in my example $8.7$ V over 4.7 µH is 1.85 A per microsecond. In the off state the switch node is about zero and the inductor sees minus $V_{out}$, so it falls at $V_{out}/L$, 0.7 A per microsecond. 

The things that don't matter for the slope are the load current, which just moves the triangle up or down, and the output capacitor, as long as the output voltage stays put. The duty cycle doesn't change the slope either; it only decides how long you stay on each slope.

In reality it's a bit more complicated: the winding resistance, the FET drop and the diode drop all change the voltage slightly, the inductance has tolerance and temperature effects, and above saturation the inductance drops so the slope shoots up."
:::

::: technical
**Slope equations.**
$$\left.\frac{di_L}{dt}\right|_{on}=\frac{V_{in}-V_{out}-i_L(R_{ds,HS}+R_{DCR})}{L}\approx\frac{V_{in}-V_{out}}{L}$$
$$\left.\frac{di_L}{dt}\right|_{off}=-\frac{V_{out}+V_f\ (\text{or } i_LR_{ds,LS})+i_LR_{DCR}}{L}\approx-\frac{V_{out}}{L}$$
Ideal: $+1.85$ and $-0.70$ A/µs. With real drops (30 mΩ high-side + DCR total about 40 mΩ at 2 A, Schottky $V_f=0.4$ V): on $\approx+1.84$ A/µs, off $\approx-0.80$ A/µs. The diode drop matters more because $V_{out}$ is small.

**What sets each term.** $V_{in}$ (supply), $V_{out}$ (regulation target, set by feedback), $L$ (component; tolerance ±20% typical, so slope varies from 1.54 to 2.31 A/µs for 4.7 µH ±20%), parasitic resistances.

**Does not set it:** $I_{out}$ (only offset), $C_{out}$ (affects $v_C$ only through the $\Delta V_C\ll V_{out}$ term), $f_{sw}$ (sets how long you ride each slope, so ripple), $D$ (for the same reason).

**Consequences.** $\Delta I=\text{slope}\times\text{time}$: $1.85\times0.55\ \mu s=1.02$ A and $0.70\times1.45\ \mu s=1.02$ A.

**Fault cases.**
- Start-up or short circuit ($V_{out}\approx0$): on slope $V_{in}/L=2.55$ A/µs, off slope only $V_f/L=0.085$ A/µs. The current cannot decay in the off time, so it staircases up cycle after cycle unless a valley-current limit or frequency foldback steps in.
- Saturation: if $L$ falls to half, both slopes double, e.g. on slope $3.7$ A/µs.
:::

::: long
"The inductor equation is $v = L\,di/dt$, so the slope of the current is the voltage across the inductor divided by $L$. In a buck that voltage is the switch node minus the output.

During the on time the switch node is tied to $V_{in}$, so the slope is $V_{in}$ minus $V_{out}$ over $L$: in my example 12 minus 3.3 is 8.7 V, over 4.7 µH, which is 1.85 amps per microsecond. During the off time the switch node is at about zero, so the voltage across the inductor is minus $V_{out}$ and the slope is minus $V_{out}$ over $L$, about minus 0.7 amps per microsecond. That's a good sanity check: since the output voltage is lower than the input, the rise is steeper and shorter than the fall.

What the slope does not depend on is the load: heavier load shifts the triangle up, not the slope. It doesn't depend on duty cycle or frequency either; those set how long you ride each slope and so the ripple. And it doesn't depend on the output capacitor, since $V_{out}$ is held steady.

The real world modifies the slope a bit. The winding resistance and FET resistance subtract a few tens of millivolts from the on voltage. The diode drop adds about 0.4 V to the off-state voltage, which is a 12% effect on a 3.3 V output. Inductance varies with tolerance, temperature and bias current, and above saturation it collapses and the slope rises. And in a short circuit the output voltage is zero, so the down-slope is almost nothing: the current keeps staircasing up, which is why converters have valley current limits."
:::

::: terms
- **Slope ($di/dt$)**: rate of current change, in A/µs.
- **Volt-seconds**: $V\cdot t$; multiplied by $1/L$ gives $\Delta I$.
- **DCR**: winding DC resistance; subtracts $iR$ from the inductor voltage.
- **Saturation**: loss of inductance at high current; steepens the slope.
- **Inductor tolerance**: ±10 to ±30% typical; changes slope and ripple.
- **Slope compensation**: ramp added to current-mode control to stabilise operation above 50% duty cycle, matched to the down-slope.
- **Valley current limit**: limit on the minimum current, protects against staircase runaway in a short.
:::

::: exceptional
**An average answer**: "$V/L$."

**An exceptional answer**:
- Gives both slopes with the correct voltages and numbers, and says what they depend on.
- States what does *not* matter (load, $C_{out}$, $f$, $D$) and why.
- Includes real-world corrections: $V_f$ matters more than $R_{ds}$ in low-voltage outputs, tolerance of $L$, saturation.
- Brings in the fault case: short circuit gives a tiny down-slope, so you need a valley limit.
- Connects to control: slope compensation for current-mode control, current sensing time constants, current-limit propagation delay.
:::

::: mistakes
- **Saying the slope depends on the load current.** It sets the average only.
- **Using $V_{in}$ instead of $V_{in}-V_{out}$** for the on-state slope.
- **Using $-V_{in}$ or $-(V_{in}-V_{out})$ for the off state.** It is $-V_{out}$ (plus the clamp drop).
- **Ignoring the diode drop at low $V_{out}$.** At $V_{out}=1$ V, a 0.4 V drop changes the down-slope by 40%.
- **Assuming $L$ is constant.** At $I_{sat}$ it may have dropped 20 to 30% (that is how $I_{sat}$ is often defined), and further beyond.
- **Treating the slope as the same in DCM.** The slopes are the same in the ramps but the current sits at zero for part of the cycle.
:::

::: deep
## Slope = volts across L over L

For any inductor current $i_L$:
$$\frac{di_L}{dt}=\frac{v_L}{L}.$$
In the buck, $v_L=V_{SW}-V_{out}-i_LR_{DCR}$, where $V_{SW}$ is whichever level the switch node is at.

| State | $V_{SW}$ | $v_L$ (ideal) | slope (4.7 µH) |
|---|---|---|---|
| On | $V_{in}-iR_{ds}$ | $+8.7$ V | $+1.85$ A/µs |
| Off, diode | $-V_f$ | $-3.7$ V | $-0.79$ A/µs |
| Off, sync | $-iR_{ds}$ | $-3.3$ V | $-0.70$ A/µs |

(The diode row includes $V_f=0.4$ V without DCR; adding 40 mΩ DCR at 2 A gives −0.80 A/µs.)

## Real-world corrections

1. **Resistive drops.** $R_{DCR}$ and $R_{ds(on)}$ total about 40 mΩ in the example, so at 2 A they subtract 80 mV from the 8.7 V on-state voltage (1%) but, in the off state, add to the $V_{out}+V_f$ term. The on-slope falls to 1.84 A/µs.
2. **Diode drop.** In the off state the inductor sees $V_{out}+V_f$. For a 3.3 V output with a 0.4 V Schottky that is 12% steeper than ideal; for a 1 V output it is 40%. This is one reason synchronous rectification matters more at low $V_{out}$.
3. **Tolerance and temperature.** A ±20% 4.7 µH inductor: on-slope 1.54 to 2.31 A/µs. Ferrite permeability also changes with temperature.
4. **Saturation.** If the effective $L$ halves, the slopes double (3.7 A/µs on). See [[q0188]] and [[q0046]].

## Why protection engineers care: the short-circuit staircase

If $V_{out}\approx0$ (short or start-up into a discharged output):
- On-slope: $V_{in}/L=12/4.7\ \mu H=2.55$ A/µs; in a minimum on-time of 100 ns that is already $+0.255$ A.
- Off-slope: $-V_f/L$ (diode) $=-0.085$ A/µs; over a 1.9 µs off time the current falls only $0.16$ A.

Each cycle the net change is about $+0.1$ A, so the current ratchets up cycle by cycle until a limit stops it. That is why controllers include a *valley* limit (check the minimum current each cycle and skip pulses if too high) and foldback/hiccup, not just a peak limit.

## Controls that use the slope

- **Peak current-mode control** compares the sensed rising current to the error-amplifier output. Above 50% duty, the sensed down-slope mismatch makes the loop unstable; *slope compensation* adds an artificial ramp of about half the down-slope ($V_{out}/2L$) to the sense signal.
- **Inductor DCR sensing** uses an RC across the inductor whose time constant is matched to $L/R_{DCR}$ so the capacitor voltage replicates $i_LR_{DCR}$.
- **Current-limit comparator delay**: if the comparator and gate-drive delay is 50 ns and the slope in a fault is 2.55 A/µs, the current overshoots the limit by 0.13 A.

## The slope sets how fast the converter can react

Because the inductor current can only move at $v_L/L$, the slope is also the converter's large-signal speed limit. For a 1 A load step, the time for the inductor to catch up is $\Delta I\,L/v_L$ in the direction of the step:

| $L$ | On-slope | Off-slope | Time to rise 1 A | Time to fall 1 A | Ripple (12 V in) |
|---|---|---|---|---|---|
| 2.2 µH | 3.95 A/µs | 1.50 A/µs | 0.25 µs | 0.67 µs | 2.17 A |
| 4.7 µH | 1.85 A/µs | 0.70 A/µs | 0.54 µs | 1.42 µs | 1.02 A |
| 10 µH | 0.87 A/µs | 0.33 A/µs | 1.15 µs | 3.03 µs | 0.48 A |

The same factor that makes the ripple small (a large inductor) also makes recovery slow, which is why transient-critical rails such as processor cores use small inductors and accept the large ripple. It is the fundamental trade-off behind the ripple ratio of 20 to 40% used in most designs. Notice also the asymmetry: the fall time is always longer than the rise time by $(V_{in}-V_{out})/V_{out}=2.64$ at this operating point, because the off-state voltage is only the small output voltage.

## What a current sensor sees: leading-edge blanking

At 1.85 A/µs the current rises by 1.85 mA every nanosecond. A peak-current-mode controller senses a resistor or FET voltage that ramps with this slope, but it also sees a large spike at the turn-on edge from the gate-drive current and the junction capacitances. To avoid triggering falsely, controllers blank the sense input for a fixed interval after turn-on, commonly tens to a few hundred nanoseconds. With 100 ns of blanking the inductor current rises by 0.19 A during the blind window, so the minimum on-time is also a minimum current rise, and a 20 mΩ sense resistor only produces 3.7 mV of useful ramp in that window. This is why sense signals are small and why layout and filtering of the sense line are critical.

## Using the slope to infer what is wrong

The two slopes together are a diagnostic. Because $di/dt=v/L$ in each state, you can read the voltage levels from the current picture:

- If the on-slope is steeper than $(V_{in}-V_{out})/L$ nominal, the effective $L$ has fallen (saturation, hot core, low-tolerance part), or $V_{out}$ has dropped (a transient or overload).
- If the off-slope is steeper than $V_{out}/L$, the diode or low-side FET has more drop than expected (a hot FET, a bad diode), as in the state table above.
- If the on-slope looks right but the current keeps rising cycle after cycle, the off-slope is too gentle for the on-slope: the volt-second balance is not met, which is the short-circuit ratchet described above.

## Measuring the slopes on a bench

1. Use a current probe whose bandwidth is at least ten times the switching frequency and that does not saturate at the DC level. Zero and degauss it before every measurement.
2. Put cursors on the straight parts of the ramps, away from the edge ringing, and read $\Delta I/\Delta t$. Then compute $L_{eff}=v_L/(di/dt)$ using the measured SW and output voltages at the same moments.
3. Compare $L_{eff}$ at light load and at full load. A drop of more than 10 to 20% as the DC current rises is the saturation knee, and it is information you cannot get from the DC inductance on the datasheet.
4. Repeat at the highest ambient temperature the product will see, because the inductance, DCR and the saturation current all change with temperature.

::: applications
- **Inductor sizing and ripple** using $\Delta I=\text{slope}\times\text{time}$.
- **Current-mode controllers** (slope compensation, peak/valley limits).
- **Short-circuit and start-up protection** design: valley limit, soft start, frequency foldback.
- **DCR current sensing** networks.
- **Estimating response time**: $\Delta I_{load}/\text{slope}$ is how long the inductor takes to supply a load step.
:::

::: assumptions
- **CCM and small ripple** in $V_{out}$.
- **Linear inductor** below saturation, constant $L$.
- **Ideal or lightly lossy switches**; the corrections above list the first-order effects.
- **Output at its regulated value**; during start-up or faults $V_{out}$ differs and so do the slopes.
- **Inductor tolerance** and temperature drift are not included in the nominal numbers.
- **DCM**: the ramps are the same, but there is a zero-current interval.
:::

::: followups
### Why is the on-slope steeper than the off-slope in my example?
The on-state voltage across the inductor ($V_{in}-V_{out}=8.7$ V) is larger than the off-state voltage ($V_{out}=3.3$ V). The two *areas* are equal ($8.7\times0.55\ \mu s=3.3\times1.45\ \mu s$), so the on-time is correspondingly shorter. At $D=0.5$ ($V_{in}=2V_{out}$) the slopes are equal and opposite.

### How does the slope change if I swap the diode for a synchronous FET?
The off-state voltage across the inductor drops from $V_{out}+V_f=3.7$ V to $V_{out}+IR_{ds}\approx3.32$ V, so the down-slope falls from 0.79 to 0.71 A/µs. The duty cycle needed for the same $V_{out}$ is also slightly smaller (0.275 vs 0.299 in the diode case, from volt-second balance with drops).

### What is the slope during a short circuit and why is that dangerous?
With $V_{out}=0$ the on-slope is $V_{in}/L=2.55$ A/µs but the off-slope is only $V_f/L$, tiny. The current cannot decay and staircases up. A peak-current limit alone is not enough, since the converter can still add current each cycle after the peak limit is hit in the minimum on-time: you need a valley limit or pulse skipping.

### Does the output capacitor affect the slope?
Only via the small ripple on $V_{out}$ (12 mV on 3.3 V is 0.4%, so the slope varies by less than 0.2% across a cycle). It does not otherwise change the slope. Reducing $C$ to zero would let $V_{out}$ move and change the slope substantially, but then it's no longer a buck regulator.

### Harder: peak-current-mode control at $D>0.5$ oscillates. How does the slope relate?
In peak current-mode control a perturbation in the inductor current is multiplied by the ratio of down-slope to up-slope each cycle: $-m_{down}/m_{up}=-(V_{out}/(V_{in}-V_{out}))=-D/(1-D)$ in magnitude. For $D>0.5$ this exceeds 1, so perturbations grow (subharmonic oscillation). Adding a compensating ramp of slope $m_a$ makes the ratio $(m_{down}-m_a)/(m_{up}+m_a)$, which is below 1 for $m_a\ge m_{down}/2$.
