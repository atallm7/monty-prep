::: basics
### In plain words
An LDO has a transistor between the input and the output, and a feedback loop that sets how hard that transistor conducts. A reference voltage, a divider, and an error amplifier compare the output to the target. If the output drops, the amplifier turns the transistor on harder. If it rises, the amplifier eases off. This keeps the output steady as the load and input change.

### Picture it
Picture a person watching a pressure gauge and turning a valve. When the gauge reads low, the person opens the valve a bit more. When it reads high, the person closes the valve a bit. The error amplifier is that person, and it is very fast. The picture misses the stability side: because it is a feedback loop, the output capacitor and loop speed must be chosen so it does not oscillate.

### Words you need
- **Reference ($V_{ref}$)**: a fixed internal voltage that the output is compared with.
- **Feedback divider**: two resistors that scale the output down to compare it with the reference ([[q0008]]).
- **Error amplifier**: an amplifier that outputs how far the output is from the target.
- **Pass transistor**: the series transistor, whose resistance the amplifier adjusts.
- **Output capacitor**: a capacitor on the output that is part of the loop's stability.

### The simplest example
Say the reference is 0.8 V and the divider is two equal 10 kΩ resistors. The chip then regulates the output to $0.8\times(1+1)=1.6$ V. If the load pulls the output down to 1.5 V, the divider reads 0.75 V, below 0.8 V. The amplifier then turns the pass transistor on harder, its resistance falls, and the output climbs back to 1.6 V.

That is the whole idea. The rest of this page covers the loop gain, the accuracy this gives, and what happens at dropout when the transistor cannot turn on any harder.
:::

::: testing
Whether you can explain a **feedback regulator** as a control loop built from parts you already know: a reference, a feedback divider, an error amplifier and a pass transistor acting as a variable resistor. A good answer follows one disturbance around the loop ("the load steps up, $V_{out}$ dips, the error amp turns the pass device on harder, $V_{out}$ recovers") and states the closed-loop equation $V_{out}=V_{ref}(1+R_1/R_2)$. Strong candidates also know *why the output capacitor matters for stability*, and what the pass element dissipates.
:::

::: why
An LDO is the simplest example of a complete negative-feedback system on a board, and it is used on almost every product. Understanding the loop explains the datasheet: line and load regulation, PSRR, transient response, why the output capacitor has a required range or ESR window, why dropout exists, and why an LDO can oscillate with the wrong capacitor. It is also the foundation for the switching regulators later in the list, which use the same feedback divider and error-amp structure ([[q0223]]).
:::

::: concepts
- **Voltage reference**: a stable bandgap voltage (typically about 0.6 to 1.25 V, depending on the part) that the output is compared against.
- **Voltage divider**: scales $V_{out}$ down to the reference level. See [[q0008]].
- **Error amplifier**: an op-amp or transconductance stage whose output moves with $V_{ref}-V_{FB}$. See [[q0143]].
- **Pass transistor as a variable resistor**: the gate voltage sets the channel resistance, so the series element drops $V_{in}-V_{out}$.
- **Negative feedback**: the loop reduces output error by a factor $1+T$, where $T$ is the loop gain. See [[q0129]].
- **Stability**: the loop must have enough phase margin, which depends on the output capacitor and load.
:::

::: answer
"An LDO is a pass transistor in series between the input and the output, and a feedback loop that adjusts how hard that transistor is on.

Inside there's a voltage reference, say 0.8 V, a resistor divider from the output that gives a feedback voltage, and an error amplifier comparing the two. The error amp drives the gate of the pass transistor, which is usually a PMOS with its source on the input. If the output drops, because the load increased or the input fell, the feedback voltage falls below the reference, the amplifier pulls the gate lower, the PMOS turns on harder and its resistance drops, so the output rises back. If the output rises, the opposite. In steady state the amplifier forces the two inputs equal, so $V_{FB}=V_{ref}$ and $V_{out}=V_{ref}(1+R_1/R_2)$.

The pass transistor is acting like a variable resistor, dropping $V_{in}-V_{out}$ and burning $(V_{in}-V_{out})\times I_{out}$ as heat. And because it's a feedback loop, it needs an output capacitor and a compensated loop to be stable. Dropout happens when the transistor is fully on and can't turn on any harder."
:::

::: technical
**Blocks.** Reference $V_{ref}$; divider $R_1,R_2$ giving $V_{FB}=V_{out}\dfrac{R_2}{R_1+R_2}$; error amplifier (gain $A_{ea}$); pass device $M_P$ (PMOS, source to $V_{in}$, drain to $V_{out}$); output capacitor $C_{out}$.

**Regulation.** For high loop gain, $V_{FB}\approx V_{ref}$:
$$V_{out}=V_{ref}\left(1+\frac{R_1}{R_2}\right)$$
Example: $V_{ref}=0.8$ V, $V_{out}=3.3$ V: $R_1/R_2=3.3/0.8-1=3.125$. With $R_2=10$ kΩ, $R_1=31.25$ kΩ. The nearest E96 value 31.6 kΩ gives $0.8(1+3.16)=3.328$ V (+0.85%).

**Loop gain.** $T=A_{ea}\cdot g_m\,(r_o\parallel R_L)\cdot\beta$ with $\beta=\dfrac{V_{ref}}{V_{out}}=\dfrac{R_2}{R_1+R_2}$. Closed-loop errors scale as $1/(1+T)$:
- Load regulation: $\dfrac{\Delta V_{out}}{\Delta I_{out}}=\dfrac{R_{out,OL}}{1+T_0}$
- Line regulation: $\dfrac{\Delta V_{out}}{\Delta V_{in}}\approx\dfrac{1}{(1+T_0)\,g_m r_o}$ roughly (for a PMOS pass device).

**Dropout.** For a PMOS, the gate swings down to ground when the loop demands maximum drive. At that limit $V_{in}-V_{out}=I\,R_{DS(on)}$ ([[q0277]]).

**Power.** $P_{pass}=(V_{in}-V_{out})I_{out}+V_{in}I_Q$ ([[q0282]]).

**Stability.** The loop has poles at the output ($1/(2\pi R_{out}C_{out})$, moving with load), at the gate, and at internal nodes, and a zero from the capacitor ESR. Different architectures put the dominant pole in different places, so each datasheet gives a stable capacitor range or ESR window.
:::

::: short
"It's a pass transistor in series with the load plus a feedback loop. A divider scales the output down to a feedback voltage, an error amplifier compares it with a reference and drives the pass transistor's gate. If the output sags, the amp turns the transistor on harder; if it rises, it backs off. In steady state the feedback equals the reference, so $V_{out}=V_{ref}(1+R_1/R_2)$. The transistor is a variable resistor that drops the excess voltage as heat, and it needs an output capacitor for stability."
:::

::: long
"An LDO is basically a regulated variable resistor between the input and the output.

The pieces are a pass transistor, usually a PMOS with the source on $V_{in}$ and the drain as the output, a voltage reference, a feedback divider from the output, and an error amplifier. The amplifier compares the divider voltage, $V_{FB}=V_{out}R_2/(R_1+R_2)$, to the reference and drives the transistor's gate.

Walk through a disturbance. Say the load current jumps, so the output sags. $V_{FB}$ drops below the reference, the error amp's output goes lower, the PMOS gate-source voltage gets bigger, the channel resistance falls, and more current flows to the output. $V_{out}$ climbs back. If the output overshoots, the amp raises the gate and shuts the transistor down a bit. The loop gain is high, so the amp forces the two inputs essentially equal, which gives $V_{out}=V_{ref}(1+R_1/R_2)$. For a 0.8 V reference and 3.3 V out, $R_1/R_2=3.125$.

The transistor drops the difference $V_{in}-V_{out}$ at the load current, so it dissipates $(V_{in}-V_{out})I_{out}$. At 5 V in, 3.3 V out and 500 mA that's 0.85 W, which is why I check thermals. And if $V_{in}$ falls so far that the PMOS gate is already at ground, the loop can't turn it on any harder: that's dropout, and the output just follows the input minus $I\times R_{DS(on)}$.

Finally, it's a feedback loop, so stability matters. The output capacitor forms a pole with the load, which moves as the load changes, and the capacitor's ESR can add a zero. That's why LDO datasheets specify a capacitor type, value range or an ESR window. Use the wrong one and the output rings or oscillates."
:::

::: terms
- **Pass element / pass transistor**: the series device that drops the excess voltage.
- **Error amplifier**: compares the feedback voltage with the reference and drives the pass device.
- **Bandgap reference**: temperature-stable voltage reference inside the LDO.
- **Feedback divider ($R_1$/$R_2$)**: sets $V_{out}=V_{ref}(1+R_1/R_2)$.
- **Loop gain ($T$)**: product of gains around the feedback loop. Errors shrink by $1+T$.
- **Line regulation**: change in $V_{out}$ for a change in $V_{in}$.
- **Load regulation**: change in $V_{out}$ for a change in $I_{out}$.
- **PSRR**: power-supply rejection ratio, how well $V_{in}$ ripple is suppressed at the output.
:::

::: exceptional
**An average answer** says "a transistor and an op-amp hold the output constant" and shows the divider equation.

**An exceptional answer**:
- Names each block and follows a disturbance around the loop *with polarity* (PMOS gate goes down, current goes up).
- Explains that the pass element is a **variable resistor** in the triode region (hence dropout is $IR_{DS(on)}$, and dissipation is $\Delta V\cdot I$).
- States the closed-loop equation and does a divider example.
- Connects loop gain to **line/load regulation and PSRR**: errors reduce by $1+T$, and PSRR degrades above the loop bandwidth.
- Knows why the output capacitor and ESR matter for stability and that load current moves the output pole.
- Mentions the difference between PMOS (source on $V_{in}$, low dropout, high-impedance output node, sensitive to $C_{out}$) and NMOS or PNP/NPN pass devices.
:::

::: mistakes
- **Wrong feedback polarity.** For a PMOS pass device the divider goes to the **non-inverting** input (output up should raise the gate to turn the PMOS off). For an NMOS source follower or NPN, the polarity flips.
- **Saying the transistor "is a switch".** In an LDO it works as a continuously adjusted resistor in the triode or saturation region, not a switch.
- **Forgetting the output capacitor** or using the wrong value or ESR. Many LDOs oscillate with an unspecified capacitor.
- **Using a reference voltage as the output voltage.** The reference is 0.6 to 1.25 V. The output equals $V_{ref}$ only for a unity-gain-feedback fixed part.
- **Believing regulation is perfect.** Finite loop gain gives finite load and line regulation, and bandwidth limits transient response and PSRR at high frequencies.
- **Ignoring thermal limits.** Everything above $V_{out}$ is dissipated in the pass device.
:::

Figure: A PMOS LDO. The error amplifier (EA) compares $V_{ref}$ (inverting input) with the divider's feedback voltage (non-inverting input) and drives the PMOS gate. If $V_{out}$ rises, $V_{FB}$ rises, the EA output rises, $V_{GS}$ of the PMOS shrinks and the transistor turns off a bit. That is **negative feedback**. The source is on $V_{in}$, the drain is the regulated output.

Follow one disturbance in numbers. Take $V_{out}=3.3$ V, $V_{ref}=0.8$ V, $\beta=0.242$. A load step makes $V_{out}$ dip by 5 mV. $V_{FB}$ falls by $0.242\times5\text{ mV}=1.2$ mV. With EA gain 1000 the gate voltage falls by 1.2 V (in a real part limited by supply and signal swing). The PMOS $V_{GS}$ becomes more negative, so its current rises sharply (square-law), and the output recovers. The loop gain does the work: the more gain you have, the smaller the sag needed to produce the same correction.

## Why the divider equation holds

The EA output is $V_G=A_{ea}(V_{FB}-V_{ref})$ (with appropriate polarity and level shifting). In equilibrium $V_G$ is whatever is needed to deliver the load current, which is finite, so $V_{FB}-V_{ref}=V_G/A_{ea}\to0$ for large $A_{ea}$. So
$$V_{FB}=V_{ref}\;\Rightarrow\;V_{out}=V_{ref}\frac{R_1+R_2}{R_2}=V_{ref}\left(1+\frac{R_1}{R_2}\right)$$
The divider is the same as in [[q0008]]; the loop just forces its midpoint to $V_{ref}$. For 3.3 V from a 0.8 V reference, the divider gain is 4.125, so $V_{out}$ is more sensitive to resistor mismatch than to the reference: 1% resistors can shift $V_{out}$ by up to about 1.5% in the worst case (the two resistors off in opposite directions: $R_1/R_2$ moves by 2%, and $\Delta V_{out}/V_{out}=\frac{R_1/R_2}{1+R_1/R_2}\times2\%=0.76\times2\%$). Fixed-output LDOs trim this internally to ±1% or better.

## Finite gain: load and line regulation, with numbers

The closed-loop output resistance is the open-loop output resistance divided by $1+T$:
$$R_{out,CL}=\frac{R_{out,OL}}{1+T_0}$$
Illustrative values (assumed, not from a datasheet): $A_{ea}=1000$, PMOS $g_m=0.5$ S, $r_o=100\ \Omega$, so $g_mr_o=50$, $\beta=0.242$:

$T_0=1000\times50\times0.242=12{,}100$ (81.6 dB), so $R_{out,CL}=100/12{,}101=8.3$ mΩ. A 100 mA load step would move the DC output by only 0.8 mV. The *transient* response is a different matter: the loop needs time to react, and the output capacitor supplies the step until it does.

## The pass device as a variable resistor

The PMOS carries $I_{out}$ while dropping $V_{in}-V_{out}$. Its effective resistance is $R_{pass}=(V_{in}-V_{out})/I_{out}$. At 5 V in, 3.3 V out, 0.5 A: $R_{pass}=3.4\ \Omega$. If load falls to 50 mA at the same input, the loop raises $R_{pass}$ to 34 Ω. When the load rises so that $R_{pass}$ would have to be below $R_{DS(on),min}$, the gate is at its limit and the regulator is in dropout ([[q0277]], [[q0279]]).

> [!NOTE]
> A PMOS in an LDO usually operates in **saturation** when the headroom is generous (it is a current source controlled by $V_{GS}$), and enters the triode region as headroom shrinks toward dropout. The "variable resistor" picture is exact in dropout and a good mental model elsewhere.

## Stability: why the output capacitor is in the loop

The loop gain has several poles. Three matter:

1. **Error-amp / gate pole**: set by the EA's output resistance and the pass transistor's gate capacitance (large for a big PMOS).
2. **Output pole**: $f_{out}=\dfrac{1}{2\pi R_{out}C_{out}}$ where $R_{out}=r_o\parallel R_{load}$. It *moves with load current*: a heavy load gives low $R_{out}$ and a high pole, and a light load gives a low-frequency pole.
3. **High-frequency parasitics**.

The output capacitor's ESR adds a zero at $f_z=\dfrac{1}{2\pi R_{ESR}C_{out}}$ that provides phase lead. Classic PNP/NPN LDOs *needed* a minimum ESR to make the loop stable, which is why old datasheets have an "ESR stability window" chart. Modern parts with an internal dominant pole are stable with low-ESR ceramics, but still specify a capacitance range.

For the same loop, lighten the load so the output pole moves from 10 kHz down to 1 kHz and the phase margin without help falls to about 6 degrees. This is why some LDOs are *least* stable at light load and need a minimum load current, and why transient tests are done at several loads.

## PSRR and the loop

PSRR is how much of the input ripple appears at the output. At low frequency it is roughly the loop gain, so it is large (60 to 80 dB). Above the loop bandwidth, the loop can no longer correct, and the rejection is set by the pass transistor's $C_{gd}$ and the output capacitor. This is why a well-chosen $C_{out}$ and an LDO with a fast loop matter for cleaning switching ripple at 500 kHz to a few MHz, and why headroom also matters (more headroom keeps the pass FET in saturation, with higher $r_o$ and PSRR).

## Other pass-device types

- **PMOS (shown)**: low dropout, no base current, gate high-impedance. Output pole at the drain, so $C_{out}$ and load set stability.
- **NMOS (source follower)**: low output impedance, fast, the output pole is pushed to high frequency, but the gate must be driven above $V_{out}+V_{GS}$, requiring a bias supply or charge pump.
- **PNP**: collector output, needs ESR for stability, base current $I_{out}/\beta$ goes to ground (high ground-pin current at heavy load).
- **NPN/Darlington**: emitter follower with the gate drive $2V_{BE}$ above the output, so dropout 1.5 to 2.5 V (a classic 78xx-type).
:::

::: applications
- **Clean analog rails** for ADCs, PLLs, RF front ends: fast loop, high PSRR, low noise.
- **Microcontroller rails** from a single cell: PMOS LDOs with microamp quiescent current.
- **Post-regulation** after a buck to remove ripple.
- **FPGA/SoC core and auxiliary rails**: LDOs with enable, power-good and tracking inputs.
- **Reference supplies** for sensors, where line regulation and temperature drift matter.
:::

::: assumptions
- The explanation assumes a **PMOS pass device with an internal reference and divider**. Fixed-voltage parts have the divider inside, and adjustable parts have an external one.
- Loop-gain numbers and pole locations are **illustrative**, not from a specific datasheet. Real LDOs differ in architecture (dominant-pole inside vs outside).
- **Steady-state DC analysis** unless stated. Transient and AC behavior depend on the compensation and $C_{out}$.
- Some LDOs use **current-mode** or **capacitor-free** architectures that change the stability story.
- Reference voltage values (0.6 to 1.25 V) are typical, and exact numbers vary by vendor.
:::

::: followups
### Why does the PMOS LDO's feedback go to the non-inverting input?
Because a PMOS turns *off* when its gate voltage rises. If $V_{out}$ is too high, we want the gate to rise, so the error amp's output must increase when $V_{FB}$ rises relative to $V_{ref}$. That is a non-inverting connection for $V_{FB}$. With an NMOS or NPN the polarity is reversed: output too high should lower the gate/base, so $V_{FB}$ goes to the inverting input.

### What sets the output voltage of an adjustable LDO, and what happens if $R_1$ is open?
$V_{out}=V_{ref}(1+R_1/R_2)$. If $R_1$ (top resistor) opens, $V_{FB}$ is pulled to ground by $R_2$, the amp sees an output that is "too low" and turns the pass device fully on, so $V_{out}\approx V_{in}$ minus the dropout. That can destroy the load, so some designs add a clamp or choose parts with feedback-open protection. If $R_2$ opens instead, $V_{FB}$ floats up with $V_{out}$ and the output is forced too low.

### How does load current change the loop's stability?
The output pole is at $1/(2\pi R_{out}C_{out})$ with $R_{out}=r_o\parallel R_L$. A light load makes the pole low and a heavy load pushes it high. In architectures where the output pole is not dominant, the worst phase margin sits at one extreme of the load range, which is why datasheets show stability across the load range and some parts require a minimum load.

### What does the output capacitor do in an LDO besides filter?
It supplies current during load steps while the loop reacts, sets the output pole in the loop, and its ESR sets a zero. A bigger $C_{out}$ improves transient droop ($\Delta V\approx\Delta I\,t_{response}/C_{out}$) and PSRR at high frequency, but it can also move the pole and degrade phase margin in parts designed for a particular capacitor range.

### Scenario: you replace the output cap of a working LDO with a smaller-case ceramic of the same nominal value and the output starts ringing. Why?
Check three effects. First, the new capacitor's DC-bias derating may leave far less effective capacitance (a 1 µF 0402 can fall below 0.3 µF at 3.3 V). Second, its ESR may be lower, removing the helpful zero. Third, the load pole has moved. Compare the effective $C$ and ESR against the datasheet's stable range and measure the loop or load-step response.
:::
