::: testing
Whether you can **predict the direction and size** of the error from the physics ($Z_0$ rises with dielectric height because $C'$ falls), compute the mismatch ($\Gamma$, return loss) for real numbers, decide **whether it matters at all** (electrical length vs edge rate), and then offer a **ranked set of fixes** from a practical engineer: re-spin if you can, rework or live with it using termination and slower edges, and what each fix costs. It is a debugging question as much as a theory one.
:::

::: why
Fabs do mis-build stackups, and dielectric thickness is the most common impedance error. A candidate who panics ("scrap the board") or who only says "make the trace wider" misses the options an experienced engineer weighs: severity, timeline, cost. It also tests whether you understand that on a two-layer board the trace and its return plane are separated by the whole core, so that is the dimension that sets $Z_0$.
:::

::: concepts
- **$Z_0$ vs dielectric height**: $Z_0$ rises with $h$ since $C'$ falls and loop $L'$ rises. See [[q0524]].
- **Reflection coefficient and return loss**: $\Gamma=(Z_0'-Z_0)/(Z_0'+Z_0)$. See [[q0526]].
- **Electrical length criterion**: reflections matter if $t_d>t_r/6$. See [[q0514]].
- **Termination**: matching source/load to the actual line. See [[q0532]], [[q0533]].
- **Two-layer boards**: the core thickness (0.8–1.6 mm) is the dielectric height. See [[q0474]].
- **Rework options**: widen or add copper, adjust terminators, slow the edges.
:::

::: answer
"Impedance goes up. The trace's capacitance to the ground plane is inversely related to the dielectric thickness, and the loop inductance goes up as the return gets further away, so Z0 which is square root of L over C increases. For a typical 50 ohm trace it's about 45 percent. For example, if I designed a 1.52 millimetre wide trace for 50 ohms on a 0.8 millimetre core and the fab gave me 1.6 millimetres, that trace is now about 73 ohms. The delay barely changes, a couple of percent, because that's set by the dielectric constant.

Against a 50 ohm driver or load, that's a reflection coefficient of 0.18, about 18 percent of the edge bouncing back, 15 dB return loss. Whether that matters depends on how long the trace is compared to the edge. If the trace delay is less than a sixth of the rise time, I might just live with it.

Fixes, in order of preference: if there's time and budget, send it back or remake it, since it's the fab's error. Otherwise I look at the electronics: terminate for the actual line. For a digital line I choose the series or parallel resistor for 73 ohms rather than 50; for RF I'd add a matching section. I can slow the edges with a larger series resistor or lower drive strength. For a few critical nets I could hand-rework by soldering copper foil on top of the trace to widen it, to about 3 millimetres, or adding grounded copper strips alongside to lower the impedance, but that's a hack."
:::

::: technical
**Physics.** For microstrip with fixed $w$, $Z_0\propto\dfrac{h}{w_{eff}\sqrt{\varepsilon_{eff}}}$ roughly. Doubling $h$ with fixed $w$ on a 50 Ω trace ($w/h\approx1.9$) raises $Z_0$ by about 45%: the model gives $50.0\to72.6\ \Omega$ for $w=1.517$ mm, $h$: 0.8→1.6 mm (FR-4, 1 oz copper, $\varepsilon_r=4.3$). The same ratio shows for $h=0.2\to0.4$ mm ($50.0\to72.3\ \Omega$) because, apart from the small copper-thickness term, only $w/h$ matters. The percentage depends on $w/h$: about +35% at $w/h=1$ and +20–30% for narrow, high-impedance traces ($w/h\le0.5$), where $Z_0$ grows only logarithmically with $h$.

**Delay.** $\varepsilon_{eff}$ shifts from 3.22 to 3.06, so $t_{pd}$ falls by 2.5% (152→148 ps/in); negligible.

**Mismatch.** Against 50 Ω: $\Gamma=(72.6-50)/(72.6+50)=0.184$, transmission $\tau=1.18$; return loss $-20\log0.184=14.7$ dB. Double reflections are $\Gamma_s\Gamma_L$ and decay; with a matched source $\Gamma_s\approx0$ only one reflection per end.

**Does it matter?** Compare line delay $t_d$ with $t_r/6$. A 50 mm trace has $t_d\approx295$ ps. With $t_r=2$ ns ($t_r/6=333$ ps) it's electrically short: ignore. With $t_r=500$ ps ($83$ ps) it's long: expect an 18% reflection.

**Fix ladder.**
1. *Re-fabricate/credit*: manufacturer error; request replacement with the correct stackup. Cleanest.
2. *Adapt terminations*: use $Z_0=72.6\ \Omega$: series $R_s=72.6-R_{out}$ (e.g. 20 Ω driver → 51–56 Ω resistor), parallel $R=75\ \Omega$ (nearest value), differential termination rescaled too ($Z_{diff}$ rises somewhat less, roughly +20–30%, because halving $s/h$ tightens the pair's coupling).
3. *Slow the edges / reduce drive*: the small-signal reflections shrink and lines become electrically short.
4. *Shorten or remove sensitive traces* by rework (jumper wires with twisted/coax) for the critical nets.
5. *Widen the trace*: need $w\approx3.07$ mm for 50 Ω at $h=1.6$ mm ($Z_0(1.517\text{ mm})=72.6$ Ω); copper tape soldered along the trace works for RF test boards.
6. *Add coplanar grounds*: grounded copper strips close alongside the trace, stitched to the plane, lower $Z_0$ (grounded coplanar waveguide), with gap tuned by measurement.
7. *Redesign matching network* (RF): add an impedance-transforming section or a pi/L matching at the ports.
8. *Measure*: TDR of the real board (and of the coupon) to confirm what was actually built; the fab's stackup report gives the as-built $h$.
:::

::: long
"Impedance goes up. For a microstrip, Z0 rises with the ratio of dielectric height to trace width. A thicker substrate means less capacitance between the trace and the ground plane and more loop inductance, so square root of L over C increases. Doubling the height at the same width raises it by about 45 percent. For example, say I designed a 1.52 millimetre trace for 50 ohms on a 0.8 millimetre core, and the fab built it with 1.6. Using a microstrip model, that trace is now 72.6 ohms. The propagation delay hardly changes, about 2 percent, because it depends on the dielectric constant not the height.

Against a 50 ohm driver or load, that's a reflection coefficient of 0.18: 18 percent of the incident wave reflects, about 15 dB return loss. Whether it hurts depends on the edge rate versus the trace length. If the one-way delay is shorter than a sixth of the rise time, the line is electrically short and I'll barely notice. If it's longer, I'd see ringing and overshoot.

What to do about it, in order. The proper fix is to get the board remade: it's the manufacturer's error. If I can't wait, I deal with it electrically. I recompute the terminations for 73 ohms, a series resistor of the line impedance minus the driver impedance, or a 75 ohm parallel termination. I can slow edges with a bigger series resistor or lower drive strength to make the lines electrically short. For a few critical nets I can rework the board: solder copper foil on top of the trace to widen it to about 3 millimetres, which brings 1.6 millimetre substrate back to 50 ohms, or add grounded copper strips next to the trace to create a coplanar waveguide. For RF I'd add a matching network. And I'd verify with a TDR, because I'd want the as-built number, not the one I assume."
:::

::: terms
- **Dielectric height ($h$)**: distance from trace to reference plane; on a 2-layer board, the core thickness.
- **Return loss**: $-20\log|\Gamma|$.
- **Reflection coefficient ($\Gamma$)**: $(Z_L-Z_0)/(Z_L+Z_0)$ at an impedance step.
- **Grounded coplanar waveguide**: trace with ground pour on the same layer plus a plane below.
- **Series / parallel termination**: resistor at source / load to match the line. See [[q0533]].
- **Impedance coupon**: test structure measured by TDR to verify as-built impedance.
- **Electrical length**: $t_d/t_r$ criterion for whether reflections matter.
- **Matching network**: L/pi/quarter-wave section to transform impedances.
:::

::: exceptional
An average answer says "impedance goes up; make the traces wider." An exceptional answer:
- Explains **why** (capacitance falls, inductance rises) and computes **by how much** (≈ +45%, 50→72.6 Ω) with $\Gamma=0.18$ and 14.7 dB return loss.
- Notes **delay is almost unchanged** (≈ −2.5%) and that only ratio $w/h$ matters.
- Asks **whether it matters** (electrical length vs $t_r$) before fixing.
- Gives a **ranked fix list**: remake, re-terminate for 73 Ω, slow edges, rework (widen to ≈3.07 mm, add coplanar grounds), matching network, and a **TDR verification**.
- Mentions that the fab's error entitles a **re-run** and that stackup reports and coupons should have caught it.
:::

::: mistakes
- **Saying impedance falls.** Thicker dielectric means higher $Z_0$.
- **Believing the delay doubles.** Velocity depends on $\varepsilon_{eff}$, not on height.
- **"Just widen the traces on the CAD file."** The board is already built; and the new width would be about 3 mm, not a small tweak.
- **Ignoring electrical length.** Short lines and slow edges tolerate big mismatches.
- **Fixing only one end.** Re-terminate both ends consistently for 73 Ω, and remember differential impedance also scales.
- **Not measuring.** The as-built $h$ may differ from "twice"; use TDR or the fab's report.
:::

::: deep
## Direction and size

For microstrip, $C'\approx\varepsilon_0\varepsilon_{eff}w_{eff}/h$ falls roughly as $1/h$ and $L'$ rises, so
$$Z_0=\sqrt{L'/C'}\ \propto\ \frac{h}{w_{eff}\sqrt{\varepsilon_{eff}}}$$
roughly (the exact dependence is logarithmic for narrow traces). The model used in the lab gives, for FR-4 ($\varepsilon_r=4.3$, 1 oz copper):

|---|---|---|---|---|---|
| As designed | 1.517 mm | 0.8 mm | 50.0 Ω | 3.22 | 152 ps/in |
| As built | 1.517 mm | 1.6 mm | 72.6 Ω | 3.06 | 148 ps/in |
| Re-widened | 3.07 mm | 1.6 mm | 50.0 Ω | – | – |

## What the mismatch costs

$\Gamma=(72.6-50)/(72.6+50)=0.184$: a wave entering the 72.6 Ω line from a 50 Ω section is transmitted with $\tau=1+\Gamma=1.184$; one leaving the line into a 50 Ω load sees $\Gamma=-0.184$ and $\tau=0.816$. Return loss is 14.7 dB. If both ends are 50 Ω terminations:
- The source launches into 72.6 Ω: divider $72.6/(72.6+R_s)$.
- At the 50 Ω load the wave reflects with $\Gamma=-0.184$ (note: line 72.6 into load 50 gives a *negative* reflection: $(50-72.6)/(122.6)=-0.184$), so the signal undershoots slightly then settles. At the source end, with source 50 Ω, $\Gamma_s=(50-72.6)/122.6=-0.184$ again; double bounce $0.034$ (3.4%).
The "18% echo" is the first-order effect. In an RF chain, it's a 15 dB return loss: VSWR $=(1+0.184)/(1-0.184)=1.45$.

## Does it matter? Electrical length

A 50 mm trace has $t_d=50\times5.9=295$ ps. The criterion $t_d<t_r/6$:
- $t_r=2$ ns: limit 333 ps → electrically short; the reflection merges into the edge; ignore.
- $t_r=500$ ps: limit 83 ps → long; the echo is visible.
- $t_r=100$ ps: limit 17 ps → long; echo plus ringing.
For a slow SPI/I²C/UART board, nothing to do. For USB 2.0 high-speed (480 Mb/s, 90 Ω differential pairs that would rise to roughly 110–120 Ω) or RF at 100s of MHz, it matters.

## Ranked fixes

1. **Have it remade (fab's error).** Document with the stackup report and a TDR of the coupon; most fabs will re-run. It costs time but nothing else.
2. **Re-terminate for the real $Z_0$.** For a series-terminated digital line: $R_s=72.6-R_{out}$. For a 20 Ω driver: $R_s=52.6$ → 51 Ω or 56 Ω. For parallel termination: 75 Ω (E24: 75 Ω). Resistor changes are cheap rework.
3. **Reduce edge rate.** A larger series resistor or lower drive-strength setting, or an RC filter; keeps $t_d<t_r/6$.
4. **Shorten critical nets** with jumper wires or coax rework.
5. **Widen the trace by soldering copper tape/foil along it** to about 3.07 mm: works for a handful of RF or clock nets; consider the discontinuity at the tape ends (taper them). Only practical for a few nets.
6. **Grounded coplanar strips**: tape grounded strips along both sides with a gap; stitched to the ground plane. Lowers $Z_0$ (the solution is empirical: tune using a TDR or VNA).
7. **Impedance-transforming sections or matching networks (RF):** a quarter-wave section of $\sqrt{50\times72.6}=60.2$ Ω would match the 72.6 Ω line to 50 Ω at one frequency, or use a pi/L network.
8. **Redesign** for the actual stackup in the next revision and request an impedance coupon with TDR report on every lot.

## Differential pairs on the same error

If the error occurs on a differential pair designed for 100 Ω, the differential impedance rises, but by less than the single-ended 45%: each trace's $Z_0$ goes up, while halving $s/h$ makes the two traces couple more tightly, which pulls $Z_{diff}$ back down. The IPC-2141A edge-coupled estimate used in the lab gives roughly 120–130 Ω. A 100 Ω termination then yields $\Gamma_{diff}\approx(100-120)/(100+120)=-0.09$ to $(100-130)/230=-0.13$ at the receiver. The only electrical fixes are re-terminating to ~140 Ω if the receiver permits (many have fixed on-die 100 Ω) or re-fabrication. This is why high-speed differential boards are not worth rescuing: re-spin.

> [!UNCERTAIN]
> The "+45%" figure is for a 50 Ω FR-4 microstrip ($w/h\approx1.9$). The rise depends on $w/h$: about +35% at $w/h=1$, +20–30% for narrow high-impedance traces, and more than 50% for very wide ones. Differential-pair figures use the IPC-2141A approximation and are rougher still. Copper tape rework gives results that depend on adhesive, edge discontinuities and solder joints; verify with a TDR.

## Real hardware behaviour

- **What really goes wrong in fabs:** prepreg flow and lamination thickness variation, wrong core selected, or ignoring the requested stackup. Dielectric tolerance ±10% is normal; ×2 is a mistake, not a tolerance.
- **Two-layer boards** have large $h$ (0.8–1.6 mm), so 50 Ω traces are 1.5–3 mm wide; that's why designers use thin cores or four layers for controlled impedance.
- **Evidence:** a TDR of the test coupon the fab includes on the panel immediately shows 72 vs 50 Ω.
:::

::: applications
- **RF test boards and microstrip filters** built on the wrong core: re-tuned or re-ordered.
- **Clock and USB boards** where the fab's stackup error is discovered by a TDR coupon.
- **Prototype bring-up**: choosing termination values empirically after measuring the real impedance.
- **Controlled-impedance quotes**: specifying coupons, tolerance and a stackup report on the fab note.
- **Antenna feed lines** adjusted with copper foil to restore 50 Ω.
:::

::: assumptions
- Assumes a **two-layer microstrip over a bottom ground plane**; "substrate layer" is the core between trace and plane. If there is a plane on both sides or a 4-layer stackup, the effect of doubling one dielectric is smaller or different.
- The original thickness is unspecified; the example uses 0.8→1.6 mm. Because (apart from copper thickness) only $w/h$ matters, any 50 Ω FR-4 microstrip ($w/h\approx1.9$) shows the same ~45% rise; narrower, higher-impedance traces rise less (20–35%).
- Numbers come from the Hammerstad–Jensen model for FR-4 and 1 oz copper; real boards vary ±5%.
- "Twice as thick" is treated exactly; real errors may be smaller.
- A different answer applies if the line is a **stripline** (both dielectrics change) or a very **short** trace (ignore).
:::

::: followups
### What if the trace was a differential pair designed for 100 Ω?
$Z_{diff}$ rises, but less than the single-ended 45%: to roughly 120–130 Ω, because the spacing-to-height ratio $s/h$ halves, so the traces couple more tightly, which partly offsets the higher single-ended impedance. That is still 20–30% out of spec for any standard link; I'd re-fabricate. Re-terminating doesn't work if the receiver has a fixed 100 Ω on-die termination.

### Would you rather widen the trace or add coplanar ground?
Widening needs a 3 mm trace, which is hard to rework and creates stub-like steps at its ends. Coplanar ground strips can be added more neatly on a few traces, but the result needs measurement. Both are rework hacks; re-fab is preferred for more than a few nets.

### What would you check first on receiving the board?
The TDR coupon and the fab's stackup/impedance report to confirm what was built, then measure a trace with a TDR. If the coupon reads 72 Ω, the error is systematic and the fab should re-run; if only some traces, it could be etch width.

### How does the velocity change?
Slightly: $\varepsilon_{eff}$ drops from 3.22 to 3.06 as less of the field is trapped in the dielectric, so delay falls 2.5%. Length matching is essentially unaffected.

### Could the error be useful?
In a rare case, if you'd designed a 75 Ω line (e.g. video), a thicker substrate might bring a narrow 50 Ω trace to 73 Ω without changing the width. Don't count on it.
:::

::: interpretations
"Substrate layer" is read as the **dielectric between the signal trace and its reference plane** (the core of a two-layer board). The question doesn't give the nominal thickness, so I use 0.8→1.6 mm as a worked example and note that the percentage change depends only on $w/h$. "Fix" is read as ways to recover the intended behaviour with the board in hand, not just a re-order.
:::
