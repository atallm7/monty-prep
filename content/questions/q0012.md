::: testing
Whether you can analyze an op-amp circuit with a **method** rather than by pattern-matching to memorized gain formulas. The interviewer is checking:

1. You know the two golden rules of an ideal op-amp *with negative feedback*: the inputs are at the same voltage (virtual short) and draw no current.
2. You can apply them with KCL at the inverting node to get the inverting, non-inverting, summing and integrator results.
3. You know when the ideal model breaks: finite gain-bandwidth, slew rate, output swing, input bias and offset.

Strong candidates check negative feedback *first*, because the golden rules are false without it.
:::

::: why
The op-amp is the workhorse of analog design: sensor front ends, ADC drivers, filters, current-sense amplifiers, compensators in power supplies. Almost every analog problem is "put a few resistors around an op-amp and solve", so this is the fastest way for an interviewer to see if you can reason about a circuit. It also leads naturally to feedback, bandwidth and stability, where deeper candidates separate themselves.
:::

::: concepts
- **Ideal op-amp**: infinite open-loop gain, infinite input impedance, zero output impedance, infinite bandwidth.
- **Negative feedback**: output is fed back to the inverting input, so the amplifier adjusts its output until $V_+ - V_- \approx 0$. This gives the **virtual short**.
- **KCL at the summing node** ([[q0004]]): since no current enters the input, the current through the input resistor all flows through the feedback resistor.
- **Voltage divider** ([[q0008]]): the non-inverting amplifier is a feedback divider in disguise.
- **Gain-bandwidth product (GBW)**: closed-loop bandwidth is about $GBW/\text{gain}$ for a voltage-feedback op-amp.
- **Slew rate and saturation**: the output can only change by so many V/µs and cannot exceed the supply rails.
:::

::: answer
"My approach is always the same. First I check there's negative feedback, meaning the output goes back to the inverting input. If so, the op-amp is going to work to keep the two inputs at the same voltage, and the inputs draw essentially no current. Then it's just KCL.

Take the inverting amplifier, input resistor R1, feedback resistor Rf, and the plus input grounded. The minus input is a virtual ground at 0 V, so the current in is Vin over R1. None of it can go into the op-amp, so all of it flows through Rf, which drops Vin times Rf over R1 and the output sits at minus that. So gain is minus Rf over R1. With 1k and 10k that's minus 10.

For the non-inverting one, the minus input is held at Vin, and Rf and R1 form a divider from the output, so Vin equals Vout times R1 over R1 plus Rf, giving gain 1 plus Rf over R1. A buffer is the special case with gain of one.

The same trick gives the summing amp, difference amp, and with a capacitor in the feedback path, an integrator. Then I'd mention the real limits: the output can't go past the rails, the closed-loop bandwidth is the gain-bandwidth product divided by the gain, and the slew rate limits large high-frequency signals."
:::

::: technical
**Rules** (ideal, negative feedback): (1) $V_+ = V_-$; (2) $I_+ = I_- = 0$.

**Inverting amplifier** ($V_+ = 0$): KCL at $V_-$: $\dfrac{V_{in}-0}{R_1} = \dfrac{0-V_{out}}{R_f}$, so
$$A_v = -\frac{R_f}{R_1},\qquad R_{in} = R_1.$$

**Non-inverting amplifier**: $V_- = V_{out}\dfrac{R_1}{R_1+R_f} = V_{in}$, so
$$A_v = 1+\frac{R_f}{R_1},\qquad R_{in}\to\infty.$$

**Buffer** ($R_f = 0$, $R_1=\infty$): $A_v = 1$.

**Summing amplifier**: $V_{out} = -R_f\sum V_i/R_i$.

**Difference amplifier** (matched $R_1/R_2 = R_3/R_4$): $V_{out} = \dfrac{R_f}{R_1}(V_2 - V_1)$.

**Integrator** (R in, C in feedback): $V_{out}(t) = -\dfrac{1}{RC}\int V_{in}\,dt$.

**Differentiator**: $V_{out} = -RC\,\dfrac{dV_{in}}{dt}$ (needs a small series R to be stable).

**Real limits**
- Closed-loop bandwidth $f_{-3dB}\approx GBW / A_{CL}$ (non-inverting gain $1+R_f/R_1$).
- Large-signal bandwidth (full-power): $f_{max} = SR/(2\pi V_p)$.
- Output limited to the rails: $V_{out}\le V_{CC}-V_{sat}$.
- Input bias current $I_B$ creates an offset $I_B R$; input offset voltage $V_{os}$ is amplified by the noise gain.

Example: $R_1 = 1$ kΩ, $R_f = 10$ kΩ, $V_{in} = 0.3$ V: inverting gives $-3$ V; non-inverting gives $+3.3$ V ($11\times0.3$).
:::

::: short
"First check for negative feedback. If it's there, the op-amp holds both inputs at the same voltage and they draw no current, so I just do KCL at the inverting node. For an inverting amp the input current Vin over R1 flows through Rf, so gain is minus Rf over R1. For a non-inverting amp the feedback divider sets the inverting node equal to Vin, so gain is one plus Rf over R1. Same method for summing amps and integrators. Then I'd check real limits: rails, gain-bandwidth, and slew rate."
:::

::: long
"I treat an op-amp circuit as a two-step process. Step one: is there negative feedback? Is some path from the output back to the inverting input? If yes, the very high open-loop gain forces the difference between the inputs to almost zero, so the two inputs sit at the same voltage, and the inputs themselves draw essentially no current. Step two: write KCL at the inverting node and solve.

For the inverting amplifier, the plus input is grounded so the minus input is a virtual ground. The current through R1 is Vin over R1, and it all flows through Rf, so Vout is minus Vin times Rf over R1. Input resistance is just R1, which is a limitation. With a 1k and a 10k I get minus ten.

For the non-inverting amplifier, the minus input is the middle of a divider from Vout to ground. Setting that equal to Vin gives gain one plus Rf over R1. The input impedance is basically the op-amp's own, which is huge.

Extending it, a summing amplifier is just several input resistors into the same node, so the currents add. An integrator replaces Rf with a capacitor, so the current charges the capacitor and Vout is minus one over RC times the integral of Vin. I'd mention it needs something to reset or a feedback resistor in parallel with the cap, or input offset will integrate until it hits the rail.

Finally, the real-world check. The output can't exceed the supply rails, so if my calculated Vout is beyond them the amp clips. The closed-loop bandwidth is the gain-bandwidth product divided by the gain, so a 1 megahertz part with a gain of 11 has about 90 kilohertz. And the slew rate sets how fast a large signal can swing, so full-power bandwidth is slew rate over two pi times peak amplitude."
:::

::: terms
- **Virtual short / virtual ground**: with negative feedback the two inputs are at (almost) the same voltage; if one is grounded the other is a "virtual ground".
- **Open-loop gain $A_{OL}$**: the amplifier's gain without feedback (typically $10^5$–$10^6$ at DC).
- **Closed-loop gain $A_{CL}$**: gain set by the feedback network.
- **Loop gain**: $A_{OL}\beta$ where $\beta$ is the feedback fraction; errors scale as $1/(1+A_{OL}\beta)$.
- **Gain-bandwidth product (GBW)**: the frequency where open-loop gain falls to 1; $A_{CL}\cdot BW\approx GBW$.
- **Slew rate (SR)**: the maximum $dV_{out}/dt$ in V/µs.
- **Input bias / offset**: small DC currents and voltage errors at the inputs.
- **Rail-to-rail**: output (and sometimes input) can swing close to the supply rails.
:::

::: exceptional
**An average answer** recites $-R_f/R_1$ and $1+R_f/R_1$.

**An exceptional answer**:
- States the golden rules *and* their precondition: negative feedback.
- Derives gain by KCL at the summing node rather than quoting it.
- Gives input and output impedances (inverting: $R_{in}=R_1$; non-inverting: very high).
- Explains the non-inverting circuit as a feedback divider and the "noise gain" idea.
- Checks real constraints: saturation, GBW/gain, slew rate, bias current.
- Can flip it around: "if the output is at a rail, the virtual short no longer holds, so either feedback is broken or you are clipping".
:::

::: mistakes
- **Applying the virtual short without negative feedback.** A comparator (no feedback) or positive-feedback Schmitt trigger does *not* have $V_+=V_-$.
- **Mixing up the gain sign.** Inverting is $-R_f/R_1$; the non-inverting gain is never below 1.
- **Forgetting $R_{in} = R_1$ for the inverting amp.** A low $R_1$ loads the source.
- **Ignoring saturation.** A gain of $-10$ on a 1.5 V input with ±12 V rails is fine, but on a 5 V input it clips at about $-11$ V.
- **Integrator without DC feedback.** Any offset will ramp the output to a rail.
- **Using the closed-loop gain as the GBW rule on a current-feedback amplifier.** CFA bandwidth is largely set by $R_f$, not by gain.
:::

::: deep
## The idea in one paragraph

An op-amp is a differential amplifier with huge gain $A_{OL}$: $V_{out} = A_{OL}(V_+ - V_-)$. With $A_{OL} = 10^5$ and an output limited to ±12 V, the differential input to stay in the linear region is below $120\ \mu V$. If you add a path that returns a fraction of the output to $V_-$, the output moves until the inputs nearly match. This is **negative feedback**; the result is that the circuit gain is set by passive resistor ratios, not by the amplifier's drifting gain.

Exactly: with feedback fraction $\beta$ (for the non-inverting amplifier $\beta = R_1/(R_1+R_f)$):
$$A_{CL} = \frac{A_{OL}}{1+A_{OL}\beta}\;\xrightarrow{A_{OL}\to\infty}\;\frac{1}{\beta} = 1+\frac{R_f}{R_1}.$$
For $A_{OL}=10^5$ and $1/\beta = 11$, the error is about $11/10^5 = 0.011\,\%$, which is why the ideal model works so well at DC.

KCL at the inverting node, using $I_- = 0$ and $V_- = V_+ = 0$:
$$\frac{V_{in}}{R_1} + \frac{V_{out}}{R_f} = 0 \;\Rightarrow\; V_{out} = -\frac{R_f}{R_1}V_{in}.$$

## Non-inverting amplifier and the buffer

$V_+ = V_{in}$, and $V_- = V_{out} R_1/(R_1+R_f)$. Setting them equal gives $V_{out}/V_{in} = 1 + R_f/R_1$. Because the signal goes straight to the high-impedance $+$ input, input resistance is enormous (typically MΩ to TΩ for CMOS/JFET inputs). If $R_f = 0$ the gain is 1: a **voltage follower**. It does not amplify voltage, it isolates: it presents a high impedance to the source and a low impedance to the load. That's the fix for the loaded divider in [[q0008]].

## Summing and difference

For $N$ inputs into the same virtual-ground node, each branch current $V_i/R_i$ adds and flows through $R_f$:
$$V_{out} = -R_f\left(\frac{V_1}{R_1}+\frac{V_2}{R_2}+\dots\right).$$
This is a DAC building block (binary-weighted resistors). The difference amplifier uses superposition: the inverting path gives $-\frac{R_f}{R_1}V_1$ and the non-inverting path, through the $R_3/R_4$ divider, gives $\frac{R_4}{R_3+R_4}\frac{R_1+R_f}{R_1}V_2$. With $R_f/R_1 = R_4/R_3$ the result is $\frac{R_f}{R_1}(V_2-V_1)$; its CMRR depends on resistor matching (1 % resistors give ~34 dB or about 50:1 worst case).

## Integrator and differentiator

With a capacitor in feedback, $I = V_{in}/R = -C\,dV_{out}/dt$, so
$$V_{out}(t) = -\frac{1}{RC}\int_0^t V_{in}\,dt' + V_{out}(0).$$
With $R=10$ kΩ, $C = 10$ nF: $RC = 100\ \mu s$. A 1 V DC input ramps the output at $-10$ V/ms, so with ±12 V rails it saturates in 1.2 ms. This is why practical integrators add a large resistor across C (a leaky integrator) or reset switch. See the op-amp lab below.

## Real op-amps: what breaks the ideal answer

**Gain-bandwidth.** A typical voltage-feedback op-amp's open-loop gain falls at $-20$ dB/dec, so $A_{OL}(f)\approx GBW/f$. The closed-loop bandwidth is where $A_{OL}\approx 1/\beta$: $f_{-3dB}\approx GBW\cdot\beta = GBW/(1+R_f/R_1)$. With $GBW = 1$ MHz and a gain of 11, that is 91 kHz. For the inverting amp use the *noise gain* $1+R_f/R_1$, not the signal gain $R_f/R_1$.

**Slew rate.** A sine of amplitude $V_p$ needs $dV/dt$ up to $2\pi f V_p$. With $SR = 1$ V/µs and $V_p = 10$ V, the maximum undistorted frequency is $SR/(2\pi V_p) = 15.9$ kHz, well below the small-signal bandwidth.

**Offsets.** Input offset voltage $V_{os}$ (µV to mV) is multiplied by the noise gain; bias currents $I_B$ flowing through the resistors create extra error voltage. A matching resistor on the other input cancels the average bias-current error in a bipolar op-amp.

**Output swing and load.** Non-rail-to-rail op-amps stop 1–2 V from each rail; rail-to-rail outputs approach the rails with light loads only. A heavy load or capacitive load can also cause instability, which is a topic of its own.

> [!TIP]
> Quick sanity check for any op-amp problem: if the algebra gives an output beyond the supply rails, the actual output is at the rail and the virtual short is violated.

## A worked example

Design: scale a 0 to 0.5 V sensor signal to 0–3.3 V for an ADC, using a single 3.3 V supply op-amp. Needed gain: $3.3/0.5 = 6.6$ (practically 6.2 to leave headroom). Non-inverting: $1+R_f/R_1 = 6.2\Rightarrow R_f/R_1 = 5.2$; choose $R_1 = 10$ kΩ, $R_f = 52$ kΩ (51.1 kΩ standard gives 6.11). Max output = $0.5\times 6.11 = 3.06$ V, which requires a rail-to-rail output op-amp (a standard op-amp would clip about 1 V below the rail). Bandwidth: for a 10 kHz signal, the GBW must be several times $6.11\times10$ kHz = 61 kHz; a 1 MHz GBW part gives 164 kHz bandwidth. Fine.

> [!UNCERTAIN]
> Current-feedback amplifiers and chopper/zero-drift amplifiers do not follow the simple "GBW divided by gain" model exactly; check the datasheet for those.
:::

::: applications
- **Sensor signal conditioning**: a thermocouple or strain-gauge bridge is amplified by an instrumentation amplifier (built from three op-amps).
- **ADC drivers and anti-alias filters**: active filters like the Sallen–Key use op-amps to provide gain and Q ([[q0010]]).
- **Transimpedance amplifiers** for photodiodes: an inverting amp with a feedback resistor converts photocurrent to voltage.
- **Current-sense amplifiers** in motor drivers and power supplies, measuring a small drop across a shunt.
- **Regulator compensators**: the error amplifier in a switching regulator is an op-amp/OTA with an RC feedback network.
- **Audio mixers** use summing amplifiers; **PID controllers** use integrators and differentiators.
:::

::: assumptions
- **Negative feedback is present** and the loop is stable. With positive feedback or no feedback the virtual short fails (comparator, Schmitt trigger).
- **Ideal op-amp** for the first pass: infinite gain, zero offset, infinite input impedance. The real-limits paragraph shows what changes.
- **Linear region**: the output within the rails and below the slew limit.
- **Resistors are ideal and matched.** For a difference amplifier, mismatch limits CMRR.
- **Dual supply vs. single supply**: with a single supply, "ground" is a bias (e.g. mid-supply) and the AC-coupled gain formulas change accordingly.
- If the interviewer gives a transistor-level or current-feedback amplifier, the rules change; ask.
:::

::: followups
### What is the gain of a non-inverting amplifier with Rf = 47 kΩ and R1 = 4.7 kΩ, and what is the output for 0.25 V input?
$A_v = 1 + 47/4.7 = 11$, so $V_{out} = 2.75$ V. With a ±5 V supply there is no clipping. The closed-loop bandwidth of a 10 MHz GBW amplifier would be about 910 kHz.

### Why does the inverting node become a "virtual ground"?
Because the open-loop gain is huge, any non-zero difference between inputs would produce an enormous output. The feedback drives the output to whatever value makes $V_-=V_+$. With $V_+=0$, $V_- \approx 0$, but no current actually goes to ground: it's all steered through $R_f$.

### What happens to the integrator if the input has a 5 mV DC offset?
With $RC = 100\ \mu s$ the output ramps at $-5\text{ mV}/100\ \mu s = -50$ V/s and hits the rail within a few hundredths of a second. The fix is a feedback resistor across $C$ (which makes a low-pass at $1/(2\pi R_f C)$) or a reset.

### An op-amp with 10 MHz GBW is configured for a gain of 100. What bandwidth do you get, and what do you do if you need 500 kHz?
$f_{-3dB}\approx 10\text{ MHz}/100 = 100$ kHz. To reach 500 kHz at gain 100 you need GBW above about 50 MHz, or two cascaded stages of gain 10 each (each with 1 MHz bandwidth, combined about 640 kHz for the 10 MHz part).

### What if the output sits at +12 V no matter what the input does?
It is saturated: either the input exceeds range, the loop is broken (feedback resistor open, wrong polarity so it's positive feedback), the op-amp input is outside the common-mode range, or the offset is amplified in an integrator. Check the voltage between the inputs: a big difference means it's not in negative feedback.

### Why is the bandwidth of an inverting amplifier with gain -10 set by a factor of 11 and not 10?
The loop gain depends on the feedback fraction $\beta = R_1/(R_1+R_f) = 1/11$, which is the same as for a non-inverting amp. The bandwidth is $GBW\cdot\beta = GBW/11$. The signal gain is $-10$, but the **noise gain** (the gain seen by an error at the input terminals) is $1+R_f/R_1 = 11$. So a 1 MHz part gives about 91 kHz, not 100 kHz.
