::: testing
Whether you can answer "sourced from where?" at two levels without contradicting yourself. **Charge/current path:** the inductor current is a loop. In the off state the loop is ground → freewheel diode (or low-side FET) → switch node → inductor → output node → load/capacitor → ground, and the input supply is *not* in it. **Energy:** the power delivered is paid for by the magnetic energy stored in the inductor during the on time. A strong answer separates "what path carries the current" from "what supplies the energy", says that the input does not supply anything in the off state, and ties it to the pulsed input current and the need for $C_{in}$.
:::

::: why
The question confuses a lot of students ("the current comes from the inductor", "from the capacitor", "from ground?") because current is continuous and charge has to come from somewhere. Getting it right explains the diode/low-side FET current, why the input current is pulsed, why the average input current is only $D I_{out}$, what the output capacitor does and does not do, and why synchronous bucks can run backwards. It also underpins efficiency accounting: the freewheel element carries $(1-D)I_{out}$ on average.
:::

::: concepts
- **Current continuity**: the loop is closed; current through $L$ equals the current through the freewheel element. See [[q0043]].
- **KCL at the SW node**: in the off state $i_L=i_D$ (or $i_{Q2}$) since $Q_1$ is off. See [[q0004]].
- **Energy storage** $\tfrac12Li^2$: the energy source in the off state. See [[q0192]].
- **Volt-second balance**: on and off energy transfers balance.
- **Ground as the return**: current "from ground" is the return path of the load current.
:::

::: answer
"In the off state, the high-side FET is open, so the input isn't connected to anything. The inductor current still flows left to right, and by KCL at the switch node it has to come from the only other thing attached to that node, the diode, or the low-side FET in a synchronous buck. So the current physically circulates: it comes up from ground through the diode into the switch node, through the inductor into the output, through the load, and back to ground. The loop is inductor, load, ground, diode.

Where does the *energy* come from? The inductor. In the on state it absorbed 9.6 microjoules in my 12 V to 3.3 V example, and now it's releasing it, which is what keeps pushing the current through the load against the output voltage. The current drops as the energy depletes.

The output capacitor is not the source: it's in parallel with the load and only supplies the difference when the inductor current dips below the load current. And the input supply does nothing in the off state; that's why the input current is pulsed, why the average is only $D I_{out}$, and why the input capacitor is needed to supply the pulses.

One more nuance: in a synchronous buck, the same path goes through the low-side FET channel; and if the inductor current goes negative, it reverses direction: current flows from the output, through the inductor, into the switch node, and out through the low-side FET."
:::

::: technical
**Off state loop (CCM).** $Q_1$ off: $i_{Q1}=0$. KCL at SW: $i_L=i_D=i_{Q2}$. Current path: GND → D (anode to cathode) → SW → $L$ → $V_{out}$ node → ($C_{out}\parallel R_{load}$) → GND. The input source and $C_{in}$ carry no current except a small leakage/$C_{oss}$ charge.

**Energy source.** Stored energy falls from $\tfrac12LI_{pk}^2=14.8\ \mu J$ to $\tfrac12LI_{val}^2=5.2\ \mu J$; difference $9.57\ \mu J=V_{out}I_{out}(1-D)T$ (energy to the output node in the off time). Instantaneous: power into the output node from the inductor $=V_{out}i_L$ (2.5 A × 3.3 V = 8.3 W falling to 4.9 W), while the inductor releases $v_Li_L$ with $v_L=-3.3$ V, magnitude equal: all of the released energy goes to the output (diode loss aside; with the diode, an extra $V_fi_L$ is dissipated, supplied by the inductor too).

**Output node accounting.** $i_L=i_C+i_{load}$: in the first 725 ns of the off time $i_L>I_{out}$ so the capacitor charges while the inductor supplies the load; in the last 725 ns $i_L<I_{out}$ and the capacitor supplies the shortfall.

**Input.** $i_{in}=0$ in the off state (for the buck itself); the source delivers its average $D I_{out}=0.55$ A into $C_{in}$.

**Light load / DCM.** Once $i_L=0$ the diode stops, the loop is open, and the capacitor alone supplies the load ([[q0190]]).

**Synchronous / negative current.** If $i_L<0$ (forced CCM), the loop reverses: $V_{out}$ → $L$ → SW → $Q_2$ → GND, with the output capacitor as the source; or on the next on time the current returns to the input through $Q_1$.
:::

::: short
"By KCL at the switch node, with the high-side FET open the inductor current has to come through the diode, or the low-side FET, from ground. So it circulates: ground, diode, switch node, inductor, load, back to ground; the input isn't in the loop. The energy comes from the inductor's magnetic field, built up during the on time, about 9.6 µJ per cycle in my example. The capacitor only fills in the gap when the inductor current is below the load current."
:::

::: long
"It helps to answer on two levels: where the current physically flows and where the energy comes from.

Physically, current flows in loops. In the off state the high-side FET is open, so the only things connected to the switch node are the inductor and the freewheel element, the diode or the low-side FET. KCL at the switch node says the current going into the inductor has to equal the current through that element. So it comes up from ground, through the diode, into the switch node, through the inductor and to the output, through the load and back to ground. That's a closed loop that doesn't involve the input supply at all, which is why the input current is only pulsed and the average is only 0.55 amps in a 12 volt to 3.3 volt, 2 amp converter.

Energetically, the source is the inductor. During the on time it absorbed about 9.6 microjoules; now it's releasing that, which is what pushes current through the load. The inductor current falls from about 2.5 to 1.5 amps as that energy is delivered. You can check it: 3.3 volts times 2 amps times 1.45 microseconds is also 9.6 microjoules.

People sometimes say the output capacitor supplies it, but the capacitor is in parallel with the load: the inductor current splits between them. For the first part of the off time the inductor current is above the load, so the capacitor is actually *charging*; only in the last part, when the inductor current falls below the load, does the capacitor supply the difference.

And in a synchronous converter with negative inductor current the loop reverses, with the output capacitor as the source."
:::

::: terms
- **Freewheeling path**: ground → diode/low-side FET → SW → inductor → load → ground.
- **Current loop**: closed path required by KCL; no charge is created or destroyed.
- **Magnetic energy**: $\tfrac12Li^2$ stored in the inductor field.
- **Hot loop**: the input loop $C_{in}$ → $Q_1$ → diode/$Q_2$ → $C_{in}$, where current switches abruptly between the two devices. The off-state freewheel loop itself carries the continuous inductor current, so it is not the hot loop.
- **Return path**: ground connection carrying the load current back to the freewheel element.
- **Forced CCM / negative current**: reverse current in a synchronous buck.
- **Input pulsed current**: zero in the off state.
:::

::: exceptional
**An average answer**: "From the inductor, which discharges."

**An exceptional answer**:
- Separates path from energy: the *current* comes through the freewheel element from ground (KCL at SW), the *energy* comes from the inductor's field.
- States that the input is not part of the loop and ties this to the pulsed input current ($D I_{out}$ average) and $C_{in}$.
- Corrects the "capacitor supplies it" misconception using the charge/discharge timing (it charges during the first part of the off state).
- Checks energy balance numerically ($9.57\ \mu J$ both ways).
- Mentions DCM and reverse current exceptions.
:::

::: mistakes
- **"The input supplies the inductor current in the off state."** The high-side FET is open; no input current flows.
- **"The current comes from the capacitor."** The capacitor charges during the first part of the off state; it only supplies the shortfall later.
- **"The inductor current comes out of nowhere, so ground must be a source."** Ground is just the return node; the loop is closed through the load.
- **"The inductor 'recreates' current."** Charge is conserved; the same carriers circulate. What changes is the energy source (stored field).
- **Forgetting the freewheel element carries the same current.** $i_D=i_L$ in the off state; this sets diode ratings and loss.
:::

::: deep
## Level 1: where does the charge flow?

Current is a flow of charge in a closed loop. At the switch node the inductor draws current out of SW. Kirchhoff's current law says that must equal the current that enters SW from the other elements: $Q_1$ and the freewheel element.

- On state: $Q_1$ conducts, freewheel element off, $i_{Q1}=i_L$.
- Off state: $Q_1$ off, freewheel element on, $i_D=i_L$.

The "source" in the charge sense is the **ground node** (and thereby the load return): carriers go around. Ground is a reservoir node, not an energy source: current into SW from ground equals current returning from the load to ground.

## Level 2: where does the energy come from?

The loop carries current against a voltage: the inductor's terminal voltage is $-V_{out}$ (current flows from the low-potential SW end to the higher-potential output end), which means the inductor is pushing charge uphill and delivering power $V_{out}i_L$ to the output node. That power comes from the magnetic field.

| Quantity | Value (example) |
|---|---|
| Energy at start of off time ($I_{pk}=2.51$ A) | 14.8 µJ |
| Energy at end ($I_{val}=1.49$ A) | 5.2 µJ |
| Released during off time | 9.57 µJ |
| $V_{out}I_{out}(1-D)T=3.3\times2\times1.45\ \mu s$ | 9.57 µJ |

That is the converter's signature: the average input power $12\times0.55=6.6$ W is delivered in bursts during the on time, partly passed directly to the output (27.5%) and partly stored (72.5%) to be released in the off time.

## Variations

### Synchronous, forced CCM, negative current

If the average load is small enough that $i_L$ goes negative at the end of the off time, the direction of the current in the loop reverses for that part of the cycle: the output capacitor becomes the source, the current flows output → $L$ → SW → $Q_2$ → ground, and the inductor's field is *charged* from the output instead of discharged into it. At the next turn-on, the negative current flows back through $Q_1$ into $C_{in}$.

### DCM

Once the inductor is empty ($i_L=0$) the freewheel element turns off and the loop is open. For the rest of the cycle the capacitor alone feeds the load.

### Dead time

During dead time the loop includes the body diode of $Q_2$ rather than the channel: same path, higher drop (about 0.7 V vs 20 mV), so slightly more energy is dissipated there, which comes out of the inductor's stored energy.

## How to answer in one breath

"Current is a loop: in the off state it's ground, through the diode, the inductor, the load, and back to ground. Energy comes from the inductor's field. The input's disconnected."

## Worked example: the same off state with a real diode

The numbers above are ideal. Put in a Schottky with $V_f=0.4$ V at 2 A and everything shifts slightly, which is a good way to check you understand the loop. In steady state the inductor volt-seconds still balance, but now the off-time voltage is $-(V_{out}+V_f)$, so

$$D=\frac{V_{out}+V_f}{V_{in}+V_f}=\frac{3.7}{12.4}=0.298,\qquad (1-D)T=0.702\times2\ \mu s=1.403\ \mu s$$

The down-slope steepens to $(3.3+0.4)/4.7\ \mu H=0.787$ A/µs, so the ripple is $0.787\times1.403=1.105$ A (peak 2.55 A, valley 1.45 A, a little more than the 1.018 A ideal figure). Now the energy ledger for the off time:

| Item | Energy per cycle |
|---|---|
| Released by the inductor, $(V_{out}+V_f)I_{out}(1-D)T$ | 10.38 µJ |
| Delivered to the output node, $V_{out}I_{out}(1-D)T$ | 9.26 µJ |
| Burned in the diode, $V_fI_{out}(1-D)T$ | 1.12 µJ |

The diode dissipates $0.4\times2\times0.702=0.56$ W, which is 0.56 W out of 6.6 W delivered, roughly 8% of the output power. That is the number that motivates synchronous rectification. Replace the diode with a 10 mΩ low-side FET and the conduction loss is about $I_{out}^2R_{ds(on)}(1-D)=4\times0.01\times0.725=29$ mW. Add dead time: if each edge leaves the body diode (about 0.7 V) conducting for 60 ns, the loss is $0.7\times2\ \text{A}\times120\ \text{ns}\times500\ \text{kHz}=84$ mW. The off-state path is the same loop either way. Only the voltage across the element, and therefore the fraction of the inductor's energy that never reaches the load, changes. The inductor's own winding resistance and core loss take a further bite from the same stored energy.

## What the real switch node does

Two parasitics make the real off state less clean than the ideal loop. First, when $Q_1$ turns off the inductor current must commutate into the freewheel path through the small loop formed by $Q_1$, the diode or $Q_2$, and $C_{in}$. Loop inductance of a few nH rings with the switch capacitance at tens to hundreds of MHz, so the SW node overshoots its ideal value before settling to $-V_f$. Second, a diode has reverse recovery (a silicon PN diode more than a Schottky), so when $Q_1$ turns back on, the diode briefly conducts backward and adds a current spike to $Q_1$. Neither changes where the off-state current flows. They show up at the edges, and they are why snubbers and tight layout exist.

> [!UNCERTAIN]
> The ringing frequency, overshoot and reverse-recovery charge depend on the exact FET, diode and layout. The few-nH loop inductance and the 60 ns dead time in this section are illustrative, not from a specific part.

## Verifying it on the bench

You can confirm each claim in this page with a scope and an ammeter:

1. **Probe SW against ground** with a short ground spring. During the off time it should sit at about $-V_f$ (about $-0.4$ V) for a diode, or $-I_{out}R_{ds(on)}$ (about $-20$ mV) for a synchronous part. A flat SW near zero proves the freewheel element is carrying the current.
2. **Clip a current probe on the diode or $Q_2$ lead** (or measure the voltage across a 10 mΩ sense resistor placed in series). The waveform should be the downward ramp of $i_L$ during the off time and zero during the on time. Average it and compare to $(1-D)I_{out}$.
3. **Measure the input side.** With a current probe on the lead between $C_{in}$ and $Q_1$ you see pulses of height $i_L$ lasting $DT$ and zero current for the rest. Measured in the source lead before $C_{in}$, the current is nearly flat at $DI_{out}\approx0.6$ A.
4. **Remove most of $C_{in}$** (with the supply current-limited) and the input rail visibly pulses, which proves the source does not feed the load during the off time.
5. **Check the energy ledger** by comparing input power $V_{in}I_{in}$ to output power plus the computed losses. The gap is the diode, FET, inductor and switching loss.
:::

::: applications
- **Sizing the freewheel element**: it carries $i_L$ for $(1-D)T$, average $(1-D)I_{out}=1.45$ A.
- **Layout**: the off-state loop (diode/low-side FET, inductor, output capacitor ground) carries the full inductor current and should be low impedance, but its current is continuous; the fast-edged "hot loop" is the one through $C_{in}$, $Q_1$ and the diode/low-side FET, where the current commutates between the two switches each edge.
- **Input-capacitor sizing**: because the input provides nothing in the off state.
- **Light-load efficiency modes** (diode emulation) where the loop is cut at zero current.
- **Bidirectional converters / regenerative operation** where the loop direction reverses.
:::

::: assumptions
- **CCM, steady state**, ideal parts for the energy numbers.
- **Constant load current.**
- **Diode or low-side FET conducting** (dead-time details change only the voltage drop).
- **The "source" has two meanings**: the path of the charge (ground via the freewheel element) and the origin of the energy (the inductor). The answer addresses both because "sourced from" is ambiguous.
- **DCM and forced-CCM**: described as exceptions.
:::

::: followups
### So is the current in the off state "from ground"?
In the loop sense, yes: it enters the switch node from the ground rail through the diode or $Q_2$. But ground is only the return node of a loop that includes the load, so the charge is simply circulating. The *energy* comes from the inductor.

### What would the input supply see during the off state?
Nothing from the converter: the high-side FET is open. With the input capacitor, the source delivers its steady average of about 0.55 A to recharge the capacitor. Without the input capacitor the source would see a pulsed load, which is why the capacitor is needed ([[q0193]]).

### Does the output capacitor supply the inductor current?
No. It is in parallel with the load at the output node. The inductor current is split between them. In the first half of the off time the capacitor is charging, because $i_L>I_{out}$.

### What if the diode were open-circuit?
The loop is broken. The inductor forces the switch node negative until something conducts or breaks down: see [[q0197]]. The energy 14.8 µJ has to go somewhere, usually destroying the FET.

### Harder: during the off time the current in the diode is 2 A and its voltage drop is 0.5 V. Where does that 1 W of power come from?
From the inductor's stored energy, since the diode is in series with the inductor current and the input is disconnected. Of the $v_L i_L$ released, $V_{out}i_L$ goes to the output and $V_fi_L$ is dissipated in the diode: the drop comes out of the inductor's magnetic energy (the inductor's down-slope is slightly steeper because of it: $-(V_{out}+V_f)/L$).
:::

::: interpretations
"Sourced from" is ambiguous (charge path versus energy). The page answers both. "Off state" follows the section note: high-side FET off, diode/low-side FET on. For the charge/discharge of the capacitor see [[q0190]]; for sink/supply of energy see [[q0192]]; for current directions see [[q0187]].
:::

::: rubric
- Current path: ground → freewheel element → SW → inductor → load → ground :: Directly answers where the current flows.
- Input not in the loop in the off state; $i_{in}=0$ :: Links to pulsed input current.
- Energy source is the inductor's stored field :: Distinguishes energy from charge.
- Energy accounting (9.57 µJ both ways) or equivalent :: Shows understanding and consistency.
- Capacitor is in parallel with the load, charging early in the off state :: Corrects a misconception.
- Mentions exceptions: DCM, reverse current, dead time :: Completeness.
:::
