::: basics
### In plain words
A universal gate is one type of gate from which you can build every other logic gate, and therefore any digital circuit. NAND is universal, and so is NOR. This matters because everything can be built from one simple gate repeated many times.

### Picture it
Imagine a toy set with only one kind of brick. With enough bricks you can still build a house, a car or a bridge, though some builds take more bricks than a mixed set would. A universal gate is that one kind of brick. The catch is the same: a design built from a single gate type is often bigger than one using a mix.

### Words you need
- **NAND**: AND followed by a flip. Its output is 0 only when all inputs are 1 ([[q0891]]).
- **NOT (inverter)**: a gate that flips 0 to 1 and 1 to 0.
- **AND / OR**: gates described on [[q0889]]. Any circuit can be written using AND, OR and NOT.
- **Tied inputs**: wiring both inputs of a gate to the same signal.

### The simplest example
Make a NOT from a NAND by tying both inputs together. If A = 0, NAND(0, 0) = 1. If A = 1, NAND(1, 1) = 0. That is a NOT.

Make an AND by following a NAND with that NOT. With A = B = 1, the NAND gives 0 and the NOT turns it into 1. Any other input gives NAND = 1 and AND = 0, which is right. So NAND can make NOT and AND, and an OR is built from NANDs too. With those three, anything can be built.

That is the whole idea. The rest of this page shows the OR and XOR from NANDs, the same trick with NOR, why AND and OR alone are not enough, and why chip designs lean toward NAND.
:::

::: testing
Whether you know that **NAND and NOR are each "universal"**, and can *prove* it by building NOT, AND and OR from them, not just state it. The deeper checks: you understand what universal means (any Boolean function can be built from that gate alone), why NAND is the favorite in CMOS (cheapest, fastest single-stage gate, [[q0890]]), and you can reason about gate counts. Strong candidates build a NOT, an AND and an XOR from NANDs on the whiteboard in a minute and notice that AND/OR alone are *not* universal because they can't invert.
:::

::: why
Universality is why digital design is tractable: with one cell type you can build anything, which is the idea behind gate arrays, standard cells, and the "spare gate" trick used to patch a board with an unused NAND from a 74-series package. It also explains why synthesis tools map logic onto NAND/NOR-style cells, why SR latches and flip-flops are cross-coupled NANDs or NORs ([[q0882]]), and why NAND flash has its name. The question tests whether you can move comfortably between Boolean algebra (De Morgan) and hardware.
:::

::: concepts
- **Functional completeness**: a set of gates is universal if every Boolean function can be built from it. {AND, OR, NOT} is the textbook complete set.
- **NAND and NOR as inverters**: tying both inputs together gives NOT: $\overline{A\cdot A}=\bar A$.
- **De Morgan's laws**: $A+B=\overline{\bar A\,\bar B}$ and $AB=\overline{\bar A+\bar B}$, the bridge from AND/OR to NAND/NOR.
- **Truth tables** ([[q0891]]): NAND is 0 only for 11, NOR is 1 only for 00.
- **CMOS single-stage gates** ([[q0890]]): NAND and NOR are the natural inverting gates; AND and OR cost an extra inverter.
- **Monotone functions cannot invert**: raising an input of an AND or OR can never lower the output, so no network of only ANDs and ORs can produce NOT. {AND, OR} alone is not complete.
:::

::: answer
"NAND is the universal gate, and NOR is too. Universal means you can build any logic function using only that gate.

To prove it for NAND, I just need to show I can make NOT, AND and OR, since those three can build everything. NOT: tie both NAND inputs together, so the output is the complement of A. AND: NAND followed by that inverter, two gates. OR: invert each input with a NAND, then NAND them, which is De Morgan: NOT of A and NOT of B, NANDed, gives A or B. Three gates. From there NOR is four gates, and XOR is four NAND gates in a neat pattern.

NOR works the same way by duality: NOT is a NOR with tied inputs, OR is NOR plus an inverter, and AND is the NOR of the two inverted inputs.

AND and OR on their own are not universal because neither can invert. You need some form of inversion.

In practice NAND is the one people prefer in CMOS: a NAND has the series stack in the NMOS, which is the faster device, so it's smaller and faster than a NOR. Real chips don't literally use one gate type, but the standard-cell libraries are heavy on NAND, and knowing universality is also handy on a board: if a bug needs one more gate, any spare NAND from a 7400 package can do the job."
:::

::: technical
**Definition.** A set $S$ of Boolean operations is *functionally complete* (universal) if every Boolean function can be expressed using only operations in $S$. Since every function can be written in sum-of-products form, it suffices to realize AND, OR and NOT.

**NAND universality** ($\mathrm{NAND}(a,b)=\overline{ab}$):
- NOT: $\overline{A\cdot A}=\bar A$, so $\mathrm{NAND}(A,A)$. (1 gate)
- AND: $AB=\overline{\overline{AB}}=\mathrm{NAND}(\mathrm{NAND}(A,B),\mathrm{NAND}(A,B))$. (2 gates)
- OR: $A+B=\overline{\bar A\,\bar B}=\mathrm{NAND}(\bar A,\bar B)$. (3 gates)
- NOR: OR followed by NOT. (4 gates)
- XOR: $N_1=\mathrm{NAND}(A,B)$; $Y=\mathrm{NAND}(\mathrm{NAND}(A,N_1),\mathrm{NAND}(B,N_1))$. (4 gates)
- 2:1 mux: $Y=\mathrm{NAND}(\mathrm{NAND}(A,\bar S),\mathrm{NAND}(B,S))$ with $\bar S=\mathrm{NAND}(S,S)$. (4 gates)

**NOR universality** ($\mathrm{NOR}(a,b)=\overline{a+b}$) is the dual:
- NOT: $\mathrm{NOR}(A,A)$ (1); OR: NOR then NOT (2); AND: $AB=\overline{\bar A+\bar B}=\mathrm{NOR}(\bar A,\bar B)$ (3); NAND: 4 gates; XNOR: 4 gates, XOR: 5.

**Non-universal sets.** {AND, OR} is **monotone**: raising an input can never lower the output, so it cannot realize NOT. {XOR} alone is linear ($\mathbb{F}_2$ affine functions only), so it is not universal either; but {XOR, AND} with the constant 1 is complete (the algebraic normal form). {NOT} alone is obviously not.

**Why NAND is preferred in CMOS.** NAND2 has the series stack in the NMOS and parallel PMOS; NOR2 has series PMOS. With a mobility ratio $\approx2$, NAND2 has logical effort $4/3$ versus NOR2's $5/3$, so NAND is faster and smaller at equal drive ([[q0890]]). (In older NMOS-only technologies the preference could flip; see the note in the deep dive.)

**Cost caveat.** Universality is about *possibility*, not efficiency. Rewriting AND-OR logic as NAND-only can add gates (every AND/OR requires inverters), so real libraries include AND, OR, XOR, AOI/OAI and mux cells too.
:::

NOR is the dual. AND and OR alone aren't universal because they can't invert. NAND is preferred in CMOS because its series stack is NMOS, so it's faster and smaller than NOR."
:::

::: long
"A gate is universal if you can build every Boolean function out of just that gate. NAND is universal, and so is NOR.

The proof is short. Every function can be written with AND, OR and NOT, so I only need to build those three from NANDs. For NOT, I tie both inputs of a NAND together: NAND of A with A is just not-A. For AND, I take a NAND and invert its output with a second NAND wired as an inverter, so that's two gates. For OR, I use De Morgan: A plus B equals the NAND of not-A and not-B. So that's two inverters feeding one NAND, three gates. With those three I can build anything. For instance an XOR takes four NANDs: one NAND of A and B, then A NANDed with that output and B NANDed with that output, and a final NAND of those two. A 2-to-1 mux is also four.

NOR is the dual, by swapping AND and OR in all of this. A NOR with tied inputs is NOT, NOR plus a NOT is OR, and AND is the NOR of the two inverted inputs.

It's worth saying that AND and OR by themselves aren't universal, because they're monotone: if you raise an input, the output can never go down, so you can't make an inverter. Any universal set needs some form of inversion.

Why does it matter? First, in CMOS a NAND is a single four-transistor stage with the series transistors being NMOS, the faster type, so NAND is cheaper and faster than NOR, and libraries use it heavily. Second, it's very practical for board-level fixes: a quad NAND chip can build whatever missing logic you need. Third, latches are cross-coupled NANDs or NORs. Finally, universality isn't efficiency: a NAND-only netlist can need more gates than a mixed one."
:::

::: terms
- **Universal (functionally complete) gate**: a gate type from which any Boolean function can be built.
- **NAND**: $\overline{AB}$; 0 only when all inputs are 1.
- **NOR**: $\overline{A+B}$; 1 only when all inputs are 0.
- **De Morgan's laws**: $\overline{AB}=\bar A+\bar B$, $\overline{A+B}=\bar A\bar B$.
- **Monotone function**: output never decreases when an input increases; AND and OR are monotone, NOT is not.
- **Tied-input inverter**: a NAND or NOR with both inputs connected, acting as NOT.
- **Sum-of-products**: OR of AND terms; any function can be written this way.
- **Duality**: swapping AND with OR (and 0 with 1) maps the NAND construction onto the NOR construction.
:::

::: mistakes
- **Saying "AND and OR are universal".** They cannot invert. {AND, OR, NOT} is complete, but {AND, OR} is not.
- **Building NOT from a NAND with one input floating or grounded.** Tie both inputs together (or tie one to logic 1: $\overline{A\cdot1}=\bar A$). A floating input is undefined; grounding one input gives a constant 1.
- **Forgetting the inverter in the AND construction.** NAND alone is AND-then-invert; you need a second inversion to get AND (2 gates).
- **Mixing up which gate needs inverted inputs.** OR needs inverted inputs into a NAND ($A+B=\overline{\bar A\bar B}$); AND from NOR also needs inverted inputs.
- **Assuming NAND-only is always the cheapest implementation.** Universality guarantees you can build it, not that it is minimal; mixed libraries use fewer transistors.
- **Claiming NOR is not universal or "less" universal.** NOR is exactly as universal as NAND; it is only slower and larger in CMOS.
:::

::: deep
## What "universal" means

Any Boolean function can be written as a **sum of products**: take each row of its truth table that outputs 1, AND the inputs (complementing those that are 0 in that row), and OR all those terms. That uses only AND, OR and NOT. So if some single gate can imitate all three of AND, OR and NOT, that gate can build any function. That is the whole proof strategy: *reduce to AND/OR/NOT, then show the candidate gate can make each*.

The algebra behind each:

- **NOT**: $\mathrm{NAND}(A,A)=\overline{A\cdot A}=\bar A$ (idempotence: $AA=A$).
- **AND**: $AB=\overline{\overline{AB}}$, so a NAND followed by a NOT.
- **OR**: by De Morgan, $A+B=\overline{\bar A\cdot\bar B}$, which is a NAND whose inputs are $\bar A$ and $\bar B$.

## NOR: the dual

Swap roles of 0 and 1 and AND and OR, and the same story holds. NOR$(A,B)=\overline{A+B}$.

- **NOT**: $\mathrm{NOR}(A,A)=\bar A$ (1 gate).
- **OR**: NOR followed by a NOT (2 gates).
- **AND**: $AB=\overline{\bar A+\bar B}=\mathrm{NOR}(\bar A,\bar B)$ (3 gates).
- **NAND**: AND then NOT (4 gates).
- **XNOR**: $\mathrm{NOR}\big(\mathrm{NOR}(A,N),\mathrm{NOR}(B,N)\big)$ with $N=\mathrm{NOR}(A,B)$ is XNOR in 4 gates; invert it for XOR (5).

I verified each construction exhaustively over all input combinations. Both families need the same *number* of gates but differ in how the swap falls (NAND gives XOR in 4, NOR gives XNOR in 4).

## Which sets are *not* universal?

- **{AND, OR}**: monotone. Raising an input never lowers the output, but NOT must do exactly that. Without constants you cannot build inversion.
- **{XOR}** alone: every function it builds is an affine (linear) function over $\mathbb{F}_2$, so it can never make AND.
- **{XOR, AND}** plus the constant 1 *is* complete ($\bar A=A\oplus1$, and OR $=A\oplus B\oplus AB$). This "ring" form is used in cryptography and error-correcting codes.
- **{NOT}**: obviously not.

The pattern: a universal set needs a **non-monotone** function (some form of inversion) and a **non-linear** one (AND-like).

## Why CMOS likes NAND

From [[q0890]]: a 2-input NAND has two NMOS in series and two PMOS in parallel. NMOS electrons are about 2-3x more mobile than PMOS holes, so the series stack (which must be widened to keep drive) is in the cheaper device. A NOR puts the series stack in the PMOS, which has to be about 4x the inverter's PMOS. The logical-effort numbers for equal drive are NAND2 $4/3$ and NOR2 $5/3$, and the gap widens at 3 or 4 inputs (NAND3 $5/3$, NOR3 $7/3$). So synthesized logic leans on NAND, and wide NORs are avoided.

> [!UNCERTAIN]
> NAND's advantage is a property of CMOS with PMOS slower than NMOS. In the older NMOS-only logic with a resistive/depletion load, NOR gates were often the more convenient form, and the Apollo Guidance Computer's logic was famously built entirely from 3-input NOR gates. Do not generalize "NAND is always better" beyond static CMOS.

1. **Spare gates on a board.** A hex inverter or quad NAND has unused gates. If a late fix needs an inverter or an AND, you wire up a spare NAND (tied inputs for NOT) rather than respin the PCB.
2. **Latches and flip-flops.** An SR latch is two cross-coupled NAND (or NOR) gates; the feedback of two inverting gates makes a bistable cell ([[q0882]], [[q0883]]).
3. **Gate arrays and masked ASICs.** Early gate arrays offered a sea of NAND gates; only the metal wiring layers were customized.
4. **Memory.** NAND flash and NOR flash are named after how their cell arrays are wired: cells in series look like a NAND gate's pull-down, cells in parallel like a NOR's.
5. **Technology mapping.** Synthesis tools convert logic to a **NAND-INV** (or AND-INV) graph, then cover it with library cells to meet timing and area.

## A worked example: implement $F = A\bar B + C$ with NANDs only

Use double inversion: $F=\overline{\overline{A\bar B}\cdot\bar C}$ (De Morgan on the OR). So:
1. $\bar B=\mathrm{NAND}(B,B)$,
2. $P=\mathrm{NAND}(A,\bar B)=\overline{A\bar B}$,
3. $\bar C=\mathrm{NAND}(C,C)$,
4. $F=\mathrm{NAND}(P,\bar C)$.

That is 4 NAND2 gates, 16 transistors in static CMOS. Compare with a mixed-cell version: an inverter for B (2), an AOI21 cell computing $\overline{A\bar B+C}$ (6) and an output inverter (2), about 10 transistors. That gap is the cost of restricting yourself to one gate type. Brute-force check over the 8 input combinations gives $F=1$ exactly when $A\bar B=1$ or $C=1$.

The general rule: write your function in sum-of-products form, then **NAND-NAND**: each AND term becomes a NAND, and the OR of terms becomes a NAND of those outputs. Any SOP is just two levels of NAND (plus input inverters).
:::

::: applications
- **Spare-gate bodge fixes on PCBs**: using an unused NAND in a 74HC00 as an inverter or AND.
- **Cross-coupled NAND/NOR latches**: SR latch, switch debouncer (the classic SPDT-switch debouncer is a NAND SR latch).
- **Standard-cell logic synthesis**: NAND2/NOR2/INV form the mapping base of a technology library.
- **NAND and NOR flash memory**: array structure mirrors the gate topology (NAND strings in series, NOR cells in parallel).
- **Apollo Guidance Computer**: all digital logic was built from a single type of 3-input NOR gate, an extreme practical example of universality.
- **Two-level NAND-NAND implementation** of any sum-of-products function in PLAs and discrete logic.
:::

::: assumptions
- I assumed **standard Boolean logic** with both constants and unlimited fan-out; "universal" is a statement about expressibility.
- Gate counts refer to **2-input gates**. With 3- or 4-input NANDs, some constructions shrink; cost in transistors depends on the process.
- The NAND-over-NOR preference assumes **static CMOS** with PMOS roughly 2-3x less mobile than NMOS. In other technologies, the preference can flip (see the uncertain note above).
- For the claim that {XOR, AND, 1} is complete I used the algebraic normal form (Zhegalkin polynomial) over $\mathbb{F}_2$, which is a standard result.
- I answered NAND first because it is the usual textbook answer; **NOR is equally correct**, and a good answer names both.

::: followups
### Prove NOR is universal.
Show NOT, OR and AND (or NOT and AND). NOT: tie the inputs, $\mathrm{NOR}(A,A)=\bar A$. OR: $\mathrm{NOT}(\mathrm{NOR}(A,B))=A+B$ (2 gates). AND: $AB=\overline{\bar A+\bar B}=\mathrm{NOR}(\bar A,\bar B)$ using two inverters and one NOR (3 gates). Since AND/OR/NOT can build any function, NOR is universal.

### How many NAND2 gates do you need for an XOR, and for a 2:1 mux?
Four for XOR: $N_1=\overline{AB}$, then $\overline{AN_1}$, $\overline{BN_1}$, and the final NAND of those two. A 2:1 mux is also four: $\overline{S}$ (1 gate), $\overline{A\bar S}$, $\overline{BS}$, and the output NAND. At 4 transistors per NAND2, that's 16 transistors for either, versus about 6-12 for dedicated cells.

### Why isn't {AND, OR} enough?
Both are monotone: changing an input from 0 to 1 can only keep or raise the output. Inversion must lower the output when the input rises, so it can't be built. (Constants 0 and 1 won't help either.) Adding NOT, or using NAND/NOR, supplies the missing non-monotone element.

### Implement a 3-input AND using only 2-input NAND gates.
$ABC=\overline{\overline{(AB)C}}$: gate 1 = NAND(A,B); gate 2 = NOT of gate 1 (tied NAND) giving $AB$; gate 3 = NAND($AB$, C); gate 4 = NOT of gate 3. That's 4 gates. A single NAND3 plus an inverter would be cheaper (2 stages).

### Harder: you must build a latch using only NOR gates. What do you draw and what is the forbidden input?
Two cross-coupled NOR gates: $Q=\mathrm{NOR}(R,\bar Q)$ and $\bar Q=\mathrm{NOR}(S,Q)$. With $S=R=0$ it holds; $S=1$ sets $Q=1$; $R=1$ resets. The forbidden input is $S=R=1$, which forces both outputs to 0 (violating $Q=\overline{\bar Q}$) and, when both go back to 0 together, leaves the latch in a race that can oscillate or go metastable. See [[q0882]].

### A designer says "I'll use only NAND gates for the whole chip to keep things simple." Good idea?
Possible but not optimal. A NAND-only netlist is legal (universal), but every AND/OR/XOR/mux costs extra gates and extra delay stages, so area, power and timing get worse than with a full library (AOI/OAI, XOR, mux, flip-flop cells). Real libraries have dozens of cells; universality just guarantees that a minimal set would be enough to function.
