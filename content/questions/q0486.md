::: testing
Whether you can define a ground plane (a continuous copper layer used as reference and return path) **and weigh it honestly**: the benefits (low impedance, small loops, controlled impedance, shielding, capacitance with power) against the costs (extra layers, stray capacitance to nearby nodes, plane noise sharing, soldering/thermal effects, plane resonances and the damage that slots and splits do). Most candidates only list benefits. A strong answer includes a real downside with a number, such as parasitic capacitance on a high-impedance node.
:::

::: why
The ground plane is the single most effective layout element on a modern board, which is exactly why interviewers ask for its downsides: they want to see whether you know *when not to blindly apply it* (RF antennas, high-impedance analog nodes, inductors, high-voltage clearance) and how it fails (slots, splits, shared return currents). It's also the base for the other planes questions ([[q0488]]–[[q0491]]).
:::

::: concepts
- **Return current and loop inductance**: a plane gives the lowest-inductance return, directly under the signal. See [[q0478]].
- **Transmission-line reference**: microstrip and stripline need a plane to define $Z_0$. See [[q0479]].
- **Parasitic capacitance**: trace-to-plane capacitance loads nodes. See [[q0463]].
- **Shielding**: planes terminate electric fields and reduce coupling. See [[q0490]].
- **Common-impedance coupling**: a plane is not a perfect conductor; currents still create drops. See [[q0484]].
- **Plane pairing**: ground next to power for decoupling. See [[q0480]].
:::

::: answer
"A ground plane is a continuous layer of copper dedicated to ground, usually right under the signal layers, that acts as the reference and the return path for everything above it.

The pros: it's very low impedance, so it keeps the ground voltage nearly the same everywhere and avoids shared-impedance noise from ground traces. At high frequency the return current flows directly under each signal trace, so the loop is small, which means less radiation, less pickup and less crosstalk. It makes controlled impedance possible, because a microstrip or stripline needs a reference plane. It shields signals on one side of the plane from the other, it spreads heat, and next to a power plane it adds distributed capacitance for decoupling.

The cons: it costs layers, so money. It adds parasitic capacitance to anything near it, which matters for high-impedance nodes or fast analog and RF circuits, so I sometimes cut it away under those. It can still carry noise: if a noisy current flows through the plane near a sensitive circuit, they share impedance. If you cut slots or splits into it, the return path breaks and it makes things worse. A big plane pair can resonate. And big planes make soldering harder, which is why you use thermal reliefs on pads. So I use it by default, and I'm careful where I interrupt it."
:::

::: technical
**Definition.** A ground plane is a layer (or most of one) of copper tied to the ground net, ideally unbroken in the region of interest.

**Benefits with numbers (1 oz copper, $\varepsilon_r = 4.3$):**
- Sheet resistance $0.48$ mΩ/□, versus 192 mΩ for a 0.25 mm × 100 mm trace.
- Return loop inductance about 0.3 nH/mm at $h = 0.2$ mm (vs ≈1.4 nH/mm for an isolated trace).
- Enables $Z_0$ control: 50 Ω microstrip at $w=0.335$ mm for $h=0.2$ mm.
- Crosstalk proxy $1/(1+(s/h)^2)$ drops from 0.5 to 0.1 when spacing goes from $h$ to $3h$.
- Heat spreading: thermal sheet resistance of 1 oz copper is $1/(kt)=1/(385\times35\times10^{-6})=74$ K/W per square.

**Costs with numbers:**
- **Stray capacitance** per length: $C'=\sqrt{\varepsilon_{eff}}/(cZ_0)$. For a 0.3 mm trace at $h=0.2$ mm: $\approx 0.11$ pF/mm, so a 100 mm trace is 11 pF. On a 10 MΩ node that's $R C=110$ µs, a 1.4 kHz pole.
- **Pad capacitance**: a 1 mm² pad over a plane 0.2 mm away is $\varepsilon_0\varepsilon_rA/h=0.19$ pF. With a 1 MΩ feedback resistor that's a pole at 0.84 MHz, relevant to op-amp stability.
- **Layer cost**: each additional plane layer adds fab cost.
- **Plane resonance**: a 100 mm plane pair resonates near 720 MHz ($c/(2\ell\sqrt{\varepsilon_r})$).

**Failure modes**: slots/anti-pad rows, splits crossing signals, noisy currents sharing the plane, floating pour islands. See [[q0485]].
:::

:::

::: long
"A ground plane is a continuous copper layer tied to ground, normally directly beneath the signal layers, and it does the job of both reference and return path for everything above it.

The advantages. First, impedance: a plane has a tenth of a milliohm per square at DC and very low inductance at high frequency, so it keeps ground nearly uniform and avoids the common-impedance noise you get from ground traces. Second, at high frequency the return current runs directly under each trace, so the loop is small. That means less radiation, less pickup and less crosstalk. Third, it enables controlled impedance: a microstrip or stripline needs a plane, and for a 0.2 millimetre prepreg a 0.33 millimetre trace is fifty ohms. Fourth, shielding: a plane between two signal layers keeps them from coupling. Fifth, it spreads heat, and next to a power plane it adds capacitance for decoupling.

The disadvantages. It costs at least one layer. It adds capacitance to everything over it: a trace is about a tenth of a picofarad per millimetre, so a long high-impedance node picks up tens of picofarads, and a pad on a feedback node can add a pole that hurts op-amp stability, so I remove the plane under those. It's not a perfect conductor, so large currents through it can still disturb a sensitive circuit, which I handle by placement. Cutting it with slots or routing across splits wrecks the return path. A big power-ground plane pair can resonate in the hundreds of MHz. And a large plane steals heat while soldering, which is why pads get thermal reliefs.

On balance I use a plane by default and treat any interruption as a deliberate decision."
:::

::: terms
- **Ground plane**: a continuous copper layer connected to ground.
- **Return current**: current flowing back to the source; at high frequency under the trace.
- **Sheet resistance**: $\rho/t$, in Ω/□.
- **Parasitic capacitance**: unwanted capacitance between a conductor and the plane.
- **Anti-pad**: clearance in a plane around a via.
- **Split / slot**: a gap in the plane that interrupts the return path.
- **Thermal relief**: spoke connection of a pad to a pour that eases soldering.
- **Plane resonance**: standing wave between two planes at a frequency set by size and dielectric.
:::

::: exceptional
An exceptional answer gives both sides with numbers (192 mΩ trace vs 0.5 mΩ/□ plane; 0.11 pF/mm trace capacitance; 11 pF per 100 mm), names the cases where you *remove* the plane (under high-impedance analog nodes and under antennas and inductors), and knows that "a plane" doesn't mean "solved": splits, slots, island pours and shared currents are how planes fail. It might also mention that the plane is a shield for electric fields but only a partial one for low-frequency magnetic fields.
:::

::: mistakes
- **Listing only pros.** The question explicitly asks for cons.
- **Believing a plane is an ideal 0 V.** It's a conductor; large or fast currents still create voltage drops.
- **Forgetting the parasitic capacitance** it adds to high-impedance nodes and to inductors' self-resonance.
- **Putting a plane under an RF antenna or a power inductor** without checking: it detunes the antenna or reduces the inductance (eddy currents).
- **Treating cuts as harmless.** A slot under a fast signal makes a big loop.
- **Assuming a ground plane shields everything.** It terminates electric fields well but does little for low-frequency magnetic fields.
:::

::: deep
## What exactly is a ground plane?

A *plane* is a layer that is mostly solid copper tied to the ground net. A *pour* is a flood fill on a signal layer that is interrupted by traces and pads. A true plane has only the necessary holes: via anti-pads, and a few cutouts. The difference matters: a plane has a defined return for traces above it; a pour with many traces through it doesn't.

## Benefits, quantified

**Impedance.** For 1 oz copper the sheet resistance is $\rho/t=0.48$ mΩ/□. A 100 mm × 100 mm plane between two edge points is about one square: 0.48 mΩ, compared with 192 mΩ for a 0.25 mm trace of the same length. At high frequency, the inductance matters: loop inductance of a trace above a plane at $h=0.2$ mm is about 0.3 nH/mm, while the same trace alone has more than 1 nH/mm *and* no defined return.

**Controlled impedance.** The IPC-2141 formula needs the plane's distance $h$: $Z_0\approx\frac{87}{\sqrt{\varepsilon_r+1.41}}\ln\frac{5.98h}{0.8w+t}$. See [[q0476]]. Without a plane there's no defined $Z_0$ at all.

**Crosstalk and radiation.** Image theory: a trace above a conducting plane is equivalent to the trace plus an opposite-current image below the plane at the same distance. The two currents form a dipole of separation $2h$, so the far field falls with $h$. A 50 mm trace at $h=0.2$ mm radiates far less than at $h=1.6$ mm (a 2-layer board). See [[q0490]].

**Heat spreading.** Copper's thermal conductivity is about 385 W/m·K, so a 1 oz layer has thermal sheet resistance $1/(kt) = 74$ K/W per square, far better than FR-4 (~0.3 W/m·K). A plane under a hot component spreads and removes heat, especially with thermal vias. See [[q0540]].

**Capacitance with power.** See [[q0480]]. Planes 0.1 mm apart give 0.25 nF/in².

## Costs, quantified

**Parasitic capacitance** of a trace over a plane:

$$C'\approx\frac{\sqrt{\varepsilon_{eff}}}{c\,Z_0}$$

Figure: The closer the plane, the more capacitance per mm. At 0.2 mm, a 100 mm trace is 11 pF; at 1.6 mm it is 4.4 pF. A close plane is what makes a transmission line well behaved, but for a high-impedance analog node it's a load.

Consequences:
- A high-impedance node (10 MΩ source) with 11 pF has a pole at $1/(2\pi\cdot10^7\cdot11\times10^{-12})=1.4$ kHz.
- A transimpedance or feedback node (1 MΩ with 0.19 pF of pad-to-plane capacitance) has a pole at 0.84 MHz, which can erode phase margin. Remedy: cut a keep-out in the plane under the node. (A driven guard at the node's potential stops leakage and bootstraps away capacitance on a node that moves, but at a virtual-ground TIA input it cannot remove capacitance.)
- Inductors: a plane under a power inductor or a spiral antenna reduces effective inductance through eddy currents and adds capacitance, lowering the self-resonance; many datasheets say to keep copper out of the area under the part.
- Antennas: a nearby plane changes the antenna's impedance and pattern; keep-outs are standard.

**Noise sharing.** A plane is a conductor with impedance. A noisy current (e.g., a switching converter's return) flowing under a sensitive circuit generates voltage gradients. Solution: placement so returns don't overlap. See [[q0484]].

**Plane resonance.** A power-ground pair is a cavity; for a 100 mm side, first resonance ≈ $c/(2\ell\sqrt{\varepsilon_r})=723$ MHz. Remedy: decoupling spread across the board, tight spacing, lossy dielectric.

**Cuts hurt.** A slot of length $d$ in the return path forces the current to detour, adding about 1 nH/mm of loop inductance and radiation from the slot. See [[q0485]].

**Soldering and rework.** A large plane draws heat from a pad; thermal reliefs mitigate this but add inductance.

**Cost.** Each added layer pair is a fab cost step. A 2-layer board with a pour as a "plane" is cheaper but has 1.6 mm between signal and ground.

## A simple decision rule

Use a plane when frequency, edge rate or sensitivity demand it; remove it locally when it harms the circuit (high-impedance node, antenna, inductor); never cut it casually.

> [!NOTE]
> Electric-field shielding by a plane works at all frequencies as long as the plane is continuous. Magnetic-field shielding by a thin copper plane only works above the frequency where the skin depth becomes smaller than the plane thickness (a few MHz and up for 35 µm copper, where the skin depth drops below 35 µm) or via the return-current cancellation effect. See [[q0490]].

## Worked example: what a plane costs a transimpedance amplifier

The page's closing scenario deserves a full calculation, because it shows the plane's downside in a form interviewers like. Take a transimpedance amplifier with feedback resistor $R_f = 1$ MΩ and an op-amp whose gain-bandwidth product is 10 MHz. Its input node has the op-amp's input capacitance and the photodiode's capacitance, say 3 pF in total. Over the plane, the inverting-input pad, the short trace and the via add the capacitances computed above: a 1 mm² pad contributes 0.19 pF at $h=0.2$ mm; with a longer trace and via of a few mm the node picks up around 2 pF, so $C_{in}$ goes from 3 pF to 5 pF.

The feedback network has a zero at $f_z = 1/(2\pi R_f C_{in})$: 53 kHz for 3 pF and 32 kHz for 5 pF. To keep a 45° phase margin, a feedback capacitor is needed whose value is approximately

$$C_f \approx \sqrt{\frac{C_{in}}{2\pi R_f\,\text{GBW}}}$$

which is 0.22 pF for 3 pF and 0.28 pF for 5 pF. The resulting closed-loop bandwidth is about $\sqrt{\text{GBW}/(2\pi R_f C_{in})}$: 728 kHz with 3 pF versus 564 kHz with 5 pF, a 23 % loss of bandwidth from 2 pF. A 0.28 pF feedback capacitor is also near the stray capacitance of the 1 MΩ resistor's own pads (0.1 to 0.2 pF), so the layout, not the capacitor you choose, can set the compensation. The plane interacts with $R_f$ in two ways the schematic never shows: capacitance from the input-side pad to the plane adds to $C_{in}$ (lowering bandwidth), while capacitance from the output-side pad is just load on the op-amp output. A grounded plane or ground trace between the two pads actually *reduces* the pad-to-pad capacitance that acts as $C_f$, a trick used when the stray $C_f$ is too large.

The fix is a plane cutout under the input node and the feedback resistor (a few mm larger than the pads, with the plane intact elsewhere), which reduces the capacitance by moving copper away. A guard ring driven to the node's potential bootstraps the capacitance away for a node that moves (a buffer input, an electrometer), and stops leakage, but at a TIA's virtual-ground input the node already sits at ground, so a guard there is just ground: it blocks leakage but cannot remove capacitance in the noise-gain sense. Tuning $C_f$ then becomes a matter of the datasheet's recommended value, not a layout surprise.

## Worked example: what a slot does to a fast return

A cut in the return path forces the current to detour around it. Take a 20 mm detour at about 1 nH/mm of extra loop inductance, or 20 nH. At 100 MHz that is $2\pi(10^{8})(20\times10^{-9}) = 12.6\ \Omega$ in series with the return of a 50 Ω line, a 25 % impedance disturbance for the harmonic content at that frequency, plus a radiating loop with 20 mm of extra length. For a 1 ns edge with 20 mA of current, the inductive spike is $L\,di/dt = 20\ \text{nH}\times 0.02\ \text{A}/1\ \text{ns} = 0.4$ V, enough to corrupt a 3.3 V logic input by itself. A "plane" with many holes is therefore not a plane at the frequencies that matter: the question is whether the return current can stay under its trace, not whether copper exists somewhere on the layer.

## Limiting cases: when a plane stops being simple

- **Very low frequency.** Below roughly a megahertz, return current takes the lowest-resistance route rather than the lowest-inductance one, so it spreads across the plane. A plane then behaves as a shared resistor, and the "noise sharing" problem dominates the "return path" benefit.
- **Very high frequency.** At gigahertz frequencies the plane's own geometry resonates and the rough surface of the copper foil increases loss; the plane becomes part of the transmission line and its imperfections show up in the channel's insertion loss.
- **A two-layer "plane".** A bottom pour at 1.6 mm gives about 0.04 pF/mm of trace capacitance versus 0.11 pF/mm at 0.2 mm: about 40 % of the capacitive load, but also impractically wide traces for any controlled impedance and a larger loop. For a slow, high-impedance analog board that trade can favor the 2-layer, but it should be a decision, not an accident.
- **Plane under an inductor.** A power inductor with a plane directly under it induces eddy currents in the plane. The loss and reduced inductance depend on the part's geometry (shielded versus open construction), so follow the part's layout recommendation.

## Real-hardware considerations

- **Copper roughness and weight.** Heavy copper (2 oz) halves the sheet resistance but makes fine-pitch routing harder on that layer. For a ground plane on an inner layer, 0.5 oz or 1 oz is typical, and the choice affects etch tolerance on the layer's traces.
- **Plane perforation.** Every via passing through the plane removes a 0.6 to 1 mm circle of copper. A BGA's via field can leave a plane with a mesh of narrow necks between anti-pads; look at the actual plane layer in CAD, not at the schematic intent.
- **Edge effects.** Fields fringe at the board edge, so keep fast traces back from the plane edge by a few $h$ and run a ground via fence along the edge for emission-sensitive designs.
- **Thermal coupling.** The same copper that spreads heat from a hot IC also moves it to nearby parts. A voltage reference or a crystal in the path will drift.

## Bench verification

To verify that the plane is doing its job, measure. A TDR on a trace crossing a deliberate slot versus a solid reference shows the impedance bump and the inductive step. A near-field probe over a trace with and without a plane gap shows the field concentrating at the gap. For the transimpedance case, inject a small square wave at the amplifier input (through a small capacitor) and look for ringing in the output; a damped response with the cutout versus ringing without it demonstrates the stray capacitance argument. Measuring the input node capacitance directly with an LCR meter on an unpopulated board gives the stray values to compare with the formulas.

::: applications
- **USB/DDR/Ethernet boards**: planes under every signal layer for controlled impedance.
- **Op-amp transimpedance stages**: plane cutout under the feedback node, with a driven guard ring.
- **RF modules**: solid ground under the RF section, keep-out under the antenna.
- **Power converters**: ground plane on layer 2 under the switching loop to reduce its inductance, but removed under the inductor if the datasheet recommends.
- **Thermal management**: planes tied to the exposed pad of a regulator via a thermal via array.
:::

::: assumptions
- Multilayer FR-4 boards with an unbroken plane; 2-layer boards with a pour behave like a poorer version.
- $\varepsilon_r=4.3$, 1 oz copper, IPC-2141-style approximations; values are first-order.
- DC-to-hundreds-of-MHz regime. Above GHz, plane resonances, via transitions and loss dominate.
- Antenna and inductor keep-outs depend on the part; follow the datasheet.
- "Ground plane" in the antenna context also means the counterpoise that the antenna design *requires*; there the plane is a feature, not a cost.
:::

::: followups
### Why does a ground plane reduce crosstalk?
It confines each trace's field to the dielectric between the trace and the plane, and it gives the return current a tight path under each trace. Coupling to a neighbour falls with spacing relative to height ($\propto 1/(1+(s/h)^2)$ as a rough proxy). With the plane 1.6 mm away instead of 0.2 mm, the same spacing couples far more.

### When would you remove the ground plane under part of a circuit?
Under high-impedance analog nodes (to cut stray capacitance), under antennas and RF matching where the datasheet calls for a keep-out, and under power inductors if recommended. In each case I'd keep the plane elsewhere, with careful return-path consideration for any signal that crosses the cutout.

### Is a ground plane an ideal 0 V reference?
No. It has about 0.5 mΩ/□ of resistance and nanohenries of inductance. A switching converter's 5 A return current over a few squares can create tens of millivolts across the plane. Sensitive circuits should be located away from those currents, or the currents should be routed through paths that don't cross the sensitive area.

### What does a ground plane do to a trace's impedance?
It defines it. For a microstrip, $Z_0$ depends on the width and height above the plane; a thinner dielectric or wider trace lowers $Z_0$. Without a plane, a trace doesn't have a defined characteristic impedance.

### Scenario: an op-amp transimpedance amplifier oscillates on the new board but not on the breadboard. How might the ground plane be responsible?
The plane adds capacitance on the inverting-input node (pad, trace and via to plane), which adds a pole in the feedback path and reduces phase margin. For example 2 pF at the input with a 1 MΩ feedback resistor gives a pole near 80 kHz, well inside the loop bandwidth. I'd cut the plane out under the input node, shorten the node, and add a small feedback capacitor to restore the phase margin.
:::
