::: basics
### In plain words
An op-amp stage is a small amplifier built with feedback. You can wire it two ways. In the non-inverting way, the signal goes straight into the op-amp's plus input and the output has the same sign. In the inverting way, the signal goes through a resistor into the minus input and the output flips sign. Most of the time you prefer the non-inverting way because it barely loads whatever feeds it.

### Picture it
Think of reading the level in a water tank. A clear glass gauge on the side lets you see the level without taking any water out. That is the non-inverting input. A pipe that drains water out of the tank to measure it is the inverting input: you change the tank by measuring it. The comparison breaks down in one place: only the inverting stage can have a gain below one.

### Words you need
- **Input impedance**: how much a circuit's input resists drawing current from the source. Higher means it disturbs the source less.
- **Source resistance**: the resistance inside the thing driving the input, such as a sensor.
- **Gain**: output voltage divided by input voltage.
- **Inverting**: the output goes down when the input goes up.
- **Op-amp**: see [[q0121]]. The two circuits are compared in [[q0125]].

### The simplest example
A sensor puts out 1 V and has 10 kΩ of resistance inside. Feed it into an inverting stage with a 10 kΩ input resistor. The sensor and that resistor form a divider, so only 0.5 V reaches the amplifier. Now feed the same sensor into the plus input of a non-inverting stage. That input draws almost no current, so nearly the full 1 V arrives. That is the whole idea. The rest of this page adds the other advantages, and the cases where inverting still wins, such as summing and current-to-voltage conversion.
:::

::: testing
Whether you can **compare two circuits on engineering criteria** and give a balanced, reasoned preference instead of reciting "non-inverting is better". The interviewer wants:

1. The headline reason: **very high input impedance**, so the stage doesn't load the source (inverting input impedance is just $R_{in}$).
2. The supporting reasons: no phase inversion, can be unity-gain (buffer), source resistance doesn't enter the gain equation.
3. The **honest counter-points**: gain $\ge 1$ only, common-mode voltage on the inputs (CMRR and input range limits), and the inverting circuit's virtual ground advantages (summing, no CM error, often lower distortion).
4. The word "**often**" in the question: you should say when each wins.
:::

::: why
Choosing between these two stages is a daily decision in sensor and signal-chain design. A high-impedance source (a piezo sensor, a pH probe, a photodiode in voltage mode, a divider off a high-value resistor, an ADC reference node) can be wrecked by the wrong choice: the inverting amplifier's input resistance turns the source impedance into a gain error and an extra noise source. Conversely, a precision DC design with a wide common-mode swing may prefer the inverting form. Interviewers use this question to see whether you reason from source impedance, noise, bandwidth and input range, not from a memorized rule.
:::

::: concepts
- **Input impedance**: inverting $=R_{in}$; non-inverting $\approx$ the op-amp's input impedance (MΩ to TΩ). See [[q0125]].
- **Source loading**: a source with resistance $R_s$ forms a divider with the stage's input impedance.
- **Noise gain / bandwidth**: inverting gain $-G$ has noise gain $G+1$; non-inverting gain $G$ has noise gain $G$. See [[q0116]].
- **Common-mode input range and CMRR**: only the non-inverting circuit moves both inputs with the signal. See [[q0115]].
- **Virtual ground**: the inverting node sits at a fixed voltage, which makes summing easy. See [[q0124]].
- **Unity-gain buffer**: only possible with the non-inverting form.
:::

::: answer
"The main reason is input impedance. In a non-inverting amplifier the signal goes straight into the op-amp's plus input, which has an enormous impedance, megaohms or more, so it doesn't load the source. In an inverting amplifier the input impedance is just the input resistor, because the minus node is a virtual ground. If my source is a sensor with ten kilohms of output resistance and my input resistor is also ten kilohms, I've lost half my signal in a divider, and that source resistance also becomes part of the gain equation. With a non-inverting stage, the source resistance doesn't matter to the gain.

Other advantages: the output isn't inverted, so there's no phase flip to worry about, and I can set the gain to exactly one with a buffer, which is how I isolate a high-impedance node from a load. For the same noise gain the bandwidth is also a little better: a non-inverting gain of 10 has a noise gain of 10, whereas an inverting gain of minus 10 has a noise gain of 11.

But it's not always better. The non-inverting circuit can't have a gain below one. And both inputs swing with the signal, so I need to stay inside the common-mode range and the CMRR error adds to the signal. The inverting configuration keeps both inputs at a fixed voltage, which is why it's the choice for summing amplifiers, precision DC work and current-to-voltage conversion. So it's input impedance and source type that decide."
:::

::: technical
**Input impedance.** Inverting: $Z_{in}=R_{in}$ (the − node is at virtual ground). Non-inverting: $Z_{in}\approx Z_{diff}(1+A\beta)\,\|\,Z_{cm}$, effectively the op-amp's common-mode input impedance, which is MΩ to TΩ (device-dependent), in parallel with any bias network.

**Source resistance.** With source resistance $R_s$:
- Inverting: $A_v = -\frac{R_f}{R_{in}+R_s}$, so $R_s$ is part of the gain. E.g., $R_f=100$ kΩ, $R_{in}=10$ kΩ, $R_s = 10$ kΩ gives $-5$ instead of $-10$.
- Non-inverting: $A_v = (1+R_f/R_g)\cdot\frac{Z_{in}}{Z_{in}+R_s}$. For $Z_{in}\sim 1$ GΩ the error is ~$10^{-5}$ at $R_s = 10$ kΩ.

**Bandwidth.** Closed-loop bandwidth $\approx GBW/\text{noise gain}$, and noise gain is $1+R_f/R_{in}$ for both. For a signal gain of magnitude $G$: non-inverting noise gain $G$; inverting noise gain $G+1$. At $G=1$ the buffer has GBW of bandwidth while the inverting unity stage has GBW/2. At $G=10$ the difference is $\sim$9%.

**Common-mode.** Non-inverting: $V_{CM}\approx V_{in}$. A finite CMRR produces an error $V_{in}/\text{CMRR}$ referred to the input and requires $V_{in}$ inside the input common-mode range; distortion from input-stage nonlinearity with CM voltage can appear. Inverting: $V_{CM}$ is fixed (virtual ground or $V_{ref}$), so no CM error and typically better distortion.

**Noise.** The source noise and the amplifier's noise are the same for both on a given source, but the inverting circuit adds the thermal noise of $R_{in}$ in series with the source, while the non-inverting adds the thermal noise of the feedback divider ($R_f\|R_g$ at the − input).

> [!UNCERTAIN]
> Distortion and CMRR-related effects differ a lot between op-amp families (rail-to-rail input stages with crossover between pairs are particularly affected). Check the datasheet's THD vs. common-mode information, if given, for the specific part.
:::

::: short
"Non-inverting stages are often preferred because the input goes straight into the op-amp's high-impedance plus terminal, so they don't load the source or turn its resistance into a gain error. They also don't invert, can be built as a unity-gain buffer, and for the same signal gain have slightly better bandwidth. The downsides: the gain is at least one, and both inputs swing with the signal, so common-mode range and CMRR matter. For summing or low-impedance sources, the inverting stage is just as good."
:::

::: long
"The headline is input impedance. In a non-inverting amplifier the signal feeds the op-amp's plus input, and that's megaohms or more, so the stage barely loads the source. In an inverting amplifier the minus node is a virtual ground, so the input impedance is just the input resistor. If I have a sensor with ten kilohms of output impedance and an input resistor of ten kilohms, I lose half the signal, and the gain depends on the source impedance, which could vary with temperature or from sensor to sensor. For a very high-impedance source, like a piezo element or a pH probe, an inverting stage would need a huge input resistor, which brings noise and bias-current errors. A non-inverting stage with a CMOS or JFET-input op-amp just works.

There are secondary advantages. The output isn't inverted, which can matter for polarity in a signal chain. It can have a gain of exactly one, a buffer, which is the standard way to drive an ADC input or isolate a node. And for the same signal gain, the non-inverting stage has a slightly lower noise gain: a gain of 10 has noise gain 10, while an inverting gain of minus 10 has noise gain 11, so the bandwidth is about 9% better. At unity gain, the buffer gets the full gain-bandwidth product but the inverting stage only gets half.

But I wouldn't say it's always better. A non-inverting stage can't attenuate, because its gain is one plus a ratio. Since both inputs follow the signal, I need the signal to stay inside the common-mode input range, and finite CMRR creates a small error. In a precision circuit the inverting stage has the advantage that both inputs sit at a fixed voltage, so no CM error and usually lower distortion. It's also the natural choice for summing, mixing, DAC current-to-voltage conversion and transimpedance amplifiers, where the virtual ground is the whole point. So my rule is: high-impedance or voltage sources and buffering go non-inverting; current sources, summing and precision, low-impedance DC work often go inverting."
:::

::: terms
- **Input impedance**: the impedance the source sees; high for non-inverting, $R_{in}$ for inverting.
- **Source loading**: gain or signal loss caused by source resistance interacting with the input impedance.
- **Noise gain**: $1/\beta$; the gain seen by the amplifier's own noise and offset, which also sets bandwidth.
- **Common-mode input range**: the input-voltage range over which the amplifier works properly.
- **CMRR**: common-mode rejection ratio; ability to ignore voltages common to both inputs.
- **Virtual ground**: fixed voltage at the inverting node of an inverting stage.
- **Buffer (follower)**: non-inverting stage with unity gain.
- **Transimpedance amplifier**: current-to-voltage inverting stage with feedback resistor.
:::

::: exceptional
**An average answer** says "non-inverting has high input impedance" and stops.

**An exceptional answer**:
- Gives the **high-Z reason with a number** (a 10 kΩ source into 10 kΩ $R_{in}$ halves the signal) and says the source resistance becomes part of the *gain* in the inverting circuit.
- Lists secondary reasons: **no inversion, unity-gain buffer, slightly better bandwidth (noise gain)**, with the $G$ vs $G+1$ comparison.
- Volunteers the **counter-arguments**: gain $\ge 1$, **common-mode range/CMRR**, distortion, and the advantages of the virtual ground (summing, TIA, precision).
- Frames the answer as a **decision rule** depending on source type and requirements instead of a universal preference.
- Notes how input stage type (JFET/CMOS vs bipolar) and bias currents modify the picture.
:::

::: mistakes
- **"Non-inverting is always better."** It isn't: the virtual-ground circuits are better for current sources, summing, and CM-sensitive precision work.
- **Forgetting the minimum gain of 1** and then trying to use a non-inverting stage as an attenuator.
- **Ignoring source resistance in the inverting circuit.** It adds to $R_{in}$ and changes the gain; a sensor with variable output impedance gives variable gain.
- **Saying the non-inverting stage has "infinite" input impedance.** It's very high, but bias current, leakage, the bias network and input capacitance (which forms a pole with source resistance) all matter.
- **Ignoring common-mode range.** In single-supply designs, a non-inverting stage with a signal near a rail can fall outside the input range of a non-rail-to-rail op-amp.
- **Thinking bandwidth is much different.** The loop is the same for the same resistor ratio; the difference is the $+1$ in noise gain, which only matters at low gains.
:::

::: deep
## Why the non-inverting input is high impedance

The + input of the op-amp is just the gate or base of the input differential pair. For a FET input that is a capacitor of a few pF and a leakage current of pA or less; for a bipolar input it is a base current of nA to µA. Either way, the DC resistance seen at that pin is huge compared to any reasonable source. In the non-inverting circuit the feedback network connects to the *other* input, so it doesn't load the signal source at all.

In the inverting circuit the signal enters through $R_{in}$ into a node held at 0 V by feedback. All of the input current $V_{in}/R_{in}$ must be supplied by the source. So the input impedance is exactly $R_{in}$, which is typically 1 to 100 kΩ.

## Bandwidth: noise gain, not signal gain

The loop gain depends on $\beta = R_g/(R_g+R_f)$ in the non-inverting circuit and on $\beta = R_{in}/(R_{in}+R_f)$ in the inverting one, giving a noise gain of $1+R_f/R_{in}$ either way. If you want a **signal gain** of magnitude $G$:

| Signal gain | Noise gain | Bandwidth (GBW = 1 MHz) |
|---|---|---|
| Non-inverting, $+G=10$ | 10 | 100 kHz |
| Inverting, $-G=-10$ | 11 | 90.9 kHz |
| Non-inverting buffer ($+1$) | 1 | 1 MHz |
| Inverting unity ($-1$) | 2 | 500 kHz |

The buffer also tends to be the most demanding on stability: not every op-amp is stable at unity gain, so look for "unity-gain stable" in the datasheet.

## Common-mode: the downside of non-inverting

In the non-inverting circuit both inputs sit at $V_{in}$. Several consequences:
- The input must stay within the **common-mode input range**, which for non-rail-to-rail parts ends 1 to 2 V inside the supply rails.
- A finite CMRR produces an error. At 80 dB (a factor of $10^4$) and $V_{in} = 2$ V the equivalent differential error at the input is $2/10^4 = 200$ µV, which is then amplified by the gain of 11 to 2.2 mV at the output.
- The input stage operates over a varying bias point, which can increase distortion, particularly in rail-to-rail input stages that switch between two input pairs mid-range.

The inverting circuit holds the − and + inputs at a fixed potential (ground or a mid-supply reference), so it avoids all three. For a precision DC measurement of a low-impedance signal, such as a shunt voltage or a DAC output, the inverting stage is often the more accurate choice, and the output polarity can be fixed with a second stage or by software.

## Noise

Both circuits share the op-amp's voltage and current noise. The difference is in the resistors: the inverting stage inserts $R_{in}$ in series with the source, which adds thermal noise ($\sqrt{4kTR}\approx 12.9$ nV/√Hz for 10 kΩ at 300 K), while the non-inverting stage's only noisy resistors are $R_f\|R_g$ at the − input. For a high-impedance source this matters little because the source's own noise dominates, but for low-noise designs both the resistor values and topology matter.

## Which one when

| Situation | Better choice | Reason |
|---|---|---|
| High-impedance voltage sensor (piezo, pH, high-value divider) | Non-inverting | Doesn't load the source |
| Isolating a node / driving an ADC | Non-inverting buffer | Unity gain, high $Z_{in}$, low $Z_{out}$ |
| Photodiode or current-output DAC | Inverting (transimpedance) | The virtual ground holds the source at a fixed bias |
| Summing / mixing several inputs | Inverting | Each input sees its own resistor to the virtual ground |
| Attenuation (gain < 1) | Inverting (or a divider + buffer) | Non-inverting gain $\ge 1$ |
| Precision DC with big common-mode swing | Inverting | No CM error, fixed input potentials |
| Polarity must be preserved, single stage | Non-inverting | No inversion |

::: applications
- **Piezo, pH and electret-microphone front ends**: a high-impedance source into a non-inverting stage or buffer (usually a JFET/CMOS input).
- **Voltage references and DAC outputs**: a buffer to drive loads without disturbing a high-impedance reference node.
- **Instrumentation amplifier input stages**: the two input buffers are non-inverting amplifiers for exactly this reason.
- **Audio line input**: a non-inverting stage for high impedance, preserving phase.
- **Transimpedance amplifiers and summing amplifiers**: inverting configurations where the virtual ground is the feature.
- **Sample-and-hold buffers and ADC drivers**: unity-gain non-inverting buffers.
:::

::: assumptions
I assumed a voltage-feedback op-amp with high input impedance and the signal source is a voltage source with series resistance. For a **current-output source** (photodiode, current DAC) the inverting circuit is not just acceptable but the correct one. For **very low-impedance sources** (a 50 Ω generator) the input-impedance advantage disappears, and the inverting stage's virtual-ground benefits may win. If the op-amp is **bipolar input**, the non-inverting input bias current ($I_B$) flows through the source resistance and creates an offset; for high source resistances you want a FET/CMOS input. Rail-to-rail input stages and chopper-stabilized parts change the common-mode behavior. And I assumed the **gain is at least 1** is acceptable; if you need attenuation, use the inverting stage or a divider. The question says "often", so these exceptions are consistent with the intended answer.
:::

::: followups
### Your sensor has 100 kΩ output impedance and you need a gain of 10. Which topology and why?
Non-inverting. In an inverting stage, $R_{in}$ would have to be $\gg 100$ kΩ to keep the loading error low (say 1 MΩ for 10%, with $R_f$ = 10 MΩ for gain 10), which adds noise ($\sim$ 130 nV/√Hz for 1 MΩ) and bias-current offset. A non-inverting stage with a FET input and, say, $R_f = 90$ kΩ, $R_g = 10$ kΩ has almost no loading. I'd choose a low-bias-current op-amp.

### How does the bandwidth of the inverting amplifier compare with the non-inverting one for the same gain magnitude?
Bandwidth follows noise gain. Non-inverting gain $G$ has noise gain $G$; inverting gain $-G$ has noise gain $G+1$. With GBW = 1 MHz and $G = 10$, that's 100 kHz vs. about 91 kHz. The difference matters mostly at low gains: unity-gain buffer vs. unity-gain inverter is a factor of two.

### When would you pick the inverting amplifier despite its low input impedance?
When the source is a current (photodiode, DAC), when I need to sum several inputs, when I need a gain below one, when I want both inputs to sit at a fixed voltage for best accuracy and lowest distortion, or when the input signal might go outside the op-amp's common-mode range (the inverting input stays at the reference voltage).

### A rail-to-rail op-amp has a non-inverting buffer with a signal sweeping 0 to 3.3 V that has a glitch at mid-scale. Why?
Many rail-to-rail input stages use two complementary pairs (NMOS and PMOS) with a transition region. As the common-mode voltage sweeps through the crossover, the offset and bias current change, which causes a kink or glitch. That is a non-inverting (CM varies) problem. The inverting configuration, with a fixed CM, avoids it. Alternatives: a part with a single input pair or charge-pump-based input stage with no crossover.

### Harder: both inputs of your non-inverting amplifier carry 2 V of common-mode signal, and you measure a 3 mV error. What do you check?
First, CMRR: with 80 dB, 2 V common-mode gives 200 µV at the input, which is multiplied by the noise gain (11) to 2.2 mV, so 3 mV is the right order of magnitude. If you need less error, choose a part with higher CMRR (100+ dB), or restructure into an inverting stage where the CM is fixed, or use an instrumentation amplifier.
:::
