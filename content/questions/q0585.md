::: testing
Whether you know the term and the mechanism behind it. "Swiss cheesing" is slang for a plane so perforated by via antipads that it looks like Swiss cheese. A good answer:

1. Defines it and says what causes it (dense via fields, large antipads, aligned rows).
2. Explains the **three harms**: higher resistance and crowding, higher inductance, and broken return paths (slots) that raise crosstalk and EMI.
3. Gives the **fixes**: stagger, shrink, bridge, reposition, fewer vias.
4. Shows judgment about when it is acceptable.
:::

::: why
Planes are the foundation of power and signal integrity. A plane that looks fine in the layer view can be electrically a mesh of islands and necks. Layout reviews routinely look for it under BGAs and connectors, and a candidate who uses the term correctly signals real layout experience.
:::

::: concepts
- **Antipad**: clearance hole around a via passing through a plane. See [[q0574]].
- **Web / neck**: copper between holes. See [[q0584]].
- **Return path**: current follows the plane under a trace; slots force detours.
- **Slot antenna effect**: a slot of length near half a wavelength radiates.
- **Via field**: dense via array, e.g. under a BGA.
:::

::: answer
"Swiss cheesing is when you put so many vias through a plane that the clearance holes around them, the antipads, cover so much of it that it looks like Swiss cheese. It typically happens under a BGA or a dense connector, especially when the vias are in straight rows so the holes line up and the gaps between them merge into a slot.

The harm is that a plane stops behaving like a solid sheet. The copper between holes becomes narrow necks, so resistance goes up and current crowds, which causes IR drop and hot spots on a power plane. The plane inductance goes up. And a ground plane with slots forces return currents to detour around them, so the loop areas grow, and crosstalk and radiation get worse, especially if a fast trace crosses the slot.

To avoid it I stagger the via rows, use smaller pads and antipads, leave copper bridges, share ground vias, move vias out of the critical current area, or use blind and microvias that don't cut every layer."
:::

::: technical
**Definition.** A plane whose antipad voids are dense enough that remaining copper is a network of narrow webs or isolated islands.

**Cause.** Via count and layout: antipad diameter $d_a$ at pitch $p$ leaves web $W=p-d_a$. Rows at constant pitch align the voids; if $W$ is below a few tenths of a mm the row acts as a slot.

**Effects.**
1. Resistance: neck $R=R_sL/W$ with $R_s\approx0.49$ mΩ/sq (1 oz). See [[q0584]].
2. Inductance: longer current paths.
3. Return path: trace crossing a slot forces return to detour, enlarging loops; crosstalk and EMI increase.
4. Radiation: a slot of length $\ell$ becomes an efficient radiator near $\ell\approx\lambda/2$; keep slots well below $\lambda/20$ at the highest significant frequency. $\lambda/20$ in free space is 15 mm at 1 GHz and 7.5 mm at 2 GHz.

**Fixes.** Stagger; smaller drills/antipads; copper bridges; fewer vias; relocate; blind/micro vias; avoid routing fast signals across slots; add stitching.

> [!UNCERTAIN]
> The λ/20 guideline is a rule of thumb; the effective wavelength in the board is shorter than free space (εeff of about 2.5-3), so be more conservative.
:::

::: long
"Swiss cheesing is the term for a plane that's so full of via clearance holes it looks like Swiss cheese. You see it under BGAs, big connectors, or anywhere there's a dense via field, especially if the vias are in straight rows.

The problem is that each via that passes through the plane without connecting to it takes an antipad. When those get close, the copper between them is only a narrow web. If they're lined up, they act as one long slot.

That causes three problems. First, resistance: a 0.1 millimetre web ten millimetres long is about 50 milliohms on one-ounce copper, so on a power plane current crowds, voltage drops and hot spots form. Second, inductance goes up because current detours. Third, and most important for ground planes, return current under a trace can't cross the slot, so it goes around it. A fast signal crossing that slot has a big loop, so crosstalk and radiation rise, and a slot near a half wavelength radiates like an antenna.

To avoid it I stagger via rows so the voids don't line up, use the smallest pads and antipads the fab allows, leave deliberate copper bridges, share ground vias, avoid routing fast traces over via fields, and use blind or microvias where possible."
:::

::: terms
- **Swiss cheese plane**: heavily perforated plane.
- **Antipad**: clearance void around a via.
- **Web**: copper between voids.
- **Slot**: long gap in a plane.
- **Return current**: current returning under a signal trace.
- **Stagger**: offset adjacent via rows.
:::

::: exceptional
**Average**: "Too many holes in the plane."

**Exceptional**:
- Distinguishes scattered holes from aligned rows that form slots.
- Gives numbers (web resistance, λ/20).
- Names three harms: resistance, inductance, return path/EMI.
- Lists multiple fixes and when it is tolerable.
:::

::: mistakes
- **Thinking only count matters.** Alignment makes slots.
- **Ignoring return path for signals crossing the area.**
- **Using huge antipads by default.** Minimise per voltage/fab rules.
- **Believing a plane is solid because the layer view looks filled.** Check copper maps.
- **Fixing with more vias.** Stitching vias also perforate.
:::

## Numbers

Web $W=p-d_a$. At $p=1.0$, $d_a=0.9$ mm: 0.1 mm; 10 mm of it is 100 squares, 49 mΩ for 1 oz copper (147 mV at 3 A). Offsetting alternate rows by half a pitch (row spacing 1.0 mm) makes the nearest-neighbour distance $\sqrt{0.5^2+1.0^2}=1.12$ mm, so the web becomes 1.12 - 0.9 = 0.22 mm, more than twice as wide, and the aligned-slot is gone.

## Slots and EMI

A slot radiates efficiently as its length approaches $\lambda/2$. A conservative guide is to keep slot lengths below $\lambda/20$ at the highest frequency of concern.

## Return-path view

A microstrip over a plane returns current directly beneath it. A slot across that path forces the current around the end, adding loop inductance (nH per mm of detour scale) and coupling to neighbours. For high-speed nets, do not route across via fields; reference to a plane with continuous copper.

## Fixes

| Fix | Effect |
|---|---|
| Stagger rows | continuous diagonal channels |
| Smaller drill and antipad | wider webs |
| Fewer vias, shared ground vias | less perforation |
| Copper bridges / split via groups | deliberate current lanes |
| Blind/micro vias | don't cut every plane |
| Route fast nets away | avoid slot crossings |

> [!INTERVIEW]
> If asked "is it ever OK?": yes on a plane carrying little current and no fast references, but check it, don't assume.
:::

::: applications
- **BGA breakout** under processors/FPGAs.
- **Dense connector footprints** (backplanes, FMC).
- **Memory interfaces** with many vias per byte lane.
- **Power stages** where vias cluster at pads.
- **HDI boards** using microvias to avoid perforation.
:::

::: assumptions
- 1 oz copper, FR-4, through vias with 0.9 mm antipads.
- λ/20 uses free-space wavelength; board effective εr shortens it.
- Staggered channel width assumes a square lattice offset by half a pitch.
- "Swiss cheese" is informal; no standard threshold exists.
:::

::: followups
### What's the difference between Swiss cheese and an intentional plane split?
A split is deliberate and its return path planned; Swiss cheese is an accidental by-product of via placement.

### How would you detect it in a design?
Plane copper density maps, DRC for minimum neck width, and a visual check of via arrays; for high speed, check slots against traces.

### Can stitching vias also cause it?
Yes. Stitching adds holes in the planes it passes through; space them from λ/20 rules, not maximum density.

### Does Swiss cheese matter on a 4-layer low-speed board?
Less, but power-plane IR drop and EMI can still bite; check under dense connectors.

### Scenario: DDR signals show crosstalk only where they cross the BGA via field. Why?
The reference plane under that region is perforated; return currents detour, enlarging loops. Stagger vias, shrink antipads, or re-layer signals to a plane with a solid region.
:::

::: interpretations
"Swiss cheesing" usually means the accidental perforation described. Some engineers also use it for intentionally hatched or perforated pours; those are different, designed structures.
:::
