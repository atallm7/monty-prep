::: basics
### In plain words
Swiss cheesing is slang for a plane that has so many via clearance holes that it looks like Swiss cheese. It happens under chips with dense via fields, and it is worst when holes line up in rows. The copper between holes becomes thin necks, so resistance and inductance go up. A row of merged holes also acts as a slot, which makes signal return currents detour and increases crosstalk and radiation.

### Picture it
Think of the perforated line between postage stamps. A straight row of small holes makes a weak line, and the paper tears along it. That is a slot. Scattered, offset holes would leave the paper in one piece. In the same way, aligned via holes make a straight line the current cannot easily cross.

### Words you need
- **Antipad**: the clearance hole in a plane around a via that does not connect to it.
- **Slot**: a long gap in a plane, made when holes in a row merge.
- **Web**: the copper strip left between two neighboring holes. It is the pitch minus the hole diameter.
- **Return current**: the current flowing back to its source, usually in the plane under the signal trace.
- **Stagger**: offsetting rows of vias so the holes do not line up.

### The simplest example
Say vias sit 1.0 mm apart and each antipad is 0.9 mm wide. The web between them is only 1.0 - 0.9 = 0.1 mm. A row of those is almost a slot. Staggering the rows at the same via density, about one via per mm², raises the nearest spacing to about 1.07 mm, so the narrowest web grows only to about 0.17 mm. The real gain is that no straight slot remains. To widen the webs, shrink the antipads: 0.7 mm antipads leave 0.3 mm.

That is the whole idea: align and pack holes carelessly and you cut the plane into strips. The rest of this page covers return paths, EMI and the fixes.
:::

::: answer
"Swiss cheesing is when you put so many vias through a plane that the clearance holes around them, the antipads, cover so much of it that it looks like Swiss cheese. It typically happens under a BGA or a dense connector, especially when the vias are in straight rows so the holes line up and the gaps between them merge into a slot.

The harm is that a plane stops behaving like a solid sheet. The copper between holes becomes narrow necks, so resistance goes up and current crowds, which causes IR drop and hot spots on a power plane. The plane inductance goes up. And a ground plane with slots forces return currents to detour around them, so the loop areas grow, and crosstalk and radiation get worse, especially if a fast trace crosses the slot.

To avoid it I stagger the via rows, use smaller pads and antipads, leave copper bridges, share ground vias, move vias out of the critical current area, or use blind and microvias that don't cut every layer."
:::

::: technical
**Definition.** A plane whose antipad voids are dense enough that remaining copper is a network of narrow webs or isolated islands.

**Cause.** Via count and layout: antipad diameter $d_a$ at pitch $p$ leaves web $W=p-d_a$. Rows at constant pitch align the voids; if $W$ is below a few tenths of a mm the row acts as a slot.

**Effects.**
1. Resistance: neck $R=R_sL/W$ with $R_s\approx0.49$ mΩ/sq (1 oz). See [[q0584]].
2. Inductance: longer current paths.
3. Return path: trace crossing a slot forces return to detour, enlarging loops; crosstalk and EMI increase.
4. Radiation: a slot of length $\ell$ becomes an efficient radiator near $\ell\approx\lambda/2$; keep slots well below $\lambda/20$ at the highest significant frequency. $\lambda/20$ in free space is 15 mm at 1 GHz and 7.5 mm at 2 GHz.

**Fixes.** Stagger; smaller drills/antipads; copper bridges; fewer vias; relocate; blind/micro vias; avoid routing fast signals across slots; add stitching.

> [!UNCERTAIN]
> The λ/20 guideline is a rule of thumb; the effective wavelength in the board is shorter than free space (εeff of about 2.5-3), so be more conservative.
:::

::: long
"Swiss cheesing is the term for a plane that's so full of via clearance holes it looks like Swiss cheese. You see it under BGAs, big connectors, or anywhere there's a dense via field, especially if the vias are in straight rows.

The problem is that each via that passes through the plane without connecting to it takes an antipad. When those get close, the copper between them is only a narrow web. If they're lined up, they act as one long slot.

That causes three problems. First, resistance: if current has to run ten millimetres along a 0.1 millimetre channel of copper, that's about 50 milliohms on one-ounce copper, so on a power plane current crowds, voltage drops and hot spots form. Second, inductance goes up because current detours. Third, and most important for ground planes, return current under a trace can't cross the slot, so it goes around it. A fast signal crossing that slot has a big loop, so crosstalk and radiation rise, and a slot near a half wavelength radiates like an antenna.

To avoid it I stagger via rows so the voids don't line up, use the smallest pads and antipads the fab allows, leave deliberate copper bridges, share ground vias, avoid routing fast traces over via fields, and use blind or microvias where possible."
:::

- **Slot**: long gap in a plane.
- **Return current**: current returning under a signal trace.
- **Stagger**: offset adjacent via rows.

- **Thinking only count matters.** Alignment makes slots.
- **Ignoring return path for signals crossing the area.**
- **Using huge antipads by default.** Minimise per voltage/fab rules.

## Numbers

Web $W=p-d_a$. At $p=1.0$, $d_a=0.9$ mm: 0.1 mm. If current were forced along a 10 mm channel that narrow, it would be 100 squares, 49 mΩ for 1 oz copper (147 mV at 3 A); a real field has many channels in parallel, so treat that as a worst case.

Staggering alone does not buy much web width at the same via density: even the best arrangement, a hexagonal pattern with one via per mm², has a nearest-neighbour spacing of about 1.07 mm, so the narrowest web only grows from 0.1 to about 0.17 mm. Its real benefit is that the voids no longer line up, so there is no straight slot for a return current to run into. To widen the webs themselves, shrink the antipads (0.7 mm at 1.0 mm pitch leaves 0.3 mm) or spread the vias out, as in the right half of the figure.

## Slots and EMI

A slot radiates efficiently as its length approaches $\lambda/2$. A conservative guide is to keep slot lengths below $\lambda/20$ at the highest frequency of concern.

## Return-path view

A microstrip over a plane returns current directly beneath it. A slot across that path forces the current around the end, adding loop inductance (nH per mm of detour scale) and coupling to neighbours. For high-speed nets, do not route across via fields; reference to a plane with continuous copper.

## How far does the return current spread? Why the holes must be near the trace to matter

The usual picture says the return current flows "right under the trace". Quantitatively, for a microstrip at height $h$ over a solid plane, the return current density at lateral distance $d$ from the trace is

$$J(d)=\frac{I}{\pi h}\cdot\frac{1}{1+(d/h)^2}$$

At high frequency this is the distribution that minimizes loop inductance. The fraction of the return current within $\pm d$ of the centerline is therefore

$$F(d)=\frac{2}{\pi}\arctan\frac{d}{h}$$

| Lateral distance | $F(d)$ |
|---|---|
| $\pm1h$ | 50% |
| $\pm3h$ | 80% |
| $\pm5h$ | 87% |
| $\pm10h$ | 94% |

For a trace 0.15 mm above its reference plane, 80% of the return current is within ±0.45 mm, and 95% within about ±1.5 mm. The consequence for Swiss-cheese layouts: antipads that touch the strip's corridor (within a few $h$) disturb most of the return current, while holes 10 mm away barely matter. It also explains why a slot only a few millimeters from a trace is almost as bad as one directly under it, and why moving a via field away from a critical net by $\geq 5h$ is a meaningful fix.

> [!NOTE]
> The $1/(1+(d/h)^2)$ profile is the standard result for a thin strip over an infinite ground plane at frequencies high enough that the return current takes the path of least inductance (roughly above a few MHz for this geometry). At DC the return current takes the least-resistance path instead, which can be far from the trace.

## What a slot crossing costs, with a number

When a signal crosses a slot, its return current has to go around the end of the slot. The extra loop area adds inductance, and for a driver edge that inductance produces a voltage disturbance $\Delta V = L_{extra}\,dI/dt$. A 3.3 V driver pushing a 66 mA step (3.3 V into 50 Ω) with a 200 ps edge has

$$\frac{dI}{dt}=\frac{0.066\ \text{A}}{0.2\ \text{ns}}=0.33\ \text{A/ns}$$

| Extra loop inductance | $\Delta V$ |
|---|---|
| 0.5 nH | 0.17 V |
| 1 nH | 0.33 V |
| 2 nH | 0.66 V |
| 4 nH | 1.3 V |

A detour of a centimeter or so easily reaches a nanohenry or two, so the disturbance is a big fraction of a 3.3 V swing. It also appears as noise on whatever else shares the gap, which is why slot crossings dominate crosstalk and radiated emissions problems.

> [!UNCERTAIN]
> The relation between detour length and added inductance depends on trace height, slot width, and how the return current actually wraps the end of the slot. The table shows the sensitivity (volts per nanohenry) rather than a prediction. Use a 3-D field solver, or measure.

## A slot as an antenna: where the λ/20 rule comes from

A slot in a plane resonates when its length is a half wavelength, with the wavelength set by the effective permittivity of the media on each side. For a slot in an inner plane of an FR-4 board take $\varepsilon_{eff}\approx2.7$ as a rough number. Then

$$f_{res}=\frac{c}{2\ell\sqrt{\varepsilon_{eff}}}$$

| Slot length | $f_{res}$ |
|---|---|
| 5 mm | 18.3 GHz |
| 10 mm | 9.1 GHz |
| 15 mm | 6.1 GHz |
| 30 mm | 3.0 GHz |

So a 15 mm slot (the 12-via row at 1.27 mm pitch from the figure) resonates near 6 GHz and starts to radiate efficiently well below that when driven by edges with energy above 1 GHz. The $\lambda/20$ rule used on this page is deliberately conservative by about a factor of ten against the resonance, because radiation efficiency rises steeply as the slot approaches half a wavelength and the harmonics of a fast edge are broadband. Inside an FR-4 stackup, with the same $\varepsilon_{eff}\approx2.7$, the in-board wavelength at 1 GHz is about $3\times10^8/(10^9\sqrt{2.7})=183$ mm, so $\lambda/20\approx9$ mm: tighter than the 15 mm free-space figure, which is why the page warns to be more conservative.

> [!UNCERTAIN]
> $\varepsilon_{eff}$ for a slot between layers depends on the stackup, on which side the nearest dielectric is, and on whether the slot is on an inner or outer layer. Use 2.5–3 as a rough range. Treat the table as an estimate of where the problem starts, not as a pass/fail test.

## A via that connects to a plane does not Swiss-cheese it

One subtlety that helps in a stackup argument: an antipad is only cut where the via does *not* connect. A ground via that ties to a ground plane has copper (or thermal-relief spokes) in that plane, not a void. So in a typical 4-layer stackup (signal, ground, power, signal) a ground via cuts an antipad only in the power plane, and a power via cuts one only in the ground plane. In a 6-layer board with two ground planes and one power plane, a signal via cuts an antipad in all three, a ground via cuts one (the power plane), and a power via cuts two. That is why a field of *signal* vias, such as a high-pin-count BGA's escape area, does the most damage to both planes, and why "fix it with more stitching vias" ends up perforating the power plane but not the ground plane.

## A worked review of a BGA escape

A 1 mm pitch BGA with 400 balls (20 × 20) has a signal-via field of about 20 mm × 20 mm. Suppose half the balls are signals with through vias on a 4-layer board with 0.9 mm antipads in the 1 oz ground and power planes. Then there are 200 antipads per plane within the footprint, each removing $\frac{\pi}{4}(0.9)^2=0.64$ mm², so $200\times0.64=127$ mm² of the 400 mm² footprint, or 32% of the plane under the part, and with the ball pitch and via positions on a grid, the webs between via rows are only $1.0-0.9=0.1$ mm. In this situation you would:

1. Move the vias to the hexagonal or staggered pattern the BGA fanout allows. This gives continuous diagonal channels even though the web width is the same.
2. Reduce the antipad to the fab's minimum for the voltage (for example 0.6 mm), which opens the webs to 0.4 mm and cuts the removed area to $200\times0.28=57$ mm², or 14%.
3. Reserve plane copper for the return current under the highest-speed nets by routing those on layers where the reference plane has the fewest voids.
4. Where the plane must carry current to the core, add a second power plane layer or a copper pour on an outer layer in parallel.

## What to verify

- **Copper maps**: view each plane layer with only the copper shown; slots and islands are obvious.
- **DRC**: set a minimum neck width of at least a few tenths of a millimeter on plane layers.
- **Crosstalk or TDR coupon**: a trace crossing a via row on a test board shows the reflection and the extra coupling to a neighbor.
- **Near-field scan or conducted/radiated pre-scan**: a slot crossing shows up as a narrow-band emission that moves when the slot is bridged with a ground via or a stitching capacitor.

## Fixes

| Fix | Effect |
|---|---|
| Stagger rows | no straight slot; current zig-zags through diagonal channels |
| Smaller drill and antipad | wider webs |
| Fewer vias, shared ground vias | less perforation |
| Copper bridges / split via groups | deliberate current lanes |
| Blind/micro vias | don't cut every plane |
| Route fast nets away | avoid slot crossings |

> [!INTERVIEW]
> If asked "is it ever OK?": yes on a plane carrying little current and no fast references, but check it, don't assume.
:::

- **BGA breakout** under processors/FPGAs.
- **Dense connector footprints** (backplanes, FMC).
- **Memory interfaces** with many vias per byte lane.
- **Power stages** where vias cluster at pads.
- **HDI boards** using microvias to avoid perforation.

::: followups
### What's the difference between Swiss cheese and an intentional plane split?
A split is deliberate and its return path planned; Swiss cheese is an accidental by-product of via placement.

### How would you detect it in a design?
Plane copper density maps, DRC for minimum neck width, and a visual check of via arrays; for high speed, check slots against traces.

### Can stitching vias also cause it?
Yes. Stitching adds holes in the planes it passes through; space them from λ/20 rules, not maximum density.

### Does Swiss cheese matter on a 4-layer low-speed board?
Less, but power-plane IR drop and EMI can still bite; check under dense connectors.

### Scenario: DDR signals show crosstalk only where they cross the BGA via field. Why?
The reference plane under that region is perforated; return currents detour, enlarging loops. Stagger vias, shrink antipads, or re-layer signals to a plane with a solid region.
:::

::: interpretations
"Swiss cheesing" usually means the accidental perforation described. Some engineers also use it for intentionally hatched or perforated pours; those are different, designed structures.
:::
