::: basics
### In plain words
Hysteresis means a circuit has two different switching points, depending on which way the input is moving. On the way up, the output flips at an upper threshold. On the way down, it flips at a lower one. A Schmitt trigger is a circuit built this way. It stops a noisy or slow input from making the output flicker near a single switching point.

### Picture it
Think of a home thermostat. If it turned the heater on at exactly 70 degrees and off at exactly 70 degrees, the heater would click on and off all day as the temperature wobbled around 70. So real thermostats turn the heater on at 68 and off at 72. That gap is the hysteresis.

### Words you need
- **Threshold**: the input voltage at which a circuit's output flips.
- **Hysteresis**: the gap between the upper and lower thresholds.
- **Schmitt trigger**: a circuit or input with hysteresis.
- **Chatter**: rapid repeated flipping of the output when a noisy input hovers near a threshold.
- **Positive feedback**: sending part of the output back to the input so that it reinforces the output's current state. This is how the two thresholds are created.

### The simplest example
A 3.3 V circuit has one threshold at 1.65 V. A slowly rising input has 0.1 V of noise, so it wobbles between 1.60 V and 1.70 V for a while. Each wobble crosses 1.65 V, so the output flips many times.

Now give it hysteresis with an upper threshold of 1.815 V and a lower one of 1.485 V, a gap of 0.33 V. The output flips high once, when the input first passes 1.815 V. The 0.1 V noise cannot bring it back down to 1.485 V, so the output stays put.

That is the whole idea: a gap wider than the noise stops chatter. The rest of this page shows how to build it, the delay it costs, and uses like button debouncing.
:::

::: why
Real inputs aren't clean: sensor signals are slow, switches bounce, long cables pick up noise. A single-threshold comparator or inverter reading such a signal toggles repeatedly as the input wanders around the threshold, which turns into chatter, extra interrupts and extra current. Hysteresis is the cheap, standard cure and shows up on almost every board: reset supervisors, push-button inputs, thermostats, power-good comparators, and the inputs of many microcontrollers and logic gates. It also ties directly to the monotonicity discussion in [[q0690]] and [[q0691]].
:::

- **Voltage divider**: sets how much of the output is fed back. See [[q0008]].
- **Threshold, noise margin**: the signal must clear the switching point by more than the noise. See [[q0687]].
- **Ringback and monotonicity**: hysteresis tolerates ringback smaller than its window. See [[q0691]].

"Hysteresis means a circuit has two different switching thresholds depending on which way the input is moving. On the way up, the output flips at an upper threshold $V_{T+}$; on the way down it flips at a lower threshold $V_{T-}$. The gap between them is the hysteresis.

You get it with positive feedback. In a comparator, you feed a fraction of the output back to the non-inverting input through a resistor divider. When the output is high it pushes the reference up a bit; when it's low it pulls it down. So once the output has switched, the input has to move back past the opposite threshold, not just the same one, to switch it back.

Why use it: if the input is slow or noisy, with a single threshold the output would toggle every time noise carried it across. With hysteresis wider than the noise, the output switches once. That's what Schmitt-trigger inputs do on microcontroller pins, button debouncing, slow sensor inputs, and I²C inputs. The cost is some delay and a dead band, and if the noise is bigger than the window, it still chatters."
:::

::: technical
**Definition.** A hysteretic element has a transfer characteristic with a loop: the output transitions at $V_{T+}$ when the input rises and at $V_{T-}$ when it falls, with $V_{T+} > V_{T-}$. The width $V_H = V_{T+} - V_{T-}$ is the hysteresis.

**Comparator with positive feedback (non-inverting form).** Input through $R_1$ to the $+$ pin, feedback $R_f$ from output to the $+$ pin, reference $V_{ref}$ at the $-$ pin:

$$V_+ = \frac{V_{in}R_f + V_{out}R_1}{R_1+R_f}$$

The output flips when $V_+ = V_{ref}$, so $V_{in}$ switch points are

$$V_{T}(V_{out}) = V_{ref}\,\frac{R_1+R_f}{R_f} - V_{out}\,\frac{R_1}{R_f}$$

With output levels $V_{OL}=0$ and $V_{OH} = 3.3$ V, $V_{ref} = 1.65$ V, $R_1 = 10$ kΩ, $R_f = 100$ kΩ: $V_{T+} = 1.815$ V (output low, rising input) and $V_{T-} = 1.485$ V (output high, falling input). Hysteresis: $V_H = (V_{OH}-V_{OL})\,R_1/R_f = 0.33$ V. The window is centred on 1.65 V here only because $V_{ref}$ happens to sit at mid-swing; in general the centre is $V_{ref}(1+R_1/R_f) - \frac{R_1}{R_f}\frac{V_{OH}+V_{OL}}{2}$.

**Op-amp with $\pm V_{sat}$ (inverting Schmitt).** Thresholds $\pm V_{sat}\frac{R_2}{R_1+R_2}$, width $2V_{sat}\frac{R_2}{R_1+R_2}$.

**CMOS Schmitt-trigger inputs** (e.g. 74HC14-style gates) build the same effect with transistors; the datasheet lists typical or min/max $V_{T+}$, $V_{T-}$ and $V_H$.

**Design rule.** Choose $V_H$ larger than the peak-to-peak noise on the input at the threshold and smaller than the signal swing minus margin. Each doubling of $R_f$ halves $V_H$.

**Costs.** Switching points shift with the output state, so the effective delay depends on edge speed; thresholds become less precise; output can still chatter if noise exceeds $V_H$. Open-drain outputs change $V_{OH}$ and hence the thresholds.
:::

::: long
"Hysteresis means a switching device has two thresholds instead of one. Say a comparator is switching at 1.65 volts. With hysteresis, when the input rises it only trips the output high at, say, 1.8 volts; and when the input falls, it only trips low at 1.5 volts. The difference, 0.3 volts, is the hysteresis. If you plot output against input it makes a little rectangular loop instead of one step.

The usual way to build it is positive feedback. In a comparator I'd run the input through a resistor $R_1$ to the plus pin, and feed back a larger resistor $R_f$ from the output to the plus pin. When the output is high it adds a bit of voltage to the plus node; when it's low it subtracts. So the input threshold depends on the current output state. The hysteresis width is the output swing times $R_1/R_f$, so with 3.3 volts swing and a ratio of 1 to 10, that's 0.33 volts.

Why use it? Real inputs aren't clean. Take a slow ramp from a sensor with 100 millivolts of noise sitting on it. A plain comparator will see the noisy ramp cross the threshold five or six times and the output will buzz. With 0.33 volts of hysteresis the output switches exactly once. That's why microcontroller pins have Schmitt inputs, why you debounce a button with an RC into a Schmitt gate, and why I²C devices specify hysteresis. Same idea in a thermostat or a battery low-voltage cutoff so it doesn't flap on and off.

The trade-offs: it adds delay and shifts the effective threshold, and it only helps if the noise is smaller than the window. If it isn't, you need filtering or a bigger window."
:::

::: terms
- **Hysteresis ($V_H$)**: the difference between the upper and lower switching thresholds.
- **$V_{T+}$ / $V_{T-}$**: positive-going and negative-going input threshold voltages.
- **Schmitt trigger**: a circuit with hysteresis, built from a comparator with positive feedback or special CMOS input stages.
- **Positive feedback**: feeding part of the output back so it reinforces the current output state.
- **Chatter**: rapid repeated output toggling when a noisy input hovers near a threshold.
- **Dead band**: input range inside the window where the output doesn't change.
- **Debouncing**: removing the multiple transitions generated by a mechanical contact.
:::

::: exceptional
An average answer says "it makes a Schmitt trigger so noise doesn't cause false triggering". An exceptional answer draws the **two-threshold loop**, gives the formula for the thresholds for a concrete resistor network (for example $V_{T\pm}$ of 1.815 V and 1.485 V from 10 kΩ/100 kΩ), states the design rule ("window wider than noise, narrower than swing"), explains the behaviour in a time-domain picture (noisy slow ramp crosses a single threshold five times but a Schmitt once), and lists the **costs** (delay, dead band, doesn't fix noise bigger than the window). It also names uses: I²C inputs, debouncing, relaxation oscillators, supervisor ICs, and connects it to ringback tolerance ([[q0691]]).
:::

::: mistakes
- **Thinking hysteresis filters noise.** It rejects noise smaller than the window at the switching moment; it doesn't remove noise from the signal and fails if noise exceeds the window.
- **Putting the feedback on the wrong input.** Positive feedback (to the non-inverting input for the standard comparator) produces hysteresis; negative feedback would make it a linear amplifier.
- **Forgetting the output levels in the calculation.** The window is $(V_{OH}-V_{OL})R_1/R_f$; for open-drain outputs the high level is set by the pull-up and varies.
- **Assuming the thresholds are symmetric around the reference.** They are shifted by the feedback network; calculate both explicitly.
- **Making the window too wide.** The signal must still swing past both thresholds with margin, or the circuit will latch in one state.
- **Ignoring added delay and jitter.** For slow inputs the switching moment moves later; for precision timing use a faster edge or a different approach.
:::

::: deep
## The idea in one picture

With one threshold $V_{th}$ the transfer curve is a single step: output low below, high above. With hysteresis it becomes a loop. Moving right (rising input), the output stays low until $V_{T+}$; moving left, it stays high until $V_{T-}$. In between, the output depends on *history*: the circuit has memory.

Figure: The output is fed back through R_f to the + input. When V_out is high the + node is pushed up, so V_in must fall further to trip it low; when V_out is low the + node is pulled down, so V_in must rise further to trip it high.

**Derivation.** By superposition (comparator input draws no current), the voltage at the $+$ node is a weighted average of $V_{in}$ and $V_{out}$:

$$V_+ = \frac{V_{in}/R_1 + V_{out}/R_f}{1/R_1 + 1/R_f} = \frac{R_f V_{in} + R_1 V_{out}}{R_1+R_f}$$

The comparator flips when $V_+ = V_{ref}$. Solve for $V_{in}$:

$$V_{in,trip} = V_{ref}\left(1+\frac{R_1}{R_f}\right) - \frac{R_1}{R_f}V_{out}$$

Output low ($V_{out}=0$): $V_{T+} = 1.65\cdot 1.1 = 1.815$ V. Output high ($V_{out}=3.3$): $V_{T-} = 1.815 - 0.1\cdot 3.3 = 1.485$ V. The hysteresis is $V_H = (V_{OH}-V_{OL})R_1/R_f = 0.33$ V.

**Design procedure.**
1. Choose the center voltage $V_C$ (about where you'd have set a plain threshold) and the width $V_H$ (greater than the peak-to-peak noise, say 2x).
2. $R_1/R_f = V_H/(V_{OH}-V_{OL})$.
3. Solve for the reference from the centre formula: with $k = R_1/R_f$ and $V_{OL}=0$, $V_{ref} = (V_C + kV_{OH}/2)/(1+k)$. Then check both thresholds from the formula above.
4. Pick $R_f$ large enough not to load the output or the source (tens to hundreds of kΩ), and include the source resistance of $V_{in}$ in $R_1$.

With thresholds at 1.485 V and 1.815 V (grey lines) the output (green) switches high once at 10.8 µs and stays there, because the noise never carries the input back below 1.485 V.

The ramp is 0.165 V/µs, while the noise slope is $0.12\cdot 2\pi\cdot 1.3\text{ MHz} \approx 0.98$ V/µs: locally, noise dominates the slope, and that's exactly when a single threshold fails. The condition for single switching is: noise peak-to-peak (0.24 V) < $V_H$ (0.33 V).

## Delay is the price

A rising ramp crosses $V_{T+}$ later than it would cross $V_{ref}$. For a ramp of slope $s$, the added delay is $(V_{T+}-V_{ref})/s = 0.165/0.165$ V/µs = 1 µs here. On the way down the switching is earlier or later by the same sort of amount, so the output pulse width distorts too. For a fast clean edge the delay is negligible; for slow edges it can matter.

## Variants and real parts

- **CMOS Schmitt-trigger gates** (the 74HC14 and 74LVC1G17 families, among others) have built-in thresholds; the datasheet gives typical and limits for $V_{T+}$, $V_{T-}$ and $V_H$ at each supply. Don't assume 1/3 and 2/3 of $V_{DD}$; take values from the datasheet for your part.
- **Comparators with built-in hysteresis** (some include a few mV to tens of mV, or a pin to adjust it) avoid external resistors for small windows.
- **Supervisors and thermal switches** add hysteresis so a threshold crossing doesn't flap: a power-good that releases at 3.0 V and re-asserts at 2.9 V.
- **Open-drain comparators** need the pull-up included in the divider calculation, since $V_{OH}$ is the pull-up rail.

> [!UNCERTAIN]
> In the NXP UM10204 I²C-bus specification, Standard-mode inputs have no hysteresis requirement, while Fast-mode and Fast-mode Plus inputs must have Schmitt-trigger hysteresis of at least 0.05 $V_{DD}$ (0.1 $V_{DD}$ for $V_{DD}$ below 2 V), together with 50 ns spike suppression. Check the I/O-stage characteristics table of the revision you design to; many Standard-mode parts include hysteresis anyway.

## Relaxation oscillator: hysteresis creates oscillation

An inverting Schmitt gate with an RC from output to input is a clock generator: output high charges $C$ through $R$ up to $V_{T+}$, the gate flips, output low discharges $C$ down to $V_{T-}$, flip, repeat. With $V_{DD} = 3.3$ V, $V_{T+} = 1.9$ V, $V_{T-} = 1.3$ V:

$$T = RC\left[\ln\frac{V_{DD}-V_{T-}}{V_{DD}-V_{T+}} + \ln\frac{V_{T+}}{V_{T-}}\right] = 0.736\,RC$$

With $R = 10$ kΩ and $C = 100$ nF, $T = 0.736$ ms ($f \approx 1.36$ kHz). Thresholds vary part to part, so this is for LED blinkers, not timing references.

## Debouncing a button

A push button produces bounces for roughly milliseconds. Feed it through an RC and a Schmitt input: with $R = 10$ kΩ and $C = 1$ µF ($\tau = 10$ ms), the capacitor takes $\tau\ln\!\left(1/(1-1.9/3.3)\right) = 8.6$ ms to reach $V_{T+} = 1.9$ V. Short bounce glitches never carry it back below $V_{T-}$, so there's one clean transition. The RC supplies the slow edge; the Schmitt input turns it into a crisp logic edge.

::: applications
- **Microcontroller GPIO and logic inputs with Schmitt option**: button and slow-sensor inputs without chatter.
- **Button debouncing**: RC into a Schmitt buffer such as a 74HC14-type gate.
- **Battery undervoltage lockout**: a supervisor or comparator with hysteresis so the load doesn't reconnect as soon as voltage recovers.
- **Thermostats and fan controllers**: turn on at 60°C, off at 55°C to avoid rapid cycling.
- **Zero-crossing and level detectors on noisy AC or sensor lines**.
- **I²C and other open-drain buses**: Schmitt-input receivers improve noise immunity on slow edges.
- **Relaxation oscillators**: LED blinkers and simple clock sources.
:::

::: assumptions
- **Ideal comparator** with rail-to-rail output and no input current; real comparators have input offset and bias currents that shift the thresholds slightly.
- **Push-pull output** at 0 V and 3.3 V. For an open-drain comparator, $V_{OH}$ is the pull-up supply, and the pull-up resistor adds to $R_f$ in the calculation.
- **Static thresholds**; real Schmitt gates' thresholds vary with supply, temperature and process: datasheets give min/max.
- **Noise smaller than the window**: if noise is larger, add filtering or a larger window.
- **Inverting versus non-inverting forms** change the mapping of thresholds but not the principle. If the interviewer draws the inverting form, derive thresholds the same way with the feedback divider on the reference node.
:::

::: followups
### What happens if the noise is bigger than the hysteresis window?
The input can still travel from one threshold to the other, so the output chatters. You need either a larger window (smaller $R_f$ or larger $R_1/R_f$ ratio), filtering before the comparator (an RC low-pass), or both. The window should exceed the peak-to-peak noise by some margin, and still leave room for the signal swing.

### Design a comparator with 100 mV of hysteresis from a 5 V output swing.
$R_1/R_f = 0.1/5 = 0.02$. Choose $R_f = 1$ MΩ and $R_1 = 20$ kΩ. If the output is rail-to-rail 0/5 V, $V_H = 5\cdot 20\text{k}/1\text{M} = 0.1$ V. Include the source resistance of the input in $R_1$, and check that thresholds are placed correctly around the desired center by solving $V_{T\pm}$ from the formula.

### Why does an I²C bus or a push-button input use a Schmitt trigger?
Both have slow, noisy edges (pull-up RC on I²C, contact bounce on a button). A single threshold would give multiple crossings; hysteresis gives one clean transition per edge and improves noise immunity. I²C also couples bus noise through long wires.

### How does hysteresis relate to ringback on a clock input?
Ringback after an edge is another form of noise at the threshold. A Schmitt input tolerates ringback as long as it doesn't cross the opposite threshold. In the earlier example a ringback of 1.55 V flips a plain 1.65 V receiver but not one with $V_{T-}=1.3$ V ([[q0691]]). It's a mitigation, not a substitute for terminating the line.

### Can hysteresis hurt? Give a case.
Yes. In a precision timing path (a zero-crossing detector for phase measurement), hysteresis shifts the trigger point depending on direction, adding a systematic phase error, and delays the output. Use a very small window there, or a comparator with controlled offset, and correct for the shift in firmware.
:::

"Hysteresis" also appears in magnetics (the B-H loop of a core) and in control (backlash, relay with dead band). If the interviewer is asking about the electrical device but mentions magnetics, the loop's memory of past state is the common idea.
