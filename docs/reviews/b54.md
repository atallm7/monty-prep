## Remaining concerns
- The site's monospace font renders `<=` as a "≤" ligature inside code spans. In q0967, regex look-behind `(?<=VDD=)` shows as `(?≤VDD=)`, which could mislead a learner. This is a site CSS fix (`font-variant-ligatures: none` on code), outside this batch's files.
- The circuit renderer has no way to escape `_` in labels. The q0960 workaround uses U+FF3F.
